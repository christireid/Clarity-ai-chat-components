# Clarity Chat Enterprise License

## Overview

The Clarity Chat Enterprise License is designed for organizations that need advanced security, compliance, and scale features beyond Pro.

## What's Included in Enterprise

Everything in Pro, plus:

- Multi-tenancy support
- SSO/SAML integration components
- Audit logging
- Advanced rate limiting with request queuing
- Cross-device synchronization with conflict resolution
- PII detection and redaction
- Prompt injection detection
- OWASP LLM Top 10 security patterns
- RAG pipeline components
- Dedicated support channel
- Custom SLA
