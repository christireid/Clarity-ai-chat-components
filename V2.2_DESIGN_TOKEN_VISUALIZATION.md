## 🎯 Design Token Decision Tree

### When to Use Which Shadow?

```
Start: Do you need a shadow?
│
├─ No → Use no shadow (flat design)
│
└─ Yes → How elevated is the element?
    │
    ├─ Base level (buttons, inputs)
    │  → shadow-xs
    │
    ├─ Slightly elevated (cards, containers)
    │  → shadow-sm
    │
    ├─ Interactive hover state
    │  → shadow-md
    │
    ├─ Floating (popovers, dropdowns)
    │  → shadow-lg
    │
    ├─ Modal (dialog, command palette)
    │  → shadow-xl
    │
    └─ Maximum (large modal, drawer)
       → shadow-2xl
```

---

### When to Use Which Border Opacity?

```
Start: Do you need a border?
│
├─ No → Use borderless design
│
└─ Yes → How prominent should it be?
    │
    ├─ Very subtle (dialogs, overlays)
    │  → border-border/30 (30%)
    │
    ├─ Default (most components)
    │  → border-border/40 (40%) ⭐
    │
    ├─ Hover/responsive state
    │  → border-border/60 (60%)
    │
    └─ Emphasis/focus (rare)
       → border-border (100%)
```

```
│         │           │          │     looks more balanced
└──────────┘           └──────────┘

Example: Icon in button
```

**v2.2 Approach:** Optical balance over mathematical precision.

## 🎨 Dark Mode Adjustments

### Shadow Opacity in Dark Mode

```
Light Mode        Dark Mode        Reason
─────────────────────────────────────────────
0.04 (4%)    →    0.20 (20%)      Need more depth
0.06 (6%)    →    0.30 (30%)      against dark bg
0.08 (8%)    →    0.40 (40%)      
0.10 (10%)   →    0.50 (50%)      Multiplier: ~5x
0.15 (15%)   →    0.60 (60%)      
```

**Key Insight:** Dark mode needs higher opacity shadows for same perceived depth.
