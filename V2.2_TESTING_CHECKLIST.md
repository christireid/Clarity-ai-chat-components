**5-Minute Smoke Test**

1. [ ] Install v2.2: `npm install @clarity-chat/react@2.2.0`
2. [ ] Start dev server
3. [ ] Check Button component - shadow should be very soft
4. [ ] Check Input component - border should be light (1px)

7. [ ] Open a dialog - backdrop should be lighter

## 📞 If Tests Fail

### Shadow Issues
**Problem:** Shadows not visible enough
**Solution:** Check `theme.css` - values may not have updated
**Verify:** Inspect element, check computed styles

### Border Issues
**Problem:** Borders too light or too heavy
**Solution:** Check opacity values (should be /40)
**Verify:** Inspect element, check border-color

### Focus Issues
**Problem:** Focus states not glowing
**Solution:** Check Tailwind config has focus utilities
**Verify:** Tab to element, inspect computed shadow

### Animation Issues
**Problem:** Animations janky
**Solution:** Check GPU acceleration (transform, not top/left)
**Verify:** Chrome DevTools Performance tab

### Dark Mode Issues
**Problem:** Not enough contrast
**Solution:** Check theme.css dark mode values
**Verify:** Toggle dark mode, check computed styles
