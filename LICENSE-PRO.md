# Clarity Chat Pro License

## Overview

The Clarity Chat Pro License grants additional features beyond the MIT-licensed core components.

## What's Included in Pro

- Memory System (conversation persistence, vector store integration)
- Advanced Analytics (usage tracking, cost monitoring)
- Custom Branding (remove watermark, custom themes)
- Priority Support (email support, faster response times)
- Tool Calling UI components
- Advanced error recovery patterns

## Core (MIT) vs Pro

The core library (`@clarity-chat/react`) is MIT-licensed and includes:
- Chat components (ChatWindow, MessageList, ChatInput, etc.)
- Basic hooks (useClarityChat, useMessages, useStreaming)
- Streaming support (SSE/WebSocket)
- Accessibility features (WCAG AAA)
- Error boundaries and basic error handling
- Theme system (15 built-in themes)
- Animations and transitions

Pro features are gated behind a license key and require a paid subscription.
