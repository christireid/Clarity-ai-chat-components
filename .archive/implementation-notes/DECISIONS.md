## Decision Template

When adding a decision, use this format:

### DEC-001: [Short Description]

| Field                | Value                                |
| -------------------- | ------------------------------------ |
| **Date**             | YYYY-MM-DD                           |
| **Category**         | warning \| lint-rule \| test \| debt |
| **Decided By**       | PM / Architect / Engineer            |
| **Related ZD Items** | ZD-XXX                               |

**Context:** Why this decision was necessary.

**Decision:** What was decided.

**Justification:** Why this is acceptable.

**Remediation Plan:** Future fix plan (if applicable).

**Approval:**

- [ ] PM Approved
- [ ] Architect Approved
