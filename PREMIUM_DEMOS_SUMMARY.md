## 🚀 How to Run

### Prerequisites
```bash
Node.js 18+
npm or yarn
```

### Run All Demos

```bash
# Demo 1: AI Research Platform
cd examples/ai-research-platform
npm install
npm run dev
# Visit http://localhost:3002

# Demo 2: Enterprise AI Ops
cd examples/enterprise-ai-ops
npm install
npm run dev
# Visit http://localhost:3003

# Demo 3: Conversational Analytics
cd examples/conversational-analytics
npm install
npm run dev
# Visit http://localhost:3004
```
