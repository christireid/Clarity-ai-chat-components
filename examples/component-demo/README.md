# Component Demo

A simple demonstration of Clarity Chat Components showing common usage patterns.

## Features

- Button examples with all variants
- Form inputs and validation
- Card layouts and patterns
- Dialog and overlay components
- Chat message components
- Real-world composition examples

## Running

```bash
npm install
npm run dev
```

Then open http://localhost:5174

## What's Inside

This demo shows the most common use cases for the component library:

1. **Buttons** - All variants, sizes, and states
2. **Forms** - Inputs, textareas, validation patterns
3. **Cards** - Layout patterns and interactive states
4. **Overlays** - Dialogs, tooltips, drawers
5. **Chat** - Message bubbles and chat interfaces
6. **Composition** - Real-world component combinations

Perfect for learning the basics or as a reference for common patterns!
