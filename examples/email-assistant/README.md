# 📧 Email Drafting Assistant Demo

AI-powered email writing assistant that helps compose professional emails, replies, and marketing
copy.

## ✨ Features

- ✍️ **Smart Composition** - AI helps write emails from scratch
- 💬 **Reply Suggestions** - Generate context-aware replies
- 🎭 **Tone Adjustment** - Professional, casual, friendly, formal
- 🌐 **Multi-Language** - Compose in multiple languages
- 🔍 **Grammar & Style** - AI checks and improves writing
- 📋 **Templates** - Pre-built email templates
- 🎯 **Purpose Detection** - Sales, support, inquiry, follow-up
- ⚡ **Quick Actions** - Summarize, expand, rephrase

## 🚀 Quick Start

```bash
npm install
cp .env.example .env.local
# Add ANTHROPIC_API_KEY to .env.local
npm run dev
```
