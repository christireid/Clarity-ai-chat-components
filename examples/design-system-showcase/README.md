# 🎨 Design System Showcase

A comprehensive showcase of the Clarity Chat Components design system, demonstrating all enhanced UI/UX patterns and components.

## Features

- **Component Gallery** - All 50+ components in one place
- **Interactive Examples** - Live demonstrations of each component
- **Design Patterns** - Visual examples of design tokens
- **Code Examples** - Copy-paste ready code snippets
- **Responsive Design** - Mobile-friendly showcase
- **Theme Switching** - Light/Dark mode toggle

## Running the Showcase

```bash
npm run dev
```

Then open http://localhost:5173

## What's Included

### Primitive Components
- Button variants and states
- Input and form elements
- Cards and containers
- Dialogs and overlays
- Badges and avatars
- Tooltips and popovers

### Chat Components
- Message bubbles
- Chat input with features
- Chat window layouts
- Thinking indicators
- Empty states

### Advanced Components
- Voice input with waveforms
- Model selector
- File upload
- Tool invocation cards
- Keyboard hints
- Interactive cards

### Design Tokens
- Color palette
- Shadow hierarchy
- Border radius scale
- Typography system
- Spacing system
- Animation guidelines

## Design Patterns Demonstrated

1. **Ring-Based Borders** - `ring-1 ring-border/50`
2. **Refined Shadows** - `shadow-xs`, `shadow-sm`
3. **Consistent Radius** - `rounded-md`, `rounded-lg`
4. **Enhanced Focus** - `ring-[3px] ring-ring/50`
5. **Precise Hover** - `-translate-y-[2px]`
6. **Consistent Opacity** - `/50`, `/30`, `/10`
