# Visual Regression Testing Guide - v2.2

**How to update and maintain visual tests after v2.2 upgrade**

---

## 🎯 **TL;DR**

**All visual changes in v2.2 are intentional improvements.** You'll need to update your visual regression baselines. This guide shows you how.

---

## ⚠️ **Expected Visual Changes**

When you upgrade to v2.2, expect these intentional changes:

### Shadows
- **40% softer** across all components
- Buttons, cards, dialogs all have lighter shadows
- This is correct ✅

### Borders
- **1px instead of 2px** in most places
- **40% opacity** by default (vs 100%)
- This is correct ✅

### Focus States
- **Glowing halos** instead of hard rings
- 1px ring + 3px outer glow
- This is correct ✅

### Hover Effects
- **1px lift** instead of 2px
- More subtle but still present
- This is correct ✅

### Badges
- **No borders** (major change)
- **Transparent backgrounds** (10% opacity)
- **Colored text** instead of white
- This is correct ✅

## 🧪 **Testing Framework Guides**

### For Playwright

#### Update Snapshots

```bash
# Update all snapshots
npx playwright test --update-snapshots

# Update specific test
npx playwright test button.spec.ts --update-snapshots

# Update in UI mode
npx playwright test --ui
# Then approve changes visually
```

#### Verify Changes

```typescript
// button.spec.ts
import { test, expect } from '@playwright/test'

test('button has refined shadow', async ({ page }) => {
  await page.goto('/components/button')
  
  const button = page.locator('button').first()
  
  // Check for v2.2 shadow class
  await expect(button).toHaveClass(/shadow-xs/)
  
  // Visual snapshot (will need updating)
  await expect(page).toHaveScreenshot('button-default.png')
})

test('button hover has subtle lift', async ({ page }) => {
  await page.goto('/components/button')
  
  const button = page.locator('button').first()
  await button.hover()
  
  // Check for v2.2 hover class
  await expect(button).toHaveClass(/-translate-y-px/)
  
  // Visual snapshot (will need updating)
  await expect(page).toHaveScreenshot('button-hover.png')
})
```

## 🔧 **Automation Scripts**

### Bulk Snapshot Update

```javascript
// scripts/update-v2.2-snapshots.js
const { execSync } = require('child_process');

const components = [
  'button',
  'input',
  'textarea',
  'card',
  'dialog',
  'badge',
  'message',
  'chat-window',
  'chat-input',
  'thinking-indicator',
];

console.log('📸 Updating v2.2 visual regression snapshots...\n');

components.forEach(component => {
  console.log(`Updating ${component}...`);
  try {
    execSync(`npx playwright test ${component}.spec.ts --update-snapshots`, {
      stdio: 'inherit'
    });
    console.log(`✅ ${component} snapshots updated\n`);
  } catch (error) {
    console.log(`❌ ${component} failed\n`);
  }
});

console.log('🎉 All snapshots updated!');
```

Usage:
```bash
node scripts/update-v2.2-snapshots.js
```

### Verify Refinements Script

```javascript
// scripts/verify-v2.2-refinements.js
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();
  
  console.log('🔍 Verifying v2.2 refinements...\n');
  
  // Check button shadow
  await page.goto('http://localhost:3000/button');
  const buttonShadow = await page.locator('button').first().evaluate(el => {
    return window.getComputedStyle(el).boxShadow;
  });
  
  if (buttonShadow.includes('rgba(0, 0, 0, 0.04)')) {
    console.log('✅ Button has refined shadow (4% opacity)');
  } else {
    console.log('❌ Button shadow not refined');
  }
  
  // Check input border
  await page.goto('http://localhost:3000/input');
  const inputClasses = await page.locator('input').first().getAttribute('class');
  
  if (inputClasses.includes('border-input/40')) {
    console.log('✅ Input has subtle border (40% opacity)');
  } else {
    console.log('❌ Input border not refined');
  }
  
  // Add more checks...
  
  await browser.close();
  console.log('\n🎉 Verification complete!');
})();
```

## 🎨 **Visual Diff Guidelines**

### What's Normal (Green Light) ✅

**Shadow Changes:**
- Shadows appear lighter/softer
- Shadow blur radius may be different
- Shadow spread may be adjusted
- Color opacity reduced

**Border Changes:**
- Borders appear thinner (2px → 1px)
- Borders appear lighter (opacity change)
- Some borders removed entirely (badges)

**Spacing Changes:**
- Elements may be slightly smaller (tighter padding)
- Gaps may be tighter
- Overall more compact

**Color Changes:**
- Badge backgrounds are transparent
- Badge text is colored
- Some text is lighter (opacity)

---

### What's Abnormal (Red Flag) ❌

**Layout Breaks:**
- Elements completely out of position
- Text overflowing containers
- Components not rendering
- Broken grids or flex layouts

**Missing Elements:**
- Shadows completely gone (should be soft, not gone)
- Borders completely invisible (should be subtle, not invisible)
- Focus states not appearing at all
- Hover states not working

**Wrong Values:**
- Shadows heavier than before (should be lighter)
- Borders thicker than before (should be thinner)
- Colors completely different (should be same hue, different opacity)

## 📸 **Screenshot Guidelines**

### Best Practices

**For Consistent Screenshots:**
1. Use same viewport size always (1280x720)
2. Disable animations (prevents timing issues)
3. Wait for fonts to load
4. Hide cursor/caret
5. Use fixed seed for dynamic content

**For Accurate Comparisons:**
1. Same lighting/color profile
2. Same zoom level (100%)
3. Same browser/version
4. Same OS font rendering

## 🎯 **Troubleshooting**

### "All my tests are failing!"

**This is expected.** v2.2 made visual changes to every component.

**Solution:**
1. Verify changes match v2.2 refinements
2. Update all snapshots
3. Tests should pass

---

### "Shadows look wrong"

**Check:**
- Are they softer? ✅ Correct
- Are they missing? ❌ Bug
- Are they heavier? ❌ Bug

**Solution:**
- If softer: Update snapshot
- If missing/heavier: Check theme.css

---

### "Borders look wrong"

**Check:**
- Are they lighter? ✅ Correct
- Are they missing? ⚠️ Depends (badges = OK, inputs = bug)
- Are they heavier? ❌ Bug

**Solution:**
- If lighter: Update snapshot
- If missing inappropriately: Check component classes

---

### "Focus states look different"

**Check:**
- Soft glow instead of hard ring? ✅ Correct
- No focus at all? ❌ Bug
- Old hard ring still? ❌ Not updated

**Solution:**
- If soft glow: Update snapshot
- If no focus: Check component implementation
