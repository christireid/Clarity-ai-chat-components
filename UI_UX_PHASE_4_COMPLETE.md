### Design Patterns Established

1. **Ring-Based Borders**
   ```tsx
   'ring-1 ring-border/50'  // Instead of 'border'
   'ring-2 ring-primary/50' // Instead of 'border-2'
   ```

2. **Refined Shadow Hierarchy**
   ```tsx
   'shadow-xs'  // Default state
   'shadow-sm'  // Hover state
   'shadow-lg'  // Popovers
   'shadow-xl'  // Dialogs/Drawers
   ```

3. **Consistent Border Radius**
   ```tsx
   'rounded-sm'  // Checkboxes, small elements
   'rounded-md'  // Buttons, inputs (most common)
   'rounded-lg'  // Cards, containers
   'rounded-full' // Avatars, circles
   ```

4. **Enhanced Focus States**
   ```tsx
   'focus-visible:ring-[3px] focus-visible:ring-ring/50 focus-visible:ring-offset-1'
   ```

5. **Precise Hover Effects**
   ```tsx
   'hover:shadow-sm hover:-translate-y-[2px]'
   ```

6. **Consistent Opacity**
   ```tsx
   'bg-muted/50'    // Default
   'bg-muted/30'    // Hover
   'bg-primary/10'  // Highlights
   ```

### Animation Guidelines

- Duration: 150ms (instant), 200ms (standard), 300ms (moderate)

- Purpose-driven animations only
