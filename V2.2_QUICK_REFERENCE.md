## ⚡ Animation Quick Reference

### Hover Effects
```tsx
// Lift (use 1px now, not 2px)
hover:-translate-y-px        // NEW standard (1px)
hover:-translate-y-0.5       // OLD (2px) - avoid

// Background hovers
hover:bg-accent/50           // NEW (lighter)
hover:bg-accent              // OLD (heavier) - avoid
```

### Focus Animations
```tsx
// Soft glow (recommended)
focus-visible:ring-1 
focus-visible:ring-ring/50 
focus-visible:shadow-focus-primary

// OLD hard ring (avoid)
focus-visible:ring-2 
focus-visible:ring-ring
```

### Timing
```tsx
duration-150   // Fast (inputs, small interactions)
duration-200   // Normal (most animations) - DEFAULT
duration-250   // Slow (complex transitions)
```

## 🔍 Common Customizations

### Override Shadow
```tsx
// Use lighter shadow
<Button className="shadow-xs">Light</Button>

// Use heavier shadow (rare)
<Button className="shadow-md">Heavy</Button>

// Remove shadow
<Button className="shadow-none">No Shadow</Button>
```

### Override Border
```tsx
// Lighter border
<Input className="border-border/20" />

// Heavier border
<Input className="border-border/60" />

// Full opacity
<Input className="border-border" />
```

### Override Hover
```tsx
// No lift
<Button className="hover:translate-y-0">No Lift</Button>

// Custom lift
<Button className="hover:-translate-y-1">2px Lift</Button>
```

## ⚠️ What NOT to Do

### ❌ Don't Use Old Patterns
```tsx
// Avoid these (v2.1 patterns)
border-2                    // Too heavy
shadow-sm hover:shadow-md   // OLD shadow levels
hover:-translate-y-0.5      // 2px lift (too much)
ring-2 ring-ring            // Hard focus ring
px-4                        // OLD button padding
```

### ✅ Use New Patterns
```tsx
// Use these (v2.2 patterns)
border border-border/40     // Subtle
shadow-xs                   // Refined
hover:-translate-y-px       // 1px lift (subtle)
ring-1 ring-ring/50 + shadow-focus-primary  // Soft glow
px-5                        // Better balance
```

## 💡 Pro Tips

### 1. Trust the Defaults
v2.2 defaults are carefully crafted. Only override when necessary.

### 2. Consistent Spacing
Use the standard scale: 1, 2, 3, 4, 6, 8 (in 0.25rem units)

### 3. Shadow Hierarchy
- `shadow-xs`: Base elements
- `shadow-sm`: Cards
- `shadow-md`: Hover states
- `shadow-lg`: Elevated (popovers)
- `shadow-xl`: Modals
- `shadow-2xl`: Large modals

### 4. Border Opacity Pattern
- `/30`: Very subtle (dialogs)
- `/40`: Default (most things)
- `/60`: Hover/active
- `/100`: Emphasis (rare)

### 5. Focus States
Always use the new soft glow pattern for accessibility:
```tsx
focus-visible:ring-1 
focus-visible:ring-ring/50 
focus-visible:shadow-focus-primary
```

## 🆘 Quick Troubleshooting

### "Borders look too light"
**Expected!** They're supposed to be subtle at 40% opacity.

### "Focus rings are different"
**Expected!** Soft glows replace hard rings (more modern).

### "Shadows are barely visible"
**Expected!** Whisper-soft shadows create premium feel.

### "Hover effects are subtle"
**Expected!** 1px lift is more refined than 2px.

### "I want the old style back"
Override with custom classes, but try the new style first!
