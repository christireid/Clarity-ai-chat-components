## 🚀 Ready to Use

### For Development
```bash
# Install components
npm install @clarity-chat/primitives @clarity-chat/react

# Install testing utilities
npm install --save-dev @clarity-chat/testing-utils

# Run showcases
cd examples/design-system-showcase && npm run dev
cd examples/theme-builder && npm run dev
cd examples/performance-dashboard && npm run dev
```

### For Testing
```bash
# Run visual regression tests
npm run test:visual

# Use testing utilities
import { renderWithProviders, mockMessage, expectAccessible } from '@clarity-chat/testing-utils'
```

### For Customization
```bash
# Run theme builder
cd examples/theme-builder
npm run dev
# Customize colors, export CSS
```

### For Monitoring
```bash
# Run performance dashboard
cd examples/performance-dashboard
npm run dev
# Monitor component performance
```
