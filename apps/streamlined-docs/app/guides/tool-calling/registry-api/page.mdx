# Tool Registry API Reference

Complete reference for the ToolRegistry API, covering tool registration, discovery, organization, and lifecycle management with support for namespaces, categories, and event-driven updates.

## Overview

The `ToolRegistry` is a central management system for tool definitions in Clarity Chat. It provides:

- **Registration & Discovery** - Register tools and query by name, category, or tags
- **Validation** - Automatic validation of tool definitions on registration
- **Organization** - Categories, tags, and namespace support
- **Event System** - Subscribe to registry changes
- **Search** - Fuzzy search with relevance scoring
- **Import/Export** - JSON serialization for persistence

**Key Benefits:**

- Type-safe tool management with TypeScript
- Prevents duplicate registrations with conflict detection
- Automatic security validation on registration
- Event-driven updates for reactive UIs
- Namespace isolation for multi-tenant applications

## Quick Start

### Basic Usage

```typescript
import { ToolRegistry } from '@clarity-chat/react/tools'
import type { ToolDefinition } from '@clarity-chat/react/tools'

// Create registry
const registry = new ToolRegistry()

// Register a tool
const weatherTool: ToolDefinition = {
  name: 'get_weather',
  description: 'Get current weather for a location',
  parameters: {
    type: 'object',
    properties: {
      location: {
        type: 'string',
        description: 'City and state, e.g. San Francisco, CA'
      }
    },
    required: ['location']
  },
  execute: async (args, context) => {
    const { location } = args
    // Fetch weather data
    return { temperature: 72, conditions: 'Sunny' }
  },
  category: 'information',
  tags: ['weather', 'api']
}

registry.register(weatherTool)

// Query tools
const tool = registry.get('get_weather')
const infoTools = registry.getByCategory('information')
const weatherTools = registry.getByTag('weather')

// Search
const results = registry.search('weather')
```

### Global Registry

For simple use cases, use the global registry instance:

```typescript
import { globalToolRegistry } from '@clarity-chat/react/tools'

// Register tools globally
globalToolRegistry.register(weatherTool)
globalToolRegistry.register(calculatorTool)

// Access from anywhere
const tool = globalToolRegistry.get('get_weather')
```

## Tool Registration

### register()

Register a single tool with validation and conflict detection.

**Signature:**
```typescript
register(tool: ToolDefinition): void
```

**Parameters:**
- `tool` - Tool definition object (see [ToolDefinition schema](#tool-definition-schema))

**Throws:**
- `Error` - If tool is invalid (missing required fields, invalid name format)
- `Error` - If tool name conflicts with existing registration

**Example:**

```typescript
const calculatorTool: ToolDefinition = {
  name: 'calculate',
  description: 'Perform mathematical calculations',
  parameters: {
    type: 'object',
    properties: {
      expression: {
        type: 'string',
        description: 'Math expression to evaluate'
      }
    },
    required: ['expression']
  },
  execute: async (args) => {
    const result = eval(args.expression) // Use safe-eval in production
    return { result }
  },
  category: 'utility',
  tags: ['math', 'calculation'],
  requiresApproval: false, // Safe calculation, no side effects
  cacheable: true, // Deterministic results
  cacheTtl: 300000 // Cache for 5 minutes
}

try {
  registry.register(calculatorTool)
  console.log('Tool registered successfully')
} catch (error) {
  console.error('Registration failed:', error.message)
}
```

**Validation Rules:**

1. **Name format**: Must match `/^[a-zA-Z_][a-zA-Z0-9_.]*$/` (alphanumeric, underscores, dots)
2. **Required fields**: `name`, `description`, `parameters`, `execute`
3. **Parameter schema**: Must have `type: 'object'` and `properties` object
4. **No duplicates**: Name must be unique in registry

### registerOrUpdate()

Register or update a tool, allowing overwrites with optional warning.

**Signature:**
```typescript
registerOrUpdate(tool: ToolDefinition, options?: { silent?: boolean }): void
```

**Parameters:**
- `tool` - Tool definition object
- `options.silent` - If `true`, suppress overwrite warnings (default: `false`)

**Use Cases:**
- Hot-reloading tools during development
- Updating tool implementations without unregistering first
- Plugin systems that may reload tools

**Example:**

```typescript
// Initial registration
registry.register(weatherTool)

// Update implementation (e.g., after hot reload)
const updatedWeatherTool = {
  ...weatherTool,
  execute: async (args) => {
    // New implementation with additional features
    const data = await fetchWeatherV2(args.location)
    return data
  }
}

// Option 1: Allow update with warning (development)
registry.registerOrUpdate(updatedWeatherTool)
// Console: "[ToolRegistry] Overwriting existing tool 'get_weather'"

// Option 2: Silent update (production)
registry.registerOrUpdate(updatedWeatherTool, { silent: true })
```

**Returns:**

### search()

Search tools with fuzzy matching and relevance scoring.

**Signature:**
```typescript
search(query: string): ToolDefinition[]
```

**Parameters:**
- `query` - Search query (case-insensitive)

**Returns:**
- Array of matching tools, sorted by relevance (highest first)

**Search Fields:**
- Tool name (highest priority)
- Display name
- Description
- Category
- Tags

**Scoring Algorithm:**
- Exact name match: +100
- Name contains query: +50
- Display name match: +30
- Description match: +20
- Category match: +15
- Tag match: +10

**Example:**

```typescript
// Simple search
const results = registry.search('weather')
console.log(`Found ${results.length} matches`)

// Empty query returns all tools
const allTools = registry.search('')

// Use case: Search UI with autocomplete
function ToolSearchBar() {
  const [query, setQuery] = useState('')
  const results = registry.search(query)

  return (
    <div>
      <input
        value={query}
        onChange={e => setQuery(e.target.value)}
        placeholder="Search tools..."
      />
      <ToolSearchResults tools={results} />
    </div>
  )
}

// Advanced: Multi-field search
function advancedSearch(criteria: {
  query?: string
  category?: string
  tags?: string[]
}) {
  let results = criteria.query
    ? registry.search(criteria.query)
    : registry.getAll()

  if (criteria.category) {
    results = results.filter(t => t.category === criteria.category)
  }

  if (criteria.tags?.length) {
    results = results.filter(t =>
      criteria.tags.some(tag => t.tags?.includes(tag))
    )
  }

  return results
}
```

## Namespace Management

### namespace()

Create a namespaced view of the registry for isolated tool collections.

**Signature:**
```typescript
namespace(namespace: string): NamespacedRegistry
```

**Parameters:**
- `namespace` - Namespace prefix (e.g., 'builtin', 'custom', 'plugin-name')

**Returns:**
- Namespaced registry instance

**Use Cases:**
- Plugin isolation (prevent name conflicts)
- Multi-tenant applications
- Built-in vs custom tool separation
- Version-specific tool collections

**Example:**

```typescript
// Create namespaced registries
const builtinRegistry = registry.namespace('builtin')
const customRegistry = registry.namespace('custom')
const pluginRegistry = registry.namespace('plugin-weather')

// Register in namespace (automatically prefixes names)
builtinRegistry.register({
  name: 'calculator', // Stored as 'builtin.calculator'
  description: 'Built-in calculator',
  // ... rest of definition
})

customRegistry.register({
  name: 'calculator', // Stored as 'custom.calculator'
  description: 'Custom calculator with extra features',
  // ... rest of definition
})

// Query from namespace
const builtinCalc = builtinRegistry.get('calculator')
// Returns tool with name 'builtin.calculator'

const customCalc = customRegistry.get('calculator')
// Returns tool with name 'custom.calculator'

// Both tools coexist without conflict
console.log(registry.has('builtin.calculator')) // true
console.log(registry.has('custom.calculator')) // true

// Get all tools in a namespace
const builtinTools = builtinRegistry.getAll()
// Only returns tools with 'builtin.*' prefix
```

**Plugin System Example:**

```typescript
class PluginManager {
  private mainRegistry = new ToolRegistry()
  private pluginNamespaces = new Map<string, NamespacedRegistry>()

  loadPlugin(pluginId: string, tools: ToolDefinition[]) {
    // Create isolated namespace for plugin
    const pluginRegistry = this.mainRegistry.namespace(`plugin-${pluginId}`)
    this.pluginNamespaces.set(pluginId, pluginRegistry)

    // Register all plugin tools in namespace
    for (const tool of tools) {
      pluginRegistry.register(tool)
    }

    console.log(`Loaded ${tools.length} tools for plugin: ${pluginId}`)
  }

  unloadPlugin(pluginId: string) {
    const pluginRegistry = this.pluginNamespaces.get(pluginId)
    if (pluginRegistry) {
      // Clear all tools in plugin namespace
      pluginRegistry.clear()
      this.pluginNamespaces.delete(pluginId)
      console.log(`Unloaded plugin: ${pluginId}`)
    }
  }

  getPluginTools(pluginId: string): ToolDefinition[] {
    const pluginRegistry = this.pluginNamespaces.get(pluginId)
    return pluginRegistry?.getAll() ?? []
  }
}
```

## Event System

### on()

Subscribe to registry events for reactive updates.

**Signature:**
```typescript
on(listener: (event: RegistryEvent) => void): () => void
```

**Parameters:**
- `listener` - Event handler function

**Returns:**
- Unsubscribe function

**Event Types:**
- `'registered'` - Tool was registered
- `'unregistered'` - Tool was unregistered
- `'cleared'` - Registry was cleared

**Event Object:**
```typescript
interface RegistryEvent {
  type: 'registered' | 'unregistered' | 'cleared'
  toolName: string
  timestamp: number
}
```

**Example:**

```typescript
// Subscribe to events
const unsubscribe = registry.on((event) => {
  console.log(`[${event.type}] ${event.toolName} at ${new Date(event.timestamp)}`)

  switch (event.type) {
    case 'registered':
      console.log(`New tool available: ${event.toolName}`)
      break
    case 'unregistered':
      console.log(`Tool removed: ${event.toolName}`)
      break
    case 'cleared':
      console.log('Registry cleared')
      break
  }
})

// Register a tool (triggers event)
registry.register(weatherTool)
// Console: "[registered] get_weather at Wed Jan 29 2026..."

// Unsubscribe when done
unsubscribe()
```

**React Integration:**

```typescript
function ToolRegistryMonitor() {
  const [events, setEvents] = useState<RegistryEvent[]>([])

  useEffect(() => {
    const unsubscribe = registry.on((event) => {
      setEvents(prev => [event, ...prev].slice(0, 10)) // Keep last 10
    })

    return unsubscribe // Cleanup on unmount
  }, [])

  return (
    <div>
      <h3>Recent Registry Events</h3>
      {events.map((event, i) => (
        <div key={i} className="p-2 border-b">
          <span className="font-bold">{event.type}</span>
          {' - '}
          <span>{event.toolName}</span>
          {' at '}
          <span className="text-sm text-gray-500">
            {new Date(event.timestamp).toLocaleTimeString()}
          </span>
        </div>
      ))}
    </div>
  )
}
```

**Real-time Tool Counter:**

```typescript
function ToolCounter() {
  const [count, setCount] = useState(registry.getAll().length)

    const unsubscribe = registry.on(() => {
```

## Tool Definition Schema

### Complete ToolDefinition Interface

```typescript
interface ToolDefinition<TArgs = Record<string, unknown>, TResult = unknown> {
  // ===== IDENTIFICATION =====

  /**
   * Unique tool identifier
   * Format: alphanumeric + underscores + dots (for namespacing)
   * Example: 'get_weather', 'builtin.calculator'
   */
  name: string

  /**
   * Human-readable description for LLM
   * Should clearly explain what the tool does and when to use it
   */
  description: string

  /**
   * Display name for UI (optional)
   * Falls back to name if not provided
   */
  displayName?: string

  // ===== PARAMETERS =====

  /**
   * JSON Schema for parameters
   * Always an object at root level
   */
  parameters: {
    type: 'object'
    properties: Record<string, ToolParameterProperty>
    required?: string[]
    additionalProperties?: boolean
  }

  // ===== EXECUTION =====

  /**
   * Async execution function
   * @param args - Validated arguments
   * @param context - Execution context (call ID, timestamps, etc.)
   * @returns JSON-serializable result
   */
  execute: (
    args: TArgs,
    context: ToolExecutionContext
  ) => Promise<TResult>

  // ===== SECURITY & BEHAVIOR =====

  /**
   * Require user approval before execution
   * Default: true (safe default)
   * Set false only for pure functions with no side effects
   */
  requiresApproval?: boolean

  /**
   * Enable result caching
   * Default: false
   * Set true only for deterministic, side-effect-free operations
   */
  cacheable?: boolean

  /**
   * Cache TTL in milliseconds
   * Default: 300000 (5 minutes)
   */
  cacheTtl?: number

  /**
   * Execution timeout in milliseconds
   * Default: 30000 (30 seconds)
   */
  timeout?: number

  /**
   * Can execute in parallel with other tools
   * Default: true
   */
  parallelizable?: boolean

  // ===== DISCOVERY & UX =====

  /**
   * Category for organization
   * Examples: 'utility', 'information', 'integration'
   */
  category?: string

  /**
   * Tags for discovery
   * Examples: ['math', 'calculation'], ['weather', 'api']
   */
  tags?: string[]

  /**
   * Icon identifier (emoji, icon name, or URL)
   */
  icon?: string

  /**
   * Color theme (CSS color, Tailwind class, or theme token)
   */
  color?: string

  // ===== LIFECYCLE HOOKS =====

  /**
   * Lifecycle hooks (all optional)
   */
  hooks?: {
    onBefore?: (args: TArgs, context: ToolExecutionContext) => void | Promise<void>
    onAfter?: (result: TResult, args: TArgs, context: ToolExecutionContext) => void | Promise<void>
    onError?: (error: Error, args: TArgs, context: ToolExecutionContext) => void | Promise<void>

  }
```

### Example 2: Plugin System with Namespaces

```typescript
class PluginRegistry {
  private mainRegistry = new ToolRegistry()
  private plugins = new Map<string, {
    namespace: NamespacedRegistry
    version: string
    enabled: boolean
  }>()

  // Load a plugin with isolated namespace
  loadPlugin(pluginId: string, version: string, tools: ToolDefinition[]) {
    // Create namespace for plugin
    const namespace = this.mainRegistry.namespace(`plugin-${pluginId}`)

    // Register all tools
    for (const tool of tools) {
      namespace.register(tool)
    }

    // Store plugin info
    this.plugins.set(pluginId, {
      namespace,
      version,
      enabled: true
    })

    console.log(`✓ Loaded plugin "${pluginId}" v${version} with ${tools.length} tools`)
  }

  // Unload a plugin
  unloadPlugin(pluginId: string) {
    const plugin = this.plugins.get(pluginId)
    if (!plugin) {
      throw new Error(`Plugin "${pluginId}" not found`)
    }

    // Clear all plugin tools
    plugin.namespace.clear()
    this.plugins.delete(pluginId)

    console.log(`✓ Unloaded plugin "${pluginId}"`)
  }

  // Enable/disable plugin
  setPluginEnabled(pluginId: string, enabled: boolean) {
    const plugin = this.plugins.get(pluginId)
    if (!plugin) {
      throw new Error(`Plugin "${pluginId}" not found`)
    }

    plugin.enabled = enabled
    console.log(`✓ Plugin "${pluginId}" ${enabled ? 'enabled' : 'disabled'}`)
  }

  // Get all tools from enabled plugins
  getEnabledTools(): ToolDefinition[] {
    const tools: ToolDefinition[] = []

    for (const [pluginId, plugin] of this.plugins) {
      if (plugin.enabled) {
        tools.push(...plugin.namespace.getAll())
      }
    }

    return tools
  }

  // Get plugin info
  getPluginInfo(pluginId: string) {
    const plugin = this.plugins.get(pluginId)
    if (!plugin) return null

    return {
      id: pluginId,
      version: plugin.version,
      enabled: plugin.enabled,
      toolCount: plugin.namespace.getAll().length,
      tools: plugin.namespace.getAll().map(t => ({
        name: t.name,
        description: t.description,
        category: t.category
      }))
    }
  }

  // List all plugins
  listPlugins() {
    return Array.from(this.plugins.entries()).map(([id, plugin]) => ({
      id,
      version: plugin.version,
      enabled: plugin.enabled,
      toolCount: plugin.namespace.getAll().length
    }))
  }
}

// Usage
const pluginRegistry = new PluginRegistry()

// Load weather plugin

  weatherTool,
  forecastTool
])

// Load math plugin

  calculatorTool,
  converterTool
])

// Get all enabled tools
const tools = pluginRegistry.getEnabledTools()
console.log(`Total enabled tools: ${tools.length}`)

// Disable a plugin

// [
//   { id: 'weather', version: '1.0.0', enabled: true, toolCount: 2 },
```

### Example 3: Version Management

```typescript
class VersionedToolRegistry {
  private registry = new ToolRegistry()
  private versions = new Map<string, Map<string, ToolDefinition>>()

  // Register a versioned tool
  registerVersion(
    baseName: string,
    version: string,
    tool: ToolDefinition
  ) {
    // Store in version map
    if (!this.versions.has(baseName)) {
      this.versions.set(baseName, new Map())
    }
    this.versions.get(baseName)!.set(version, tool)

    // Register with versioned name
    const versionedName = `${baseName}@${version}`
    this.registry.register({
      ...tool,
      name: versionedName,
      metadata: {
        ...tool.metadata,
        baseName,
        version
      }
    })
  }

  // Get a specific version
  getVersion(baseName: string, version: string): ToolDefinition | undefined {
    return this.versions.get(baseName)?.get(version)
  }

  // Get latest version
  getLatest(baseName: string): ToolDefinition | undefined {
    const versions = this.versions.get(baseName)
    if (!versions) return undefined

    const sortedVersions = Array.from(versions.keys()).sort(compareVersions)
    const latestVersion = sortedVersions[sortedVersions.length - 1]

    return versions.get(latestVersion)
  }

  // List all versions of a tool
  listVersions(baseName: string): string[] {
    const versions = this.versions.get(baseName)
    return versions ? Array.from(versions.keys()).sort(compareVersions) : []
  }

  // Deprecate a version
  deprecateVersion(baseName: string, version: string, reason: string) {
    const tool = this.getVersion(baseName, version)
    if (!tool) {
      throw new Error(`Version ${baseName}@${version} not found`)
    }

    // Update metadata
    const versionedName = `${baseName}@${version}`
    const existing = this.registry.get(versionedName)
    if (existing) {
      this.registry.registerOrUpdate({
        ...existing,
        metadata: {
          ...existing.metadata,
          deprecated: true,
          deprecationReason: reason,
          deprecatedAt: Date.now()
        }
      }, { silent: true })
    }
  }
}

// Usage
const versionedRegistry = new VersionedToolRegistry()

// Register multiple versions
versionedRegistry.registerVersion('get_weather', '1.0.0', weatherToolV1)
versionedRegistry.registerVersion('get_weather', '1.1.0', weatherToolV1_1)
versionedRegistry.registerVersion('get_weather', '2.0.0', weatherToolV2)

// Get latest version
const latest = versionedRegistry.getLatest('get_weather')
console.log(`Latest: ${latest?.metadata?.version}`) // "2.0.0"

// List all versions
const versions = versionedRegistry.listVersions('get_weather')
console.log(versions) // ["1.0.0", "1.1.0", "2.0.0"]

// Deprecate old version
versionedRegistry.deprecateVersion(
  'get_weather',
  '1.0.0',
  'Security vulnerability fixed in 1.1.0'
)

// Utility: Compare semantic versions
function compareVersions(a: string, b: string): number {
  const partsA = a.split('.').map(Number)
  const partsB = b.split('.').map(Number)

  for (let i = 0; i < 3; i++) {
    if (partsA[i] > partsB[i]) return 1
    if (partsA[i] < partsB[i]) return -1
  }

  return 0
}
```

### 1. Tool Naming Conventions

```typescript
// ✅ Good: Descriptive, snake_case
'get_weather'
'calculate_distance'
'send_email'

// ✅ Good: Namespaced for organization
'builtin.calculator'
'plugin.weather.get_forecast'
'custom.database.query'

// ❌ Bad: Unclear, inconsistent

'getWeather' // camelCase not recommended

```

Use consistent category names across your application:

```typescript
const CATEGORIES = {
```

### 3. Tag Best Practices

```typescript
// ✅ Good: Specific, searchable tags
tags: ['weather', 'api', 'location', 'forecast']

// ✅ Good: Functional tags
tags: ['read-only', 'external-api', 'cacheable']

// ❌ Bad: Too generic
tags: ['tool', 'function']

tags: ['utility'] // If category is already 'utility'
```

### 4. Event Listener Cleanup

Always unsubscribe from events to prevent memory leaks:

```typescript
// ✅ Good: React hook with cleanup
function useToolRegistry() {
  const [tools, setTools] = useState(registry.getAll())

  useEffect(() => {
    const unsubscribe = registry.on(() => {
      setTools(registry.getAll())
    })

    return unsubscribe // Cleanup on unmount
  }, [])

  return tools
}

// ❌ Bad: No cleanup
function useToolRegistry() {
  const [tools, setTools] = useState(registry.getAll())

  useEffect(() => {
    registry.on(() => setTools(registry.getAll()))
    // Memory leak: listener never removed
  }, [])

  return tools
}
```

### 6. Validation Before Registration

```typescript
// ✅ Good: Validate before bulk registration
function registerToolsSafely(tools: unknown[]) {
  const valid: ToolDefinition[] = []
  const invalid: { tool: unknown; error: string }[] = []

  for (const tool of tools) {
    try {
      validateToolDefinition(tool as any)
      valid.push(tool as ToolDefinition)
    } catch (error) {
      invalid.push({
        tool,
        error: error instanceof Error ? error.message : String(error)
      })
    }
  }

  // Register valid tools
  registry.registerMany(valid)

  // Report invalid tools
  if (invalid.length > 0) {
    console.warn(`Failed to register ${invalid.length} tools:`, invalid)
  }

  return { valid: valid.length, invalid: invalid.length }
}
```

### Generic Registry Wrapper

```typescript
class TypedToolRegistry<T extends Record<string, ToolDefinition>> {
  private registry = new ToolRegistry()

  constructor(tools: T) {
    for (const tool of Object.values(tools)) {
      this.registry.register(tool)
    }
  }

  get<K extends keyof T>(name: K): T[K] {
    const tool = this.registry.get(name as string)
    if (!tool) {
      throw new Error(`Tool "${String(name)}" not found`)
    }
    return tool as T[K]
  }
}

// Usage with type safety
const tools = {
  get_weather: weatherTool,
  calculate: calculatorTool
} as const

const typedRegistry = new TypedToolRegistry(tools)

// Type-safe access

const calc = typedRegistry.get('calculate')      // Type: typeof calculatorTool
```
