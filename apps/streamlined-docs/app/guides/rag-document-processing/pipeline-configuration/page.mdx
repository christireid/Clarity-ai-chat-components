# RAG Pipeline Configuration Guide

Build production-ready Retrieval-Augmented Generation (RAG) pipelines with optimal component integration, performance tuning, and comprehensive error handling.

## Overview

### What is a RAG Pipeline?

A RAG pipeline retrieves relevant information from a knowledge base to augment LLM responses with factual, up-to-date context. The pipeline consists of:

1. **Document Loading** - Ingest documents from various formats
2. **Text Chunking** - Split documents into semantic units
3. **Embedding Generation** - Convert text to vector representations
4. **Vector Storage** - Store and index embeddings
5. **Retrieval** - Query and rank relevant chunks
6. **Generation** - Augment LLM prompts with retrieved context

**Key Benefits:**

- **Factual Accuracy** - Ground responses in source documents
- **Up-to-date Information** - Include recent data not in training set
- **Source Attribution** - Cite specific documents and passages
- **Cost Efficiency** - Reduce context size with targeted retrieval

### Architecture Overview

```typescript
// High-level pipeline flow
Document → Loader → Chunker → Embeddings → Vector Store → Retrieval → LLM
```

## Quick Start

### Basic Pipeline Setup

```typescript
import {
  TextLoader,
  RecursiveTextSplitter,
  createEmbeddingProvider,
  createVectorStore,
} from '@clarity-chat/react'

// 1. Initialize components
const loader = new TextLoader()
const splitter = new RecursiveTextSplitter()
const embeddings = createEmbeddingProvider({
  provider: 'openai',
  apiKey: process.env.OPENAI_API_KEY,
  model: 'text-embedding-3-small',
})
const vectorStore = createVectorStore({
  provider: 'pinecone',
  apiKey: process.env.PINECONE_API_KEY,
  environment: 'us-east1-gcp',
  indexName: 'my-knowledge-base',
})

// 2. Load and process documents
const docs = await loader.load(file)
const chunks = splitter.splitDocuments(docs, {
  chunkSize: 1000,
  chunkOverlap: 200,
})

// 3. Generate embeddings
const vectors = await Promise.all(
  chunks.map(async (chunk) => ({
    id: chunk.id,
    values: await embeddings.embedText(chunk.content),
    metadata: {
      text: chunk.content,
      source: chunk.metadata.source,
    },
  }))
)

// 4. Store in vector database
await vectorStore.initialize()
await vectorStore.upsert(vectors)

// 5. Query for retrieval
const queryVector = await embeddings.embedText('How do I configure authentication?')
const results = await vectorStore.query({
  vector: queryVector,
  topK: 5,
  includeMetadata: true,
})

// 6. Use in LLM prompt
const context = results.matches
  .map((match) => match.metadata?.text)
  .join('\n\n')

const prompt = `Context:\n${context}\n\nQuestion: How do I configure authentication?`
```

```typescript
import type { DocumentLoader, Document } from '@clarity-chat/react'

class CustomCSVLoader implements DocumentLoader {
  name = 'custom-csv'
  supportedTypes = ['text/csv', 'csv']

  async load(source: string | File | Blob): Promise<Document[]> {
    const content = typeof source === 'string'
      ? source
      : await source.text()

    // Parse CSV
    const rows = content.split('\n').map(row => row.split(','))
    const headers = rows[0]
    const data = rows.slice(1)

    // Create document per row
    return data.map((row, index) => ({
      content: headers.map((h, i) => `${h}: ${row[i]}`).join('\n'),
      metadata: {
        source: source instanceof File ? source.name : 'csv',
        type: 'csv',
        row: index + 1,
      },
    }))
  }

  supports(type: string): boolean {
    return this.supportedTypes.includes(type)
  }
}

registry.register(new CustomCSVLoader())
```

### 1. Chunk Size Optimization

```typescript
// Small chunks (200-500 tokens): Precise retrieval
const precisionChunks = splitter.splitDocuments(docs, {
  chunkSize: 300,
  chunkOverlap: 50,

// Medium chunks (500-1000 tokens): Balanced
const balancedChunks = splitter.splitDocuments(docs, {
  chunkSize: 800,
  chunkOverlap: 150,
})
// Pros: Good balance of precision and context
// Cons: Requires more tokens per retrieval

// Large chunks (1000-2000 tokens): Context-heavy
const contextChunks = splitter.splitDocuments(docs, {
  chunkSize: 1500,
  chunkOverlap: 300,
})
// Pros: Rich context, fewer retrievals needed
// Cons: Higher token costs, may include irrelevant info
```

#### Chunk Size Decision Matrix

```typescript
function determineOptimalChunkSize(docType: string): number {
  switch (docType) {
    case 'technical-docs':
```

### 2. Overlap Configuration

Maintain context continuity across chunks:

```typescript
// Calculate optimal overlap (typically 10-20% of chunk size)
const chunkSize = 1000
const overlap = Math.floor(chunkSize * 0.15) // 15% = 150 tokens

const chunks = splitter.splitDocuments(docs, {
  chunkSize,
  chunkOverlap: overlap,
  preserveSentences: true, // Don't split mid-sentence
})

// Validate overlap effectiveness
function validateOverlap(chunks: DocumentChunk[]) {
  for (let i = 0; i < chunks.length - 1; i++) {
    const current = chunks[i]
    const next = chunks[i + 1]

    if (!current || !next) continue

    const overlapText = current.content.slice(-overlap)
    const hasOverlap = next.content.includes(overlapText)

    if (!hasOverlap) {
      console.warn(`Chunks ${i} and ${i + 1} have no overlap`)
    }
  }
}
```

## Performance Optimization

### 1. Batch Processing

Process documents efficiently in batches:

```typescript
async function processDocumentsBatch(
  files: File[],
  batchSize: number = 10
) {
  const results = []

  for (let i = 0; i < files.length; i += batchSize) {
    const batch = files.slice(i, i + batchSize)

    // Load documents in parallel within batch
    const loadPromises = batch.map((file) => loader.load(file))
    const docBatches = await Promise.all(loadPromises)
    const allDocs = docBatches.flat()

    // Chunk all documents
    const chunks = splitter.splitDocuments(allDocs, {
      chunkSize: 1000,
      chunkOverlap: 200,
    })

    // Generate embeddings in batch
    const texts = chunks.map((c) => c.content)
    const embeddings = await embeddingProvider.embedBatch(texts)

    // Create vectors
    const vectors = chunks.map((chunk, idx) => ({
      id: chunk.id,
      values: embeddings[idx] || [],
      metadata: {
        text: chunk.content,
        source: chunk.metadata.source,
        index: chunk.index,
      },
    }))

    // Upsert in batch
    await vectorStore.upsert(vectors)

    results.push(...vectors)

    console.log(`Processed batch ${i / batchSize + 1}/${Math.ceil(files.length / batchSize)}`)
  }

  return results
}
```

### 2. Parallel Processing

Maximize throughput with parallel operations:

```typescript
async function parallelDocumentProcessing(files: File[]) {
  const startTime = Date.now()

  // Process in parallel with concurrency limit
  const concurrency = 5
  const results = []

  for (let i = 0; i < files.length; i += concurrency) {
    const batch = files.slice(i, i + concurrency)

    const batchResults = await Promise.all(
      batch.map(async (file) => {
        try {
          // Load
          const docs = await loader.load(file)

          // Chunk
          const chunks = splitter.splitDocuments(docs, {
            chunkSize: 1000,
            chunkOverlap: 200,
          })

          // Embed (batch internally)
          const vectors = await Promise.all(
            chunks.map(async (chunk) => ({
              id: chunk.id,
              values: await embeddingProvider.embedText(chunk.content),
              metadata: { text: chunk.content, source: file.name },
            }))
          )

          return { success: true, vectors, file: file.name }
        } catch (error) {
          console.error(`Failed to process ${file.name}:`, error)
          return { success: false, error, file: file.name }
        }
      })
    )

    results.push(...batchResults)
  }

  const duration = Date.now() - startTime
  const successful = results.filter((r) => r.success).length

  console.log(`Processed ${successful}/${files.length} files in ${duration}ms`)

  return results
}
```

### 3. Caching Strategy

Implement multi-level caching:

```typescript
import { TieredCache } from '@clarity-chat/token-optimization'
import { createCachedEmbeddingProvider } from '@clarity-chat/react'

// Level 1: In-memory cache (fastest, limited size)
const memoryCache = new MemoryEmbeddingCache()

// Level 2: Redis cache (fast, larger capacity)
const redisCache = new RedisEmbeddingCache({
  host: process.env.REDIS_HOST,
  port: 6379,
  ttl: 3600, // 1 hour
})

// Tiered cache strategy
class TieredEmbeddingCache {
  async get(text: string, model: string) {
    // Try L1 first
    const memResult = await memoryCache.get(text, model)
    if (memResult) return memResult

    // Try L2
    const redisResult = await redisCache.get(text, model)
    if (redisResult) {
      // Promote to L1
      await memoryCache.set(text, model, redisResult)
      return redisResult
    }

    return null
  }

  async set(text: string, model: string, embedding: number[]) {
    // Write to both levels
    await Promise.all([
      memoryCache.set(text, model, embedding),
      redisCache.set(text, model, embedding),
    ])
  }
}

const tieredCache = new TieredEmbeddingCache()
const cachedEmbeddings = createCachedEmbeddingProvider(embeddings, {
  cache: tieredCache,
})
```

### 4. Query Optimization

Optimize retrieval performance:

```typescript
async function optimizedRetrieval(query: string, options: {
  maxResults?: number
  minScore?: number
  rerank?: boolean
}) {
  const { maxResults = 10, minScore = 0.7, rerank = true } = options

  // 1. Generate query embedding
  const queryVector = await embeddings.embedText(query)

  // 2. Retrieve more candidates than needed (for reranking)
  const candidateCount = rerank ? maxResults * 3 : maxResults
  const results = await vectorStore.query({
    vector: queryVector,
    topK: candidateCount,
    includeMetadata: true,
  })

  // 3. Filter by minimum score
  const filtered = results.matches.filter(
    (match) => (match.score || 0) >= minScore
  )

  // 4. Rerank with cross-encoder (optional)
  if (rerank) {
    const reranked = await rerankResults(query, filtered)
    return reranked.slice(0, maxResults)
  }

  return filtered.slice(0, maxResults)
}

async function rerankResults(
  query: string,
  candidates: any[]
): Promise<any[]> {
  // Use a cross-encoder model for more accurate ranking
  // This is slower but more accurate than vector similarity
  const scores = await Promise.all(
    candidates.map(async (candidate) => {
      const text = candidate.metadata?.text || ''
      const score = await calculateRelevanceScore(query, text)
      return { ...candidate, rerankScore: score }
    })
  )

  return scores.sort((a, b) => (b.rerankScore || 0) - (a.rerankScore || 0))
}

function calculateRelevanceScore(query: string, text: string): number {
  // Simple scoring based on keyword overlap (use ML model in production)
  const queryWords = new Set(query.toLowerCase().split(/\s+/))
  const textWords = text.toLowerCase().split(/\s+/)

  const matches = textWords.filter((word) => queryWords.has(word))
  return matches.length / queryWords.size
}
```

## Error Handling

### 1. Document Loading Errors

Handle various loading failures gracefully:

```typescript
async function safeLoadDocument(file: File) {
  try {
    // Validate file size
    const maxSize = 10 * 1024 * 1024 // 10 MB
    if (file.size > maxSize) {
      throw new Error(`File too large: ${file.size} bytes (max ${maxSize})`)
    }

    // Validate file type
    const supportedTypes = ['application/pdf', 'text/plain', 'application/json']
    if (!supportedTypes.includes(file.type)) {
      throw new Error(`Unsupported file type: ${file.type}`)
    }

    // Load document
    const docs = await loader.load(file)

    // Validate content
    if (!docs || docs.length === 0) {
      throw new Error('No content extracted from file')
    }

    return { success: true, docs }
  } catch (error) {
    console.error(`Failed to load ${file.name}:`, error)

    return {
      success: false,
      error: error instanceof Error ? error.message : 'Unknown error',
      file: file.name,
    }
  }
}

// Batch with error recovery
async function loadDocumentsWithRetry(files: File[], maxRetries = 3) {
  const results = []

  for (const file of files) {
    let lastError

    for (let attempt = 0; attempt < maxRetries; attempt++) {
      const result = await safeLoadDocument(file)

      if (result.success) {
        results.push(result)
        break
      }

      lastError = result.error
      console.warn(`Retry ${attempt + 1}/${maxRetries} for ${file.name}`)

      // Exponential backoff
      await new Promise((resolve) =>
        setTimeout(resolve, Math.pow(2, attempt) * 1000)
      )
    }

    if (lastError) {
      results.push({
        success: false,
        error: lastError,
        file: file.name,
      })
    }
  }

  return results
}
```

### 2. Embedding Generation Errors

Handle API failures and rate limits:

```typescript
async function safeEmbedText(
  text: string,
  options: {
    maxRetries?: number
    timeout?: number
  } = {}
) {
  const { maxRetries = 3, timeout = 30000 } = options

  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      // Set timeout
      const controller = new AbortController()
      const timeoutId = setTimeout(() => controller.abort(), timeout)

      const embedding = await embeddings.embedText(text)

      clearTimeout(timeoutId)
      return { success: true, embedding }
    } catch (error: any) {
      // Handle rate limits
      if (error.status === 429) {
        const retryAfter = error.headers?.['retry-after'] || Math.pow(2, attempt)
        console.warn(`Rate limited, retrying after ${retryAfter}s`)
        await new Promise((resolve) => setTimeout(resolve, retryAfter * 1000))
        continue
      }

      // Handle timeouts
      if (error.name === 'AbortError') {
        console.warn(`Timeout on attempt ${attempt + 1}`)
        continue
      }

      // Handle other errors
      if (attempt === maxRetries - 1) {
        return {
          success: false,
          error: error instanceof Error ? error.message : 'Unknown error',
        }
      }

      // Exponential backoff
      await new Promise((resolve) =>
        setTimeout(resolve, Math.pow(2, attempt) * 1000)
      )
    }
  }

  return { success: false, error: 'Max retries exceeded' }
}

// Batch with partial failure handling
async function embedBatchWithFallback(texts: string[]) {
  try {
    // Try batch first
    return await embeddings.embedBatch(texts)
  } catch (error) {
    console.warn('Batch embedding failed, falling back to individual')

    // Fall back to individual embeddings
    const results = await Promise.all(
      texts.map(async (text) => {
        const result = await safeEmbedText(text)
        return result.success ? result.embedding : null
      })
    )

    return results.filter((r): r is number[] => r !== null)
  }
}
```

```typescript
    if (!loadResult.success) {
      return {
        success: false,
        error: loadResult.error,
        stage: 'loading',
      }
    }

    // Stage 2: Chunk
    let chunks
    try {
      chunks = splitter.splitDocuments(loadResult.docs || [], {

        chunkOverlap: 200,

        success: false,
        error: 'Chunking failed',
        stage: 'chunking',
      }
    }

    // Stage 3: Embed
    const embeddings = await embedBatchWithFallback(
      chunks.map((c) => c.content)
    )

    if (embeddings.length !== chunks.length) {
      console.warn('Some embeddings failed, using partial results')
    }

    // Stage 4: Store
    const vectors = chunks
      .map((chunk, idx) => {
        const embedding = embeddings[idx]
        if (!embedding) return null

        return {
          id: chunk.id,
          values: embedding,
          metadata: { text: chunk.content, source: file.name },
        }
      })
      .filter((v): v is NonNullable<typeof v> => v !== null)

    try {
      await vectorStore.upsert(vectors)
    } catch (error) {
      return {
        success: false,
        error: 'Vector store upsert failed',
        stage: 'storing',
      }
    }

    return {
      success: true,
      data: {
        chunks: chunks.length,
        vectors: vectors.length,
        file: file.name,
      },
    }
  } catch (error) {
    return {
      success: false,
      error: error instanceof Error ? error.message : 'Unknown error',
      stage: 'unknown',
    }
  }
}
```

```typescript
      embeddingsGenerated: 0,

      errors: 0,
      totalDuration: 0,
      avgDocumentSize: 0,
      avgChunksPerDoc: 0,
```

```typescript
class CostTracker {
  private costs: CostMetrics = {
    embeddingCost: 0,
    vectorStorageCost: 0,
    totalCost: 0,
    tokenCount: 0,
  }

  private pricing = {
    embeddings: {
      'text-embedding-3-small': 0.02 / 1_000_000, // per token
      'text-embedding-3-large': 0.13 / 1_000_000,
    },
    vectorStore: {
      pinecone: 0.096 / 1000, // per 1K vectors per month
      qdrant: 0, // self-hosted
    },
  }

  trackEmbedding(tokens: number, model: string) {
    const cost = tokens * (this.pricing.embeddings[model] || 0)
    this.costs.embeddingCost += cost
    this.costs.tokenCount += tokens
    this.costs.totalCost += cost
  }

  trackVectorStorage(vectorCount: number, provider: string) {
    const cost = vectorCount * (this.pricing.vectorStore[provider] || 0)
    this.costs.vectorStorageCost += cost
    this.costs.totalCost += cost
  }

  getCosts(): CostMetrics {
    return { ...this.costs }
  }

  getProjectedMonthlyCost(vectorsPerDay: number): number {
    const dailyEmbeddingCost =
      (this.costs.embeddingCost / this.costs.tokenCount) *
      vectorsPerDay *
      500 // avg tokens per doc

    const monthlyStorage =
      vectorsPerDay * 30 * this.pricing.vectorStore.pinecone

    return (dailyEmbeddingCost * 30) + monthlyStorage
  }
}
```

### 3. Quality Metrics

Monitor retrieval quality:

```typescript
interface QualityMetrics {
  averageRelevanceScore: number
  topKRecall: number
  precision: number
  averageLatency: number
  cacheHitRate: number
}

class QualityMonitor {
  private samples: Array<{
    query: string
    results: any[]
    relevantIds: Set<string>
    latency: number
    cached: boolean
  }> = []

  async trackQuery(
    query: string,
    relevantIds: string[],
    fn: () => Promise<any[]>
  ) {
    const startTime = Date.now()
    const results = await fn()
    const latency = Date.now() - startTime

    this.samples.push({
      query,
      results,
      relevantIds: new Set(relevantIds),
      latency,
      cached: false, // Track from cache stats
    })

    return results
  }

  calculateMetrics(): QualityMetrics {
    const total = this.samples.length
    if (total === 0) {
      return {
        averageRelevanceScore: 0,
        topKRecall: 0,
        precision: 0,
        averageLatency: 0,
        cacheHitRate: 0,
      }
    }

    let totalRelevance = 0
    let totalRecall = 0
    let totalPrecision = 0
    let totalLatency = 0
    let cacheHits = 0

    for (const sample of this.samples) {
      // Average relevance score
      const avgScore =
        sample.results.reduce((sum, r) => sum + (r.score || 0), 0) /
        sample.results.length
      totalRelevance += avgScore

      // Recall: % of relevant docs retrieved
      const retrieved = new Set(sample.results.map((r) => r.id))
      const relevant = sample.relevantIds
      const intersection = new Set(
        [...retrieved].filter((x) => relevant.has(x))
      )
      const recall = relevant.size > 0 ? intersection.size / relevant.size : 0
      totalRecall += recall

      // Precision: % of retrieved docs that are relevant
      const precision =
        retrieved.size > 0 ? intersection.size / retrieved.size : 0
      totalPrecision += precision

      totalLatency += sample.latency
      if (sample.cached) cacheHits++
    }

    return {
      averageRelevanceScore: totalRelevance / total,
      topKRecall: totalRecall / total,
      precision: totalPrecision / total,
      averageLatency: totalLatency / total,
      cacheHitRate: cacheHits / total,
    }
  }
}
```

```typescript
import { AccurateTokenCounter } from '@clarity-chat/token-optimization'

async function productionRAGPipeline(
  files: File[],
  options: {
    batchSize?: number
    useSemanticChunking?: boolean
    monitoring?: boolean
  } = {}
) {
  const {
    batchSize = 10,
    useSemanticChunking = false,
    monitoring = true,
  } = options

  // Initialize monitoring
  const monitor = monitoring ? new PipelineMonitor() : null
  const logger = monitoring ? new PipelineLogger() : null
  const costTracker = monitoring ? new CostTracker() : null

  logger?.info('pipeline', 'Starting RAG pipeline', {
    files: files.length,
    batchSize,
  })

  // Initialize components with error handling
  const registry = new LoaderRegistry()
  const embeddings = createCachedEmbeddingProvider({
    provider: 'openai',
    apiKey: process.env.OPENAI_API_KEY,
    model: 'text-embedding-3-small',
  })
  const vectorStore = new RobustVectorStore(
    createVectorStore({
      provider: 'pinecone',
      apiKey: process.env.PINECONE_API_KEY,
      environment: 'us-east1-gcp',
      indexName: 'production-kb',
    })
  )

  // Initialize vector store
  await vectorStore.store.initialize()

  // Process in batches
  const results = []

  for (let i = 0; i < files.length; i += batchSize) {
    const batch = files.slice(i, i + batchSize)
    logger?.info('pipeline', `Processing batch ${i / batchSize + 1}`, {
      files: batch.length,
    })

    const batchResults = await Promise.all(
      batch.map(async (file) => {
        return await monitor?.trackPipeline(async () => {
          // Load with retry
          const loadResult = await safeLoadDocument(file)
          if (!loadResult.success) {
            logger?.error('loading', 'Failed to load document', {
              file: file.name,
              error: loadResult.error,
            })
            return { success: false, error: loadResult.error }
          }

          // Chunk
          let chunks
          if (useSemanticChunking) {
            const counter = new AccurateTokenCounter({ model: 'gpt-4' })
            const semanticChunker = new SemanticChunker(
              (text) => counter.count(text),
              (text) => embeddings.embedText(text)
            )
            const allText = loadResult.docs?.map((d) => d.content).join('\n\n')
            chunks = await semanticChunker.chunkConversation(allText || '')
          } else {
            const splitter = new RecursiveTextSplitter()
            chunks = splitter.splitDocuments(loadResult.docs || [], {
              chunkSize: 1000,
              chunkOverlap: 200,
            })
          }

          logger?.debug('chunking', 'Created chunks', {
            file: file.name,
            chunks: chunks.length,
          })

          // Embed with fallback
          const embedResults = await embedBatchWithFallback(
            chunks.map((c) => c.content || c.text)
          )

          // Track costs
          const totalTokens = chunks.reduce(
            (sum, c) => sum + (c.tokens || 0),
            0
          )
          costTracker?.trackEmbedding(totalTokens, 'text-embedding-3-small')

          // Create vectors
          const vectors = chunks
            .map((chunk, idx) => {
              const embedding = embedResults[idx]
              if (!embedding) return null

              return {
                id: `${file.name}-${idx}`,
                values: embedding,
                metadata: {
                  text: chunk.content || chunk.text,
                  source: file.name,
                  index: idx,
                  topic: chunk.topic,
                },
              }
            })
            .filter((v): v is NonNullable<typeof v> => v !== null)

          // Store with error handling
          try {
            await vectorStore.store.upsert(vectors)
            costTracker?.trackVectorStorage(vectors.length, 'pinecone')

            logger?.info('storing', 'Stored vectors', {
              file: file.name,
              vectors: vectors.length,
            })
          } catch (error) {
            logger?.error('storing', 'Failed to store vectors', {
              file: file.name,
              error,
            })
            return { success: false, error: 'Storage failed' }
          }

          return {
            success: true,
            file: file.name,
            chunks: chunks.length,
            vectors: vectors.length,
          }
        })
      })
    )

    results.push(...batchResults)
  }

    results,
    metrics: monitor?.getMetrics(),
    costs: costTracker?.getCosts(),
```

```typescript
    vector: queryVector,

    includeMetadata: true,
  })

  // Filter by score
  let filtered = results.matches.filter(
    (match) => (match.score || 0) >= minScore

  // Rerank if requested
  if (rerank) {
    filtered = await rerankResults(query, filtered)
  }

  // Take top K

      return `[${idx + 1}] (Source: ${source})\n${text}`
```
