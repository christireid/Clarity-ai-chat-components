# Migration Guide: v1.x to v2.0

<Callout type="info">
  **Upgrade Time:** 10-30 minutes for most projects • **Breaking Changes:** Dependency management + API refinements • **Bundle Reduction:** 60-92% depending on features used
</Callout>

## Overview

Clarity Chat 2.0 is a **major architecture improvement** focused on performance, bundle size optimization, and API consistency. This guide provides everything you need for a smooth migration.

### What Changed

| Category | Impact | Description |
|----------|--------|-------------|
| **Peer Dependencies** | 🔴 High | Major dependencies externalized for better tree-shaking |
| **Hook Names** | 🟡 Medium | `useChat` removed in favor of `useClarityChat` |
| **Component Props** | 🟡 Medium | Nested props flattened for better DX |
| **Token Optimization** | 🟢 Low | Import path changes (still backwards compatible) |
| **Deprecated APIs** | 🟢 Low | Legacy components removed with replacements |

### Key Benefits

✅ **60-92% smaller bundles** depending on feature usage
✅ **Better tree-shaking** and code splitting
✅ **Improved type safety** with stricter TypeScript
✅ **Enhanced DX** with simpler APIs
✅ **Zero runtime changes** - only build-time improvements

## Breaking Changes

### 1. Peer Dependencies Externalized

**Impact:** 🔴 **HIGH** - Required action

**What Changed:**
Major dependencies moved from bundled to peer dependencies, giving you control over versions and dramatically reducing bundle size.

**Required Dependencies:**
```json
{
  "react": "^18.0.0 || ^19.0.0",
  "framer-motion": "^12.23.25",
  "lucide-react": "^0.500.0",
  "zod": "^3.24.0"
}
```

**Optional Dependencies** (install only if using the feature):
```json
{
  "flowtoken": "^1.0.0",          // Token optimization
  "mermaid": "^11.0.0",            // Diagram rendering
  "pdfjs-dist": "^3.0.0 || ^4.0.0", // PDF loader
  "mammoth": "^1.0.0",             // DOCX loader
  "cohere-ai": "^7.0.0",           // Cohere reranking
  "shiki": "^3.0.0",               // Syntax highlighting
  "jszip": "^3.10.0",              // ZIP handling
  "prismjs": "^1.29.0",            // Code highlighting
  "react-markdown": "^10.0.0",     // Markdown rendering
  "remark-gfm": "^4.0.0",          // GitHub Flavored Markdown
  "rehype-highlight": "^7.0.0"     // Code highlighting
}
```

**Migration Steps:**

```bash
# Minimal installation (basic chat only)
npm install @clarity-chat/react@2.0.0 \
  framer-motion@^12.23.25 \
  lucide-react@^0.500.0 \
  zod@^3.24.0

npm install flowtoken@^1.0.0

# With document loaders (RAG features)
npm install pdfjs-dist@^4.0.0 mammoth@^1.0.0 jszip@^3.10.0

# With Cohere reranking
npm install cohere-ai@^7.0.0

# With advanced code highlighting
npm install shiki@^3.0.0

# With markdown rendering
npm install react-markdown@^10.0.0 remark-gfm@^4.0.0 rehype-highlight@^7.0.0
```

### 2. Hook API Changes

**Impact:** 🟡 **MEDIUM** - Code changes required

#### useChat → useClarityChat

The generic `useChat` hook has been removed in favor of the more specific `useClarityChat`.

**Before (v1.x):**
```tsx
import { useChat } from '@clarity-chat/react'

function ChatComponent() {
  const { messages, append, isLoading } = useChat({
    api: '/api/chat'
  })

  return <ChatWindow messages={messages} isLoading={isLoading} />
}
```

**After (v2.0):**
```tsx
import { useClarityChat } from '@clarity-chat/react'

function ChatComponent() {
  const { messages, append, isLoading } = useClarityChat({
    api: '/api/chat'
  })

  return <ChatWindow messages={messages} isLoading={isLoading} />
}
```

**Automated Fix:** Use the codemod script (see below)

### 3. Component Prop Structure

**Impact:** 🟡 **MEDIUM** - API improvements

Component props have been flattened from nested objects to top-level props for better DX.

#### ChatWindow Props

**Before (v1.x):**
```tsx
<ChatWindow
  messages={messages}
  messageActions={{
    onCopy: handleCopy,
    onFeedback: handleFeedback,
    onRetry: handleRetry,
  }}
  editActions={{
    editingMessageId: editingId,
    onSaveEdit: handleSave,
    onCancelEdit: handleCancel,
  }}
  header={{
    show: true,
    title: 'Chat Assistant',
    showMessageCount: true,
  }}
/>
```

**After (v2.0) - Legacy props still supported:**
```tsx
<ChatWindow
  messages={messages}
  // New top-level props (recommended)
  onMessageCopy={handleCopy}
  onMessageFeedback={handleFeedback}
  onMessageRetry={handleRetry}
  editingMessageId={editingId}
  onSaveEdit={handleSave}
  onCancelEdit={handleCancel}
  showHeader={true}
  sessionTitle="Chat Assistant"
  showMessageCount={true}
/>
```

**Note:** Nested props are still supported for backwards compatibility but will be removed in v3.0. Update to top-level props when convenient.

---

### 4. Token Optimization Import Paths

**Impact:** 🟢 **LOW** - Import path changes

Token optimization utilities have moved to a dedicated package for better modularity.

**Before (v1.x):**
```tsx
import { TokenCounter, compressText } from '@clarity-chat/react/internal'
```

**After (v2.0):**
```tsx
import { AccurateTokenCounter, compressAdaptively } from '@clarity-chat/token-optimization'
```

**Note:** Old imports still work but emit deprecation warnings. Update imports to avoid warnings.

---

### 5. Deprecated Components Removed

**Impact:** 🟢 **LOW** - Clear replacements available

#### Think Component

**Before (v1.x):**
```tsx
import { Think } from '@clarity-chat/react'

<Think reasoning={reasoning} />
```

**After (v2.0):**
```tsx
import { ThinkingPill } from '@clarity-chat/react'

<ThinkingPill reasoning={reasoning} />
```

#### Token Components

**Before (v1.x):**
```tsx
import { TokenOptimizationBadge } from '@clarity-chat/react'
```

**After (v2.0):**
```tsx
import { TokenOptimizationBadge } from '@clarity-chat/token-optimization/react'
```

## Testing Migration Completeness

### Automated Checks

Create a migration verification script:

```typescript
// scripts/verify-migration.ts
import { execSync } from 'child_process'
import * as fs from 'fs'

interface MigrationCheck {
  name: string
  check: () => boolean
  fix?: string
}

const checks: MigrationCheck[] = [
  {
    name: 'No useChat imports',
    check: () => {
      try {
        execSync('grep -r "useChat" src/ --include="*.tsx" --include="*.ts"', {
          stdio: 'pipe'
        })
        return false // Found useChat
      } catch {
        return true // No useChat found
      }
    },
    fix: 'Run codemod: node migrate-v1-to-v2.js src/'
  },
  {
    name: 'Peer dependencies installed',
    check: () => {
      const pkg = JSON.parse(fs.readFileSync('package.json', 'utf-8'))
      const deps = { ...pkg.dependencies, ...pkg.devDependencies }
      return !!(deps['framer-motion'] && deps['lucide-react'] && deps['zod'])
    },
    fix: 'npm install framer-motion lucide-react zod'
  },
  {
    name: 'No deprecated imports',
    check: () => {
      try {
        execSync('grep -r "@clarity-chat/react/internal" src/', {
          stdio: 'pipe'
        })
        return false // Found deprecated imports
      } catch {
        return true // No deprecated imports
      }
    },
    fix: 'Update imports to @clarity-chat/token-optimization'
  },
  {
    name: 'TypeScript compiles',
    check: () => {
      try {
        execSync('npm run typecheck', { stdio: 'pipe' })
        return true
      } catch {
        return false
      }
    },
    fix: 'Fix TypeScript errors reported by typecheck'
  },
  {
    name: 'Tests pass',
    check: () => {
      try {
        execSync('npm test', { stdio: 'pipe' })
        return true
      } catch {
        return false
      }
    },
    fix: 'Fix failing tests'
  }
]

console.log('🔍 Verifying migration completeness...\n')

let allPassed = true

for (const check of checks) {
  const passed = check.check()
  const icon = passed ? '✅' : '❌'
  console.log(`${icon} ${check.name}`)

  if (!passed) {
    allPassed = false
    if (check.fix) {
      console.log(`   Fix: ${check.fix}`)
    }
  }
}

console.log(allPassed ? '\n✅ Migration complete!' : '\n⚠️  Some checks failed')
process.exit(allPassed ? 0 : 1)
```

**Run verification:**
```bash
npx tsx scripts/verify-migration.ts
```

## Rollback Plan

If you encounter issues during migration, follow these steps to rollback:

### Immediate Rollback

```bash
# If you used --backup flag, restore from backups
find src/ -name "*.v1.backup" -exec bash -c 'mv "$0" "${0%.v1.backup}"' {} \;

# Or revert via git
git checkout src/

# Downgrade package
npm install @clarity-chat/react@1.1.0
```

### Complete Rollback

**Step 1: Downgrade package**
```bash
npm install @clarity-chat/react@1.1.0
# or
pnpm add @clarity-chat/react@1.1.0
# or
yarn add @clarity-chat/react@1.1.0
```

**Step 2: Update package.json**
```json
{
  "dependencies": {
    "@clarity-chat/react": "^1.1.0"
  }
}
```

**Step 3: Remove peer dependencies (optional)**

Only if they're not used by other packages:
```bash
npm uninstall framer-motion lucide-react zod flowtoken \
  mermaid pdfjs-dist mammoth cohere-ai shiki jszip \
  prismjs react-markdown remark-gfm rehype-highlight
```

**Step 4: Reinstall and test**
```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```

**Step 5: Report issue**

If you needed to rollback, please report:
- Error messages
- Migration report output
- Environment details (Node version, package manager, OS)
- GitHub Issue: https://github.com/christireid/Clarity-ai-chat-components/issues

## Deprecation Warnings

### Runtime Warnings

If you see deprecation warnings in your console, update as follows:

#### "useChat is deprecated"
```tsx
// ❌ Old
import { useChat } from '@clarity-chat/react'

// ✅ New
import { useClarityChat } from '@clarity-chat/react'
```

#### "Import from @clarity-chat/token-optimization"
```tsx
// ❌ Old
import { TokenCounter } from '@clarity-chat/react/internal'

// ✅ New
import { AccurateTokenCounter } from '@clarity-chat/token-optimization'
```

#### "Think component is deprecated"
```tsx
// ❌ Old
import { Think } from '@clarity-chat/react'

// ✅ New
import { ThinkingPill } from '@clarity-chat/react'
```

### Suppressing Warnings

**Not recommended**, but if you need time to migrate:

```tsx
// In your entry point or test setup
if (process.env.NODE_ENV === 'development') {
  const originalWarn = console.warn
  console.warn = (...args) => {
    if (typeof args[0] === 'string' && args[0].includes('deprecated')) {
      return // Suppress deprecation warnings
    }
    originalWarn(...args)
  }
}
```

## Common Issues & Solutions

### Issue: Missing Peer Dependency Warning

**Symptoms:**
```
npm WARN @clarity-chat/react@2.0.0 requires a peer of framer-motion@^12.23.25 but none is installed
```

**Solution:**
```bash
npm install framer-motion@^12.23.25
```

### Issue: Module Not Found Error

**Symptoms:**
```
Module not found: Can't resolve 'lucide-react'
```

**Solution:**
```bash
npm install lucide-react@^0.500.0
```

### Issue: TypeScript Errors After Migration

**Symptoms:**
```
Property 'append' does not exist on type 'UseClarityChatReturn'
```

**Solution:**
1. Ensure TypeScript is using the latest type definitions:
```bash
npm install @clarity-chat/react@latest --save-exact
rm -rf node_modules/.cache
```

2. Restart your TypeScript server (VS Code: Cmd+Shift+P → "TypeScript: Restart TS Server")

### Issue: Feature Not Working (Optional Dependency)

**Symptoms:**
```
Warning: PDF loader requires pdfjs-dist to be installed
```

**Solution:**
Install the optional dependency for that feature:
```bash
npm install pdfjs-dist@^4.0.0
```

### Issue: Bundle Size Didn't Decrease

**Symptoms:**
Bundle size is similar to v1.x after migration.

**Solution:**
1. Verify peer dependencies are external in your bundler config
2. Check for accidental direct imports:
```bash
# Find large imports
npm run build -- --analyze

# Check for unused optional dependencies
grep -r "pdfjs\|mammoth\|mermaid\|shiki" src/
```

3. Use dynamic imports for optional features:
```tsx
// Instead of
import { PDFLoader } from '@clarity-chat/token-optimization'

// Use dynamic import
const loadPDF = async (file: File) => {
  const { PDFLoader } = await import('@clarity-chat/token-optimization')
  const loader = new PDFLoader()
  return loader.load(file)
}
```

### Issue: Animations Not Working

**Symptoms:**
Animations are choppy or not working.

**Solution:**
Ensure framer-motion is installed and imported:
```bash
npm install framer-motion@^12.23.25
```

### Issue: Tests Failing After Migration

**Symptoms:**
Tests that passed on v1.x now fail on v2.0.

**Solution:**
1. Update test utilities:
```tsx
// Before
import { render } from '@testing-library/react'

// After - ensure peer deps are available in test environment
import { render } from '@testing-library/react'
import '@testing-library/jest-dom' // If using jest-dom matchers
```

2. Mock peer dependencies if needed:
```tsx
// vitest.config.ts or jest.config.js
export default {
  setupFiles: ['./test-setup.ts'],
}

// test-setup.ts
vi.mock('framer-motion', () => ({
  motion: {
    div: 'div',
    span: 'span',
  },
  AnimatePresence: ({ children }: any) => children,
}))
```

## Bundle Size Optimization Tips

After migrating, optimize your bundle further:

### 1. Use Dynamic Imports for Heavy Features

```tsx
// PDF loader (800KB)
const PDFViewer = lazy(() => import('./components/PDFViewer'))

// Mermaid diagrams (1.2MB)
const MermaidDiagram = lazy(() => import('./components/MermaidDiagram'))

// Syntax highlighting (2.5MB)
const CodeEditor = lazy(() => import('./components/CodeEditor'))
```

### 2. Install Only Required Optional Dependencies

Review and remove unused optional dependencies:

```bash
# Check what's actually used
npm ls | grep -E "flowtoken|mermaid|pdfjs|mammoth|cohere|shiki"

# Remove if not needed
npm uninstall flowtoken mermaid pdfjs-dist mammoth cohere-ai shiki
```

### 3. Configure Code Splitting

```typescript
// vite.config.ts
export default {
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          'clarity-chat': ['@clarity-chat/react'],
          'animations': ['framer-motion'],
          'icons': ['lucide-react'],
        }
      }
    }
  }
}

// next.config.js
module.exports = {
  webpack: (config) => {
    config.optimization.splitChunks = {
      cacheGroups: {
        clarityChat: {
          test: /@clarity-chat/,
          name: 'clarity-chat',
          chunks: 'all',
        }
      }
    }
    return config
  }
}
```

### 4. Use Tree-Shaking Friendly Imports

```tsx
// ✅ Good - imports only what's needed
import { ChatWindow } from '@clarity-chat/react'

// ❌ Bad - might import more than needed
import * as ClarityChat from '@clarity-chat/react'
```

## FAQ

### Do I need to change any code?

For most projects, the codemod handles 90% of changes automatically. You'll mainly need to install peer dependencies and verify everything works.

### Can I migrate incrementally?

Yes! v2.0 maintains backwards compatibility with v1.x APIs (with deprecation warnings). You can migrate one feature at a time.

### What if I'm using React 19?

Clarity Chat v2.0 fully supports React 19. Just ensure you're using compatible peer dependency versions.

### Will this break my production app?

No, if you follow the migration guide and install required peer dependencies. Always test in staging first.

### Can I use different versions of peer dependencies?

Generally yes, but we recommend the specified versions. Use `npm ls` to check for conflicts.

### How do I know which optional dependencies I need?

Check the feature mapping:
- Token optimization → `flowtoken`
- PDF loading → `pdfjs-dist`
- DOCX loading → `mammoth`
- Cohere reranking → `cohere-ai`
- Advanced highlighting → `shiki`
- Mermaid diagrams → `mermaid`
- Markdown rendering → `react-markdown`, `remark-gfm`, `rehype-highlight`

### What's the deadline for migration?

There's no deadline! v1.x will continue to work. However, new features and bug fixes will focus on v2.0+.

### Can I get help with migration?

Yes! Open a GitHub issue with the `migration` label, or join our Discord community.
