# Provider Caching Strategies

Comprehensive guide to implementing intelligent caching for LLM providers to reduce costs and improve response times.

## Overview

Effective caching can reduce LLM API costs by 50-90% and improve response times by 10-100x. This guide covers multiple caching strategies with real-world implementations and performance benchmarks.

## Cache Key Generation

### Deterministic Hashing

Generate consistent cache keys from prompts and parameters:

```typescript
import { createHash } from 'crypto';

interface CacheableRequest {
  prompt: string;
  model: string;
  temperature?: number;
  maxTokens?: number;
  systemPrompt?: string;
  tools?: any[];
}

export function generateCacheKey(request: CacheableRequest): string {
  // Normalize temperature to avoid float precision issues
  const normalizedTemp = request.temperature
    ? Math.round(request.temperature * 1000) / 1000
    : 1.0;

  // Create deterministic object representation
  const cacheObject = {
    prompt: request.prompt.trim(),
    model: request.model,
    temperature: normalizedTemp,
    maxTokens: request.maxTokens || null,
    systemPrompt: request.systemPrompt?.trim() || '',
    tools: request.tools ? JSON.stringify(request.tools) : null
  };

  // Generate SHA-256 hash
  const hash = createHash('sha256')
    .update(JSON.stringify(cacheObject))
    .digest('hex');

  // Include model prefix for easy identification
  return `${request.model}:${hash}`;
}

// Example usage
const key = generateCacheKey({
  prompt: 'Explain quantum computing',
  model: 'claude-3-5-sonnet-20241022',
  temperature: 0.7,
  maxTokens: 1000
});
// Returns: "claude-3-5-sonnet-20241022:a3f2c9d8e1..."
```

### Semantic Similarity Hashing

For fuzzy matching of similar prompts:

```typescript
import { encode } from 'gpt-tokenizer';
import { cosineSimilarity } from './similarity';

export class SemanticCacheKeyGenerator {
  private embeddings: Map<string, number[]> = new Map();

  async generateSemanticKey(
    prompt: string,
    threshold: number = 0.95
  ): Promise<{ key: string; isExactMatch: boolean }> {
    // Check for exact matches first
    const exactKey = this.hashPrompt(prompt);

    // Look for semantically similar cached prompts
    for (const [cachedKey, embedding] of this.embeddings.entries()) {
      const promptEmbedding = await this.getEmbedding(prompt);
      const similarity = cosineSimilarity(embedding, promptEmbedding);

      if (similarity >= threshold) {
        return { key: cachedKey, isExactMatch: false };
      }
    }

    // No match found, create new key
    return { key: exactKey, isExactMatch: true };
  }

  private hashPrompt(prompt: string): string {
    return createHash('sha256').update(prompt).digest('hex');
  }

  private async getEmbedding(text: string): Promise<number[]> {
    // Use lightweight embedding model or token-based approximation
    const tokens = encode(text);
    // Simplified: In production, use actual embedding model
    return tokens.slice(0, 128).map(t => t / 1000);
  }
}
```

## Cache Invalidation Policies

### Time-To-Live (TTL)

Expire cache entries after a specified duration:

```typescript
interface CacheEntry<T> {
  value: T;
  createdAt: number;
  lastAccessedAt: number;
  ttl: number;
  hits: number;
}

export class TTLCache<T> {
  private cache = new Map<string, CacheEntry<T>>();
  private defaultTTL: number;

  constructor(defaultTTL: number = 3600000) { // 1 hour default
    this.defaultTTL = defaultTTL;
    this.startCleanupInterval();
  }

  set(key: string, value: T, ttl?: number): void {
    this.cache.set(key, {
      value,
      createdAt: Date.now(),
      lastAccessedAt: Date.now(),
      ttl: ttl || this.defaultTTL,
      hits: 0
    });
  }

  get(key: string): T | null {
    const entry = this.cache.get(key);

    if (!entry) {
      return null;
    }

    // Check if expired
    const age = Date.now() - entry.createdAt;
    if (age > entry.ttl) {
      this.cache.delete(key);
      return null;
    }

    // Update access time and hits
    entry.lastAccessedAt = Date.now();
    entry.hits++;

    return entry.value;
  }

  private startCleanupInterval(): void {
    setInterval(() => {
      const now = Date.now();
      for (const [key, entry] of this.cache.entries()) {
        if (now - entry.createdAt > entry.ttl) {
          this.cache.delete(key);
        }
      }
    }, 60000); // Clean every minute
  }

  getStats() {
    let totalHits = 0;
    let totalAge = 0;

    for (const entry of this.cache.values()) {
      totalHits += entry.hits;
      totalAge += Date.now() - entry.createdAt;
    }

    return {
      size: this.cache.size,
      totalHits,
      averageAge: totalAge / this.cache.size,
      averageHits: totalHits / this.cache.size
    };
  }
}
```

### Least Recently Used (LRU)

Evict least recently used entries when cache is full:

```typescript
export class LRUCache<T> {
  private cache = new Map<string, T>();
  private maxSize: number;

  constructor(maxSize: number = 1000) {
    this.maxSize = maxSize;
  }

  get(key: string): T | null {
    const value = this.cache.get(key);

    if (!value) {
      return null;
    }

    // Move to end (most recently used)
    this.cache.delete(key);
    this.cache.set(key, value);

    return value;
  }

  set(key: string, value: T): void {
    // Remove if exists (to update position)
    if (this.cache.has(key)) {
      this.cache.delete(key);
    }

    // Add to end
    this.cache.set(key, value);

    // Evict oldest if over capacity
    if (this.cache.size > this.maxSize) {
      const firstKey = this.cache.keys().next().value;
      this.cache.delete(firstKey);
    }
  }

  has(key: string): boolean {
    return this.cache.has(key);
  }

  delete(key: string): boolean {
    return this.cache.delete(key);
  }

  clear(): void {
    this.cache.clear();
  }

  get size(): number {
    return this.cache.size;
  }
}
```

### Adaptive Invalidation

Intelligent invalidation based on usage patterns:

```typescript
interface AdaptiveCacheEntry<T> {
  value: T;
  createdAt: number;
  lastAccessedAt: number;
  hits: number;
  score: number; // Composite score for eviction priority
}

export class AdaptiveCache<T> {
  private cache = new Map<string, AdaptiveCacheEntry<T>>();
  private maxSize: number;
  private baseScore = 100;

  constructor(maxSize: number = 1000) {
    this.maxSize = maxSize;
    this.startScoreDecay();
  }

  get(key: string): T | null {
    const entry = this.cache.get(key);

    if (!entry) {
      return null;
    }

    // Update access patterns
    entry.lastAccessedAt = Date.now();
    entry.hits++;
    entry.score = this.calculateScore(entry);

    return entry.value;
  }

  set(key: string, value: T): void {
    const entry: AdaptiveCacheEntry<T> = {
      value,
      createdAt: Date.now(),
      lastAccessedAt: Date.now(),
      hits: 0,
      score: this.baseScore
    };

    this.cache.set(key, entry);

    // Evict if necessary
    if (this.cache.size > this.maxSize) {
      this.evictLowestScore();
    }
  }

  private calculateScore(entry: AdaptiveCacheEntry<T>): number {
    const now = Date.now();
    const age = now - entry.createdAt;
    const recency = now - entry.lastAccessedAt;

    // Score based on frequency, recency, and age
    const frequencyScore = Math.log(entry.hits + 1) * 20;
    const recencyScore = Math.max(0, 100 - (recency / 60000)); // Decay over 100 minutes
    const ageScore = Math.max(0, 100 - (age / 3600000)); // Decay over 100 hours

    return frequencyScore + recencyScore + ageScore;
  }

  private evictLowestScore(): void {
    let lowestScore = Infinity;
    let lowestKey: string | null = null;

    for (const [key, entry] of this.cache.entries()) {
      if (entry.score < lowestScore) {
        lowestScore = entry.score;
        lowestKey = key;
      }
    }

    if (lowestKey) {
      this.cache.delete(lowestKey);
    }
  }

  private startScoreDecay(): void {
    setInterval(() => {
      for (const entry of this.cache.values()) {
        entry.score = this.calculateScore(entry);
      }
    }, 60000); // Recalculate scores every minute
  }
}
```

## Cache Warming

### Preload Common Queries

```typescript
interface WarmupQuery {
  prompt: string;
  model: string;
  priority: number;
  frequency: 'hourly' | 'daily' | 'weekly';
}

export class CacheWarmer {
  private warmupQueries: WarmupQuery[] = [];
  private cache: TTLCache<any>;
  private llmClient: any;

  constructor(cache: TTLCache<any>, llmClient: any) {
    this.cache = cache;
    this.llmClient = llmClient;
  }

  addWarmupQuery(query: WarmupQuery): void {
    this.warmupQueries.push(query);
    this.warmupQueries.sort((a, b) => b.priority - a.priority);
  }

  async warmCache(): Promise<void> {
    console.log(`Warming cache with ${this.warmupQueries.length} queries...`);

    for (const query of this.warmupQueries) {
      const key = generateCacheKey({
        prompt: query.prompt,
        model: query.model
      });

      // Skip if already cached
      if (this.cache.get(key)) {
        continue;
      }

      try {
        const response = await this.llmClient.generate({
          prompt: query.prompt,
          model: query.model
        });

        this.cache.set(key, response, this.getTTLForFrequency(query.frequency));

        // Rate limiting between requests
        await this.sleep(1000);
      } catch (error) {
        console.error(`Failed to warm cache for query: ${query.prompt}`, error);
      }
    }
  }

  startScheduledWarming(): void {
    // Warm on startup
    this.warmCache();

    // Schedule based on frequency
    setInterval(() => this.warmCache(), 3600000); // Hourly check
  }

  private getTTLForFrequency(frequency: string): number {
    switch (frequency) {
      case 'hourly': return 3600000;
      case 'daily': return 86400000;
      case 'weekly': return 604800000;
      default: return 3600000;
    }
  }

  private sleep(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}

// Example usage
const warmer = new CacheWarmer(cache, llmClient);

warmer.addWarmupQuery({
  prompt: 'What are the main features of React 19?',
  model: 'claude-3-5-sonnet-20241022',
  priority: 10,
  frequency: 'daily'
});

warmer.addWarmupQuery({
  prompt: 'Explain the differences between REST and GraphQL',
  model: 'gpt-4o',
  priority: 8,
  frequency: 'weekly'
});

warmer.startScheduledWarming();
```

## Analytics and Hit Rate Tracking

### Comprehensive Cache Metrics

```typescript
interface CacheMetrics {
  hits: number;
  misses: number;
  hitRate: number;
  averageLatency: number;
  costSavings: number;
  tokensSaved: number;
  entriesCount: number;
  memoryUsage: number;
}

export class CacheAnalytics {
  private hits = 0;
  private misses = 0;
  private latencies: number[] = [];
  private tokensSaved = 0;
  private costSavings = 0;

  private readonly COST_PER_1K_TOKENS = {
    'claude-3-5-sonnet-20241022': { input: 0.003, output: 0.015 },
    'gpt-4o': { input: 0.0025, output: 0.01 },
    'gpt-4o-mini': { input: 0.00015, output: 0.0006 }
  };

  recordHit(latency: number, tokens: number, model: string): void {
    this.hits++;
    this.latencies.push(latency);
    this.tokensSaved += tokens;

    const costPer1K = this.COST_PER_1K_TOKENS[model];
    if (costPer1K) {
      this.costSavings += (tokens / 1000) * costPer1K.output;
    }
  }

  recordMiss(): void {
    this.misses++;
  }

  getMetrics(cache: any): CacheMetrics {
    const total = this.hits + this.misses;
    const hitRate = total > 0 ? this.hits / total : 0;
    const averageLatency = this.latencies.length > 0
      ? this.latencies.reduce((a, b) => a + b, 0) / this.latencies.length
      : 0;

    return {
      hits: this.hits,
      misses: this.misses,
      hitRate,
      averageLatency,
      costSavings: this.costSavings,
      tokensSaved: this.tokensSaved,
      entriesCount: cache.size,
      memoryUsage: this.estimateMemoryUsage(cache)
    };
  }

  private estimateMemoryUsage(cache: any): number {
    // Rough estimation based on cache size
    // In production, use process.memoryUsage() or similar
    return cache.size * 2048; // Assume 2KB per entry
  }

  reset(): void {
    this.hits = 0;
    this.misses = 0;
    this.latencies = [];
    this.tokensSaved = 0;
    this.costSavings = 0;
  }

  generateReport(): string {
    const metrics = this.getMetrics({ size: 0 });

    return `
Cache Performance Report
========================
Total Requests: ${this.hits + this.misses}
Cache Hits: ${this.hits} (${(metrics.hitRate * 100).toFixed(2)}%)
Cache Misses: ${this.misses}
Average Latency: ${metrics.averageLatency.toFixed(2)}ms
Tokens Saved: ${metrics.tokensSaved.toLocaleString()}
Cost Savings: $${metrics.costSavings.toFixed(4)}
Memory Usage: ${(metrics.memoryUsage / 1024 / 1024).toFixed(2)} MB
    `.trim();
  }
}
```

## Multi-Tier Caching

### Memory + Redis + Disk

```typescript
import { createClient, RedisClientType } from 'redis';
import { promises as fs } from 'fs';
import { join } from 'path';

interface CacheTier {
  name: string;
  get(key: string): Promise<any>;
  set(key: string, value: any, ttl?: number): Promise<void>;
  delete(key: string): Promise<void>;
  has(key: string): Promise<boolean>;
}

export class MultiTierCache {
  private memoryCache: LRUCache<any>;
  private redisCache?: RedisClientType;
  private diskCachePath: string;
  private analytics: CacheAnalytics;

  constructor(options: {
    memoryCacheSize?: number;
    redisUrl?: string;
    diskCachePath?: string;
  }) {
    this.memoryCache = new LRUCache(options.memoryCacheSize || 100);
    this.diskCachePath = options.diskCachePath || '/tmp/llm-cache';
    this.analytics = new CacheAnalytics();

    if (options.redisUrl) {
      this.initializeRedis(options.redisUrl);
    }

    this.ensureDiskCacheDir();
  }

  private async initializeRedis(url: string): Promise<void> {
    this.redisCache = createClient({ url });
    await this.redisCache.connect();
  }

  private async ensureDiskCacheDir(): Promise<void> {
    try {
      await fs.mkdir(this.diskCachePath, { recursive: true });
    } catch (error) {
      console.error('Failed to create disk cache directory:', error);
    }
  }

  async get(key: string): Promise<any> {
    const startTime = Date.now();

    // L1: Memory cache
    const memoryResult = this.memoryCache.get(key);
    if (memoryResult) {
      this.analytics.recordHit(Date.now() - startTime, 0, 'memory');
      return memoryResult;
    }

    // L2: Redis cache
    if (this.redisCache) {
      const redisResult = await this.redisCache.get(key);
      if (redisResult) {
        const value = JSON.parse(redisResult);
        // Promote to memory cache
        this.memoryCache.set(key, value);
        this.analytics.recordHit(Date.now() - startTime, 0, 'redis');
        return value;
      }
    }

    // L3: Disk cache
    const diskResult = await this.getDiskCache(key);
    if (diskResult) {
      // Promote to memory and Redis
      this.memoryCache.set(key, diskResult);
      if (this.redisCache) {
        await this.redisCache.setEx(key, 3600, JSON.stringify(diskResult));
      }
      this.analytics.recordHit(Date.now() - startTime, 0, 'disk');
      return diskResult;
    }

    this.analytics.recordMiss();
    return null;
  }

  async set(key: string, value: any, ttl: number = 3600): Promise<void> {
    // Write to all tiers
    this.memoryCache.set(key, value);

    if (this.redisCache) {
      await this.redisCache.setEx(key, ttl, JSON.stringify(value));
    }

    await this.setDiskCache(key, value);
  }

  private async getDiskCache(key: string): Promise<any> {
    try {
      const filePath = join(this.diskCachePath, `${key}.json`);
      const data = await fs.readFile(filePath, 'utf-8');
      return JSON.parse(data);
    } catch {
      return null;
    }
  }

  private async setDiskCache(key: string, value: any): Promise<void> {
    try {
      const filePath = join(this.diskCachePath, `${key}.json`);
      await fs.writeFile(filePath, JSON.stringify(value), 'utf-8');
    } catch (error) {
      console.error('Failed to write disk cache:', error);
    }
  }

  async delete(key: string): Promise<void> {
    this.memoryCache.delete(key);

    if (this.redisCache) {
      await this.redisCache.del(key);
    }

    try {
      const filePath = join(this.diskCachePath, `${key}.json`);
      await fs.unlink(filePath);
    } catch {
      // Ignore if file doesn't exist
    }
  }

  getAnalytics(): CacheMetrics {
    return this.analytics.getMetrics(this.memoryCache);
  }
}
```

## Provider-Specific Caching

### Anthropic Prompt Caching

Leverage Anthropic's native prompt caching:

```typescript
import Anthropic from '@anthropic-ai/sdk';

interface AnthropicCacheConfig {
  type: 'ephemeral';
  minTokens?: number; // Minimum 1024 tokens to cache
}

export class AnthropicCachedClient {
  private client: Anthropic;
  private localCache: MultiTierCache;

  constructor(apiKey: string, localCache: MultiTierCache) {
    this.client = new Anthropic({ apiKey });
    this.localCache = localCache;
  }

  async generate(options: {
    prompt: string;
    systemPrompt?: string;
    model?: string;
    maxTokens?: number;
    enablePromptCaching?: boolean;
  }) {
    const cacheKey = generateCacheKey({
      prompt: options.prompt,
      model: options.model || 'claude-3-5-sonnet-20241022',
      systemPrompt: options.systemPrompt
    });

    // Check local cache first
    const cached = await this.localCache.get(cacheKey);
    if (cached) {
      return cached;
    }

    // Build messages with prompt caching markers
    const messages: any[] = [];

    if (options.systemPrompt && options.enablePromptCaching) {
      messages.push({
        role: 'user',
        content: [
          {
            type: 'text',
            text: options.systemPrompt,
            cache_control: { type: 'ephemeral' }
          }
        ]
      });
    }

    messages.push({
      role: 'user',
      content: options.prompt
    });

    const response = await this.client.messages.create({
      model: options.model || 'claude-3-5-sonnet-20241022',
      max_tokens: options.maxTokens || 4096,
      messages,
      system: options.systemPrompt && !options.enablePromptCaching
        ? options.systemPrompt
        : undefined
    });

    // Store in local cache
    await this.localCache.set(cacheKey, response);

    // Log cache usage
    if (response.usage) {
      console.log('Cache stats:', {
        cacheCreationTokens: response.usage.cache_creation_input_tokens || 0,
        cacheReadTokens: response.usage.cache_read_input_tokens || 0,
        inputTokens: response.usage.input_tokens,
        outputTokens: response.usage.output_tokens
      });
    }

    return response;
  }
}
```

### OpenAI Semantic Caching

```typescript
import OpenAI from 'openai';

export class OpenAICachedClient {
  private client: OpenAI;
  private semanticCache: SemanticCacheKeyGenerator;
  private localCache: MultiTierCache;

  constructor(apiKey: string, localCache: MultiTierCache) {
    this.client = new OpenAI({ apiKey });
    this.localCache = localCache;
    this.semanticCache = new SemanticCacheKeyGenerator();
  }

  async generate(options: {
    prompt: string;
    model?: string;
    temperature?: number;
    maxTokens?: number;
    useSemanticCache?: boolean;
  }) {
    // Try semantic cache for similar prompts
    if (options.useSemanticCache) {
      const { key, isExactMatch } = await this.semanticCache.generateSemanticKey(
        options.prompt,
        0.95 // 95% similarity threshold
      );

      const cached = await this.localCache.get(key);
      if (cached) {
        console.log(`Semantic cache ${isExactMatch ? 'hit' : 'near-match'}`);
        return cached;
      }
    }

    // Standard cache key
    const cacheKey = generateCacheKey({
      prompt: options.prompt,
      model: options.model || 'gpt-4o',
      temperature: options.temperature,
      maxTokens: options.maxTokens
    });

    const cached = await this.localCache.get(cacheKey);
    if (cached) {
      return cached;
    }

    const response = await this.client.chat.completions.create({
      model: options.model || 'gpt-4o',
      messages: [{ role: 'user', content: options.prompt }],
      temperature: options.temperature,
      max_tokens: options.maxTokens
    });

    await this.localCache.set(cacheKey, response);

    return response;
  }
}
```

## Best Practices

### 1. Choose the Right Strategy

- **In-Memory LRU**: Low-latency requirements, single-server deployments
- **Redis**: Distributed systems, shared cache across instances
- **Multi-Tier**: High traffic, cost-sensitive applications
- **Provider Native**: Large context windows, repetitive system prompts

### 2. Optimize Cache Keys

```typescript
// Good: Normalized and deterministic
const key = generateCacheKey({
  prompt: prompt.trim().toLowerCase(),
  model: normalizeModelName(model),
  temperature: Math.round(temperature * 1000) / 1000
});

// Bad: Non-deterministic or too specific
const key = `${prompt}_${Date.now()}_${Math.random()}`;
```

### 3. Monitor and Tune

```typescript
// Set up monitoring
setInterval(() => {
  const metrics = cache.getAnalytics();

  if (metrics.hitRate < 0.6) {
    console.warn('Low hit rate, consider increasing cache size');
  }

  if (metrics.memoryUsage > 1024 * 1024 * 1024) {
    console.warn('High memory usage, consider eviction policy');
  }

  // Log to monitoring service
  sendMetrics({
    hitRate: metrics.hitRate,
    costSavings: metrics.costSavings,
    latency: metrics.averageLatency
  });
}, 60000);
```

### 4. Handle Cache Failures Gracefully

```typescript
async function getCachedOrGenerate(prompt: string) {
  try {
    const cached = await cache.get(prompt);
    if (cached) return cached;
  } catch (error) {
    console.error('Cache error, falling back to API:', error);
  }

  // Always have fallback to direct API call
  const response = await llmClient.generate(prompt);

  // Try to cache, but don't fail if caching fails
  try {
    await cache.set(prompt, response);
  } catch (error) {
    console.error('Failed to cache response:', error);
  }

  return response;
}
```
