# Anthropic Provider-Side Caching Setup Guide

Anthropic's native prompt caching can reduce costs by up to 90% on cached content. This guide covers implementation, configuration, best practices, and integration with existing strategies.

## Overview

### What is Anthropic Provider-Side Caching?

Anthropic's prompt caching is a **server-side feature** that caches static portions of your prompts at the API level. Unlike client-side caching, this happens inside Anthropic's infrastructure and requires explicit cache control markers in your API requests.

**Key Benefits:**

- **90% cost reduction** on cached input tokens
- **No quality degradation** - exact same model outputs
- **5-minute or 1-hour TTL** options
- **Up to 4 cache breakpoints** per request
- **Automatic cache management** by Anthropic

**How It Works:**

```typescript
// Without caching: Pay full price every request
const cost = 5000 tokens × $0.003/1K = $0.015 per request

// With caching (after first request):
const cost = (5000 cached × $0.0003/1K) + (500 new × $0.003/1K) = $0.003 per request
// 80% cost reduction
```

### Requirements

- **Minimum tokens**: 1024 tokens for Sonnet/Opus, 2048-4096 for Haiku
- **Supported models**: Claude 3.5 Sonnet, Claude 3 Opus, Claude 3 Haiku, Claude 3.5 Haiku
- **Static content**: System prompts, few-shot examples, large documents
- **API integration**: You must implement Anthropic API calls yourself

## Quick Start

### Basic Usage

```typescript
import { formatMessagesForProviderCaching } from '@clarity-chat/token-optimization'
import Anthropic from '@anthropic-ai/sdk'

// Step 1: Define your messages
const messages = [
  {
    role: 'system',
    content: 'You are an expert coding assistant with deep knowledge of TypeScript, React, and Node.js. You provide clear, well-documented code examples and explain complex concepts in simple terms.',
    cacheable: true // Mark as cacheable
  },
  {
    role: 'user',
    content: 'How do I implement authentication in Next.js 15?'
  }
]

// Step 2: Format messages for Anthropic caching
const result = await formatMessagesForProviderCaching(messages, {
  provider: 'anthropic',
  enabled: true
})

console.log('Cached:', result.cached)
console.log('Estimated savings:', result.estimatedSavings)
console.log('Recommendations:', result.recommendations)

// Step 3: Make API call with formatted messages
const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY
})

const response = await anthropic.messages.create({
  model: 'claude-3-5-sonnet-20241022',
  max_tokens: 4096,
  messages: result.messages, // Use formatted messages
  system: 'System prompt if needed' // Optional separate system message
})

console.log('Response:', response.content[0].text)

// Check actual cache performance from API response
if (response.usage) {
  console.log('Cache stats:', {
    inputTokens: response.usage.input_tokens,
    cacheCreationTokens: response.usage.cache_creation_input_tokens || 0,
    cacheReadTokens: response.usage.cache_read_input_tokens || 0,
    outputTokens: response.usage.output_tokens
  })
}
```

## Core API Reference

### formatMessagesForProviderCaching

Main function for formatting messages with cache control markers.

```typescript
function formatMessagesForProviderCaching(
  messages: CacheableMessage[],
  config?: Partial<ProviderCachingConfig>,
  tokenCounter?: TokenCounter
): Promise<ProviderCachingResult>
```

**Parameters:**

- `messages`: Array of messages to format
- `config`: Configuration options (see [Configuration](#configuration))
- `tokenCounter`: Optional token counter for accurate estimates

**Returns:** `ProviderCachingResult`

```typescript
interface ProviderCachingResult {
  cached: boolean                    // Whether caching was applied
  messages: AnthropicMessage[]       // Formatted messages with cache_control
  metadata: ProviderCacheMetadata    // Cache metadata
  estimatedSavings: {
    tokens: number                   // Estimated tokens saved
    percentage: number               // Savings percentage (0-1)
    costReduction: number            // Cost reduction (0-1)
  }
  recommendations: string[]          // Optimization recommendations
}
```

**Message Format:**

```typescript
interface CacheableMessage {
  role: 'system' | 'user' | 'assistant'
  content: string | any[]
  cacheable?: boolean        // Mark as cacheable (default: auto-detect)
  cacheWeight?: number       // Priority for caching (0-1)
}
```

### Simple API Functions

For quick implementation without configuration:

```typescript
import { anthropicCache, estimateCacheSavings } from '@clarity-chat/token-optimization'

// Quick cache formatting
const result = await anthropicCache([
  { role: 'system', content: largeSystemPrompt },
  { role: 'user', content: userQuery }
])

// Check if caching will be beneficial

console.log(estimate.recommendation)
```

## Configuration Options

### Full Configuration

```typescript
import { ProviderCachingFormatter } from '@clarity-chat/token-optimization'

const formatter = new ProviderCachingFormatter({
  enabled: true,
  provider: 'anthropic',
  anthropic: {
    defaultTTL: '5m',              // '5m' or '1h'
    minCachedTokens: 1024,         // Minimum tokens to cache
    maxBreakpoints: 4,             // Max cache breakpoints (1-4)
    autoDetectBreakpoints: true    // Auto-detect optimal locations
  }
})

const result = await formatter.formatMessagesForCaching(messages)
```

### Configuration Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `enabled` | `boolean` | `true` | Enable/disable caching |
| `provider` | `'anthropic'` | `'anthropic'` | Target provider |
| `anthropic.defaultTTL` | `'5m' \| '1h'` | `'5m'` | Cache time-to-live |
| `anthropic.minCachedTokens` | `number` | `1024` | Minimum tokens before caching |
| `anthropic.maxBreakpoints` | `number` | `4` | Maximum cache breakpoints |
| `anthropic.autoDetectBreakpoints` | `boolean` | `true` | Auto-detect cache locations |

### TTL Selection Guide

```typescript
// 5-minute TTL (default): For frequently changing content
{
  defaultTTL: '5m'  // Good for: Real-time conversations, dynamic context
}

// 1-hour TTL: For stable content
{
  defaultTTL: '1h'  // Good for: System prompts, few-shot examples, documentation
}
```

## Best Practices

### 1. Content Organization

**Structure prompts for optimal caching:**

```typescript
// ✅ Good: Static content first, dynamic last
const messages = [
  { role: 'system', content: staticSystemPrompt, cacheable: true },
  { role: 'user', content: staticExamples, cacheable: true },
  { role: 'user', content: dynamicUserQuery }  // Not cached
]

// ❌ Bad: Dynamic content in the middle
const messages = [
  { role: 'system', content: staticSystemPrompt, cacheable: true },
  { role: 'user', content: dynamicUserQuery },  // Breaks cache chain
  { role: 'user', content: staticExamples, cacheable: true }
]
```

**Why?** Anthropic caching works best when static content is contiguous at the beginning of the conversation.

### 2. Token Threshold Awareness

### 4. Monitoring Cache Performance

```typescript
interface CacheMetrics {
  requests: number
  cacheWrites: number
  cacheReads: number
  totalCost: number
  savedCost: number
}

const metrics: CacheMetrics = {
  requests: 0,
  cacheWrites: 0,
  cacheReads: 0,
  totalCost: 0,
  savedCost: 0
}

async function trackCachedRequest(messages: CacheableMessage[]) {
  metrics.requests++

  const response = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 4096,
    messages: formattedMessages
  })

  const usage = response.usage

  // Track cache performance
  if (usage.cache_creation_input_tokens > 0) {
    metrics.cacheWrites++
    console.log('Cache write:', usage.cache_creation_input_tokens, 'tokens')
  }

  if (usage.cache_read_input_tokens > 0) {
    metrics.cacheReads++
    const savings = usage.cache_read_input_tokens * 0.003 * 0.9 / 1000
    metrics.savedCost += savings
    console.log('Cache hit! Saved:', savings.toFixed(4), 'USD')
  }

  // Calculate total cost
  const cost =
    (usage.input_tokens / 1000) * 0.003 +
    (usage.cache_creation_input_tokens / 1000) * 0.003 +
    (usage.cache_read_input_tokens / 1000) * 0.0003 +
    (usage.output_tokens / 1000) * 0.015

  metrics.totalCost += cost

  return response
}

// Generate daily report
function generateCacheReport() {
  const hitRate = metrics.requests > 0 ? metrics.cacheReads / metrics.requests : 0

  console.log('Cache Performance Report')
  console.log('========================')
  console.log(`Total Requests: ${metrics.requests}`)
  console.log(`Cache Writes: ${metrics.cacheWrites}`)
  console.log(`Cache Reads: ${metrics.cacheReads}`)
  console.log(`Hit Rate: ${(hitRate * 100).toFixed(1)}%`)
  console.log(`Total Cost: $${metrics.totalCost.toFixed(2)}`)
  console.log(`Cost Saved: $${metrics.savedCost.toFixed(2)}`)
  console.log(`Savings Rate: ${((metrics.savedCost / (metrics.totalCost + metrics.savedCost)) * 100).toFixed(1)}%`)
}
```

### 5. Error Handling

```typescript
import { formatMessagesForProviderCaching } from '@clarity-chat/token-optimization'
import Anthropic from '@anthropic-ai/sdk'

async function safeCachedRequest(messages: CacheableMessage[]) {
  try {
    // Format messages for caching
    const result = await formatMessagesForProviderCaching(messages, {
      provider: 'anthropic'
    })

    // Check recommendations
    if (result.recommendations.length > 0) {
      console.warn('Caching recommendations:', result.recommendations)
    }

    if (!result.cached) {
      console.warn('Caching not applied. Using standard request.')
    }

    // Make API call
    const response = await anthropic.messages.create({
      model: 'claude-3-5-sonnet-20241022',
      max_tokens: 4096,
      messages: result.messages
    })

    return response

  } catch (error) {
    if (error.message?.includes('cache_control')) {
      // Cache-specific error
      console.error('Cache control error:', error)

      // Fallback to non-cached request
      return await anthropic.messages.create({
        model: 'claude-3-5-sonnet-20241022',
        max_tokens: 4096,
        messages: messages.map(m => ({
          role: m.role === 'system' ? 'user' : m.role,
          content: m.content
        }))
      })
    }

    throw error  // Re-throw non-cache errors
  }
}
```

### ROI Calculator

```typescript
interface CacheROIInput {
  systemPromptTokens: number
  staticContextTokens: number
  avgQueryTokens: number
  avgResponseTokens: number
  requestsPerDay: number
  cacheHitRate: number  // 0-1
  model: 'claude-3-5-sonnet-20241022' | 'claude-3-opus' | 'claude-3-haiku'
}

function calculateCacheROI(input: CacheROIInput) {
  const pricing = {
    'claude-3-5-sonnet-20241022': { input: 0.003, output: 0.015, cached: 0.0003 },
    'claude-3-opus': { input: 0.015, output: 0.075, cached: 0.0015 },
    'claude-3-haiku': { input: 0.0008, output: 0.004, cached: 0.00008 }
  }

  const prices = pricing[input.model]
  const cacheableTokens = input.systemPromptTokens + input.staticContextTokens
  const newTokens = input.avgQueryTokens

  // Cost without caching
  const costWithoutCache =
    ((cacheableTokens + newTokens) / 1000) * prices.input +
    (input.avgResponseTokens / 1000) * prices.output

  // Cost with caching (weighted by hit rate)
  const cacheHitCost =
    (cacheableTokens / 1000) * prices.cached +
    (newTokens / 1000) * prices.input +
    (input.avgResponseTokens / 1000) * prices.output

  const cacheMissCost = costWithoutCache

  const avgCostWithCache =
    (cacheHitCost * input.cacheHitRate) +
    (cacheMissCost * (1 - input.cacheHitRate))

  // Calculate totals
  const dailyCostWithout = costWithoutCache * input.requestsPerDay
  const dailyCostWith = avgCostWithCache * input.requestsPerDay
  const dailySavings = dailyCostWithout - dailyCostWith

  return {
    withoutCache: {
      perRequest: costWithoutCache,
      daily: dailyCostWithout,
      monthly: dailyCostWithout * 30,
      annual: dailyCostWithout * 365
    },
    withCache: {
      perRequest: avgCostWithCache,
      daily: dailyCostWith,
      monthly: dailyCostWith * 30,
      annual: dailyCostWith * 365
    },
    savings: {
      perRequest: costWithoutCache - avgCostWithCache,
      daily: dailySavings,
      monthly: dailySavings * 30,
      annual: dailySavings * 365,
      percentage: (dailySavings / dailyCostWithout) * 100
    },
    breakeven: {
      requests: 1,  // Breaks even after first cache hit
      days: input.cacheHitRate > 0 ? 1 / input.cacheHitRate : Infinity
    }
  }
}

// Usage
const roi = calculateCacheROI({
  systemPromptTokens: 2500,
  staticContextTokens: 5000,
  avgQueryTokens: 150,
  avgResponseTokens: 400,
  requestsPerDay: 500,
  cacheHitRate: 0.85,
  model: 'claude-3-5-sonnet-20241022'
})

console.log('Annual savings:', `$${roi.savings.annual.toFixed(2)}`)
console.log('Savings rate:', `${roi.savings.percentage.toFixed(1)}%`)
```

```typescript
const tokens = counter.count(messages[0].content)

if (tokens < 1024) {
  // Solution: Consolidate or expand content
  const expandedSystemPrompt = `${originalPrompt}

Additional context and examples to reach 1024+ tokens...`

// Check 2: Ensure cacheable flag is set
messages[0].cacheable = true

// Check 3: Verify configuration
const result = await formatMessagesForProviderCaching(messages, {

    minCachedTokens: 1024,
    autoDetectBreakpoints: true
  }

```

```typescript
  timestamp: new Date().toISOString()
})

// Solution 2: Reduce cache churn
// ❌ Bad: Creating new caches per user
const userSpecificPrompt = `System prompt for user ${userId}...`

// ✅ Good: Shared cache across users
const sharedPrompt = 'System prompt...'
const userContext = { userId, preferences } // Passed separately

// Solution 3: Use appropriate caching granularity
// Cache stable, high-token content only
const shouldCache = (content: string, tokens: number) => {
  return (
    tokens >= 1024 &&
    !content.includes('${') &&  // No template variables
    !content.includes(new Date().toISOString()) &&  // No timestamps
    isStableContent(content)
  )
}
```

```typescript
import { TieredCache } from '@clarity-chat/token-optimization'
import { formatMessagesForProviderCaching } from '@clarity-chat/token-optimization'

// Layer 1: Client-side cache for complete responses
const responseCache = new TieredCache({
  l1: { maxSize: 100, ttl: 300000 },  // 5 min in-memory
  l2: { maxSize: 1000, ttl: 3600000 }  // 1 hour Redis

// Layer 2: Provider caching for partial prompts
async function getCachedResponse(query: string, context: string) {
  // Check L1: Complete response cache
  const cacheKey = `${context}:${query}`
  const cached = await responseCache.get(cacheKey)

  if (cached) {
    console.log('L1 Cache hit - complete response')
    return cached
  }

  // L2: Provider caching for static context
  const messages = [
    { role: 'system', content: staticSystemPrompt, cacheable: true },
    { role: 'user', content: context, cacheable: true },
    { role: 'user', content: query }

  })

  const response = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 4096,
    messages: formatted.messages
  })

  // Store in L1 cache for next time
  await responseCache.set(cacheKey, response, 300000)

  return response
}
```

### Combining with Compression

```typescript
import {
  formatMessagesForProviderCaching,
  compressAdaptively
} from '@clarity-chat/token-optimization'

async function optimizedRequest(
  systemPrompt: string,
  userQuery: string,
  conversationHistory: Message[]
) {
  // Step 1: Compress old conversation history
  const compressedHistory = conversationHistory.length > 5
    ? await compressAdaptively(
        JSON.stringify(conversationHistory.slice(0, -5)),
        0.3  // 70% compression on old messages
      )
    : ''

  // Step 2: Build messages with compression + caching
  const messages = [
    {
      role: 'system',
      content: systemPrompt,
      cacheable: true  // Cache full system prompt
    },
    ...(compressedHistory ? [{
      role: 'user',
      content: `Previous conversation summary: ${compressedHistory}`,
      cacheable: true  // Cache compressed history
    }] : []),
    ...conversationHistory.slice(-5),  // Keep recent messages uncompressed
    {
      role: 'user',
      content: userQuery
    }
  ]

  // Step 3: Apply provider caching
  const formatted = await formatMessagesForProviderCaching(messages, {
    provider: 'anthropic',
    anthropic: {
      defaultTTL: '5m',
      minCachedTokens: 1024
    }
  })

  // Step 4: Send to API
  const response = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 4096,
    messages: formatted.messages
  })

  console.log('Optimization stats:', {
    originalHistoryTokens: conversationHistory.length * 200,  // Estimate
    compressedTokens: countTokens(compressedHistory),
    cachedTokens: formatted.metadata.cachedTokens,
    totalSavings: formatted.estimatedSavings.percentage
  })

  return response
}
```

## Production Checklist

Before deploying provider caching to production:

- [ ] **Verify token counts** - System prompts have 1024+ tokens (2048+ for Haiku)
- [ ] **Test cache behavior** - Monitor first request (cache write) vs subsequent (cache read)
- [ ] **Set appropriate TTL** - Use 1h for stable content, 5m for dynamic
- [ ] **Implement monitoring** - Track cache hit rate, cost savings, API errors
- [ ] **Add error handling** - Fallback to non-cached requests on cache errors
- [ ] **Normalize content** - Ensure consistent formatting for cache hits
- [ ] **Document cache strategy** - Clear guidelines for team on what to cache
- [ ] **Set cost alerts** - Monitor actual costs match expected savings
- [ ] **Test edge cases** - Empty caches, TTL expiry, concurrent requests
- [ ] **Review cache metrics** - Weekly analysis of hit rates and savings
