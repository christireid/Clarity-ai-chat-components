# Animation Performance Optimization

Create smooth, performant animations that enhance UX without sacrificing performance. This guide covers GPU acceleration, frame rate optimization, and accessibility considerations.

## Core Principles

### The 60fps Target

Modern displays refresh at 60Hz, giving you **16.67ms per frame** to render:

```typescript
// Frame budget breakdown (16.67ms total)
const frameBudget = {
  javascript: 3, // ~3ms for JS execution
  styleRecalc: 2, // ~2ms for style calculations
  layout: 4, // ~4ms for layout (avoid if possible)
  paint: 5, // ~5ms for painting
  composite: 2, // ~2ms for compositing
  buffer: 0.67, // ~0.67ms buffer
}

// Performance thresholds
const performanceTargets = {
  excellent: 16.67, // 60fps
  good: 33.33, // 30fps (acceptable on lower-end devices)
  poor: 50, // 20fps (noticeable jank)
  unacceptable: 100, // 10fps (unusable)
}
```

### GPU-Accelerated Properties

Only these properties can be accelerated by the GPU:

```css
/* ✅ GPU-accelerated (compositing only) */
.gpu-accelerated {
  transform: translate3d(0, 0, 0);
  opacity: 0.5;
  filter: blur(10px);
  will-change: transform;
}

/* ❌ Forces layout/paint (avoid in animations) */
.layout-thrashing {
  width: 100px; /* Layout */
  height: 100px; /* Layout */
  top: 10px; /* Layout */
  left: 10px; /* Layout */
  margin: 10px; /* Layout */
  padding: 10px; /* Layout */
  border-width: 2px; /* Layout */
  background-color: red; /* Paint */
  color: blue; /* Paint */
  box-shadow: 0 2px 4px; /* Paint */
}
```

## GPU Acceleration Techniques

### 1. Transform-Based Animations

Use `transform` instead of position properties:

```tsx
'use client'

import { motion } from 'framer-motion'

// ❌ Bad: Triggers layout on every frame (~8-12ms per frame)
export function SlowSlideIn({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      initial={{ left: -100 }}
      animate={{ left: 0 }}
      className="relative"
    >
      {children}
    </motion.div>
  )
}

// ✅ Good: GPU-accelerated (~0.5-1ms per frame)
export function FastSlideIn({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      initial={{ x: -100 }}
      animate={{ x: 0 }}
      transition={{ type: 'spring', damping: 20, stiffness: 300 }}
    >
      {children}
    </motion.div>
  )
}

// Performance comparison
// SlowSlideIn: ~125fps budget used (8ms / 16.67ms)
// FastSlideIn: ~6% budget used (1ms / 16.67ms)
```

## Will-Change Optimization

Use `will-change` strategically to prepare GPU layers:

```tsx
'use client'

import { motion } from 'framer-motion'
import { useEffect, useRef } from 'react'

// ❌ Bad: Always-on will-change (wastes GPU memory)
function BadWillChange() {
  return (
    <div className="will-change-transform">
      {/* GPU layer always allocated */}
    </div>
  )
}

// ✅ Good: Scoped will-change with proper cleanup
export function OptimizedWillChange({ children }: { children: React.ReactNode }) {
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const element = ref.current
    if (!element) return

    // Add will-change on interaction hint
    const handlePointerEnter = () => {
      element.style.willChange = 'transform, opacity'
    }

    // Remove after animation completes
    const handleAnimationEnd = () => {
      element.style.willChange = 'auto'
    }

    element.addEventListener('pointerenter', handlePointerEnter)
    element.addEventListener('animationend', handleAnimationEnd)
    element.addEventListener('transitionend', handleAnimationEnd)

    return () => {
      element.removeEventListener('pointerenter', handlePointerEnter)
      element.removeEventListener('animationend', handleAnimationEnd)
      element.removeEventListener('transitionend', handleAnimationEnd)
    }
  }, [])

  return (
    <div ref={ref} className="transition-transform hover:scale-110">
      {children}
    </div>
  )
}

// ✅ Best: Framer Motion handles will-change automatically
export function FramerMotionWillChange({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      whileHover={{ scale: 1.1 }}
      // Framer Motion adds/removes will-change automatically
    >
      {children}
    </motion.div>
  )
}
```

### Will-Change Best Practices

```css
/* ✅ Good: Temporary, specific properties */
.animating {
  will-change: transform, opacity;
}

.animating.finished {
  will-change: auto; /* Clean up after animation */
}

/* ❌ Bad: Too broad, always-on */
.always-changing {
  will-change: transform, opacity, filter, background-color; /* Too many */
}

/* ❌ Bad: On too many elements */
.grid-item {
  will-change: transform; /* Don't use on 100+ elements */
}

/* ✅ Good: Use data attributes for state-based will-change */
[data-animating='true'] {
  will-change: transform;
}
```

## CSS vs JavaScript Animations

### When to Use CSS

```tsx
// ✅ Use CSS for simple, state-based transitions
export function SimpleButton() {
  return (
    <button className="btn-css-transition">
      Click me
    </button>
  )
}

// CSS (most performant for simple transitions)

  .btn-css-transition {
    @apply px-4 py-2 bg-blue-500 text-white rounded;
    transition: transform 200ms cubic-bezier(0.22, 1, 0.36, 1),
                background-color 200ms ease;
  }

  .btn-css-transition:hover {
    transform: translateY(-2px);
    background-color: theme('colors.blue.600');
  }

  .btn-css-transition:active {
    transform: translateY(0);
  }

  /* GPU acceleration hint */
  @media (prefers-reduced-motion: no-preference) {
    .btn-css-transition {
      transform: translate3d(0, 0, 0);
    }
  }
`

// Performance: ~0.3-0.5ms per frame, runs on compositor thread
```

### When to Use JavaScript

```tsx
'use client'

import { motion, useMotionValue, useTransform } from 'framer-motion'
import { useEffect } from 'react'

// ✅ Use JS for complex, coordinated animations
export function ParallaxCard() {
  const mouseX = useMotionValue(0)
  const mouseY = useMotionValue(0)

  // Transform mouse position to rotation
  const rotateX = useTransform(mouseY, [-300, 300], [15, -15])
  const rotateY = useTransform(mouseX, [-300, 300], [-15, 15])

  return (
    <motion.div
      style={{
        rotateX,
        rotateY,
        transformStyle: 'preserve-3d',
      }}
      onMouseMove={(e) => {
        const rect = e.currentTarget.getBoundingClientRect()
        const centerX = rect.left + rect.width / 2
        const centerY = rect.top + rect.height / 2
        mouseX.set(e.clientX - centerX)
        mouseY.set(e.clientY - centerY)
      }}
      onMouseLeave={() => {
        mouseX.set(0)
        mouseY.set(0)
      }}
      className="w-64 h-96 bg-gradient-to-br from-blue-500 to-purple-600 rounded-xl"
    >
      <div className="p-6" style={{ transform: 'translateZ(50px)' }}>
        <h3 className="text-2xl font-bold text-white">Parallax Card</h3>
        <p className="text-white/80">Move your mouse over me</p>
      </div>
    </motion.div>
  )
}

// Performance: ~1-2ms per frame, 60fps maintained
```

### Decision Matrix

```typescript
interface AnimationDecision {
  useCSS: boolean
  reason: string
  performance: string
}

function shouldUseCSSAnimation(requirements: {
  complexity: 'simple' | 'moderate' | 'complex'
  interactivity: 'static' | 'hover' | 'dynamic'
  coordination: boolean
  precision: boolean
}): AnimationDecision {
  // Use CSS for simple, non-coordinated animations
  if (
    requirements.complexity === 'simple' &&
    !requirements.coordination &&
    !requirements.precision
  ) {
    return {
      useCSS: true,
      reason: 'Simple transition, runs on compositor thread',
      performance: 'Excellent (0.3-0.5ms/frame)',
    }
  }

  // Use JS for complex, coordinated, or precise animations
  if (
    requirements.complexity === 'complex' ||
    requirements.coordination ||
    requirements.precision
  ) {
    return {
      useCSS: false,
      reason: 'Requires JavaScript for coordination/precision',
      performance: 'Good (1-3ms/frame with optimization)',
    }
  }

  // Moderate case: prefer CSS, fallback to JS if needed
  return {
    useCSS: true,
    reason: 'Start with CSS, upgrade to JS if needed',
    performance: 'Good (0.5-2ms/frame)',
  }
}

// Example usage
const buttonAnimation = shouldUseCSSAnimation({
  complexity: 'simple',
  interactivity: 'hover',
  coordination: false,
  precision: false,
})
// Result: Use CSS

const parallaxAnimation = shouldUseCSSAnimation({
  complexity: 'complex',
  interactivity: 'dynamic',
  coordination: true,
  precision: true,
})
// Result: Use JavaScript
```

## Reduced Motion Support

Respect user preferences for reduced motion:

```tsx
'use client'

import { motion, Variants, useReducedMotion } from 'framer-motion'

// Hook to conditionally disable animations
export function useAccessibleAnimation() {
  const prefersReducedMotion = useReducedMotion()

  return {
    prefersReducedMotion,
    // Reduce animation duration
    getDuration: (duration: number) =>
      prefersReducedMotion ? duration * 0.3 : duration,
    // Disable spring physics
    getTransition: (transition: any) =>
      prefersReducedMotion ? { duration: 0.1 } : transition,
  }
}

// Accessible animation variants
export function createAccessibleVariants(
  normalVariants: Variants,
  reducedVariants?: Variants
): Variants {
  const shouldReduce = typeof window !== 'undefined' &&
    window.matchMedia('(prefers-reduced-motion: reduce)').matches

  return shouldReduce ? (reducedVariants || {}) : normalVariants
}

// Example component with reduced motion support
export function AccessibleCard({ children }: { children: React.ReactNode }) {
  const { prefersReducedMotion } = useAccessibleAnimation()

  return (
    <motion.div
      whileHover={
        prefersReducedMotion
          ? { scale: 1 } // No animation
          : { scale: 1.05, y: -4 } // Full animation
      }
      transition={
        prefersReducedMotion
          ? { duration: 0 }
          : { duration: 0.2, ease: [0.22, 1, 0.36, 1] }
      }
      className="p-6 bg-white rounded-xl shadow-lg"
    >
      {children}
    </motion.div>
  )
}
```

### CSS Media Query Approach

```css
/* Default: Full animations */
.animated-element {
  transition: transform 300ms cubic-bezier(0.22, 1, 0.36, 1),
              opacity 300ms ease;
}

.animated-element:hover {
  transform: translateY(-4px) scale(1.05);
}

/* Reduced motion: Instant or minimal transitions */

  .animated-element {
    transition: transform 50ms ease,
                opacity 50ms ease;
  }

  .animated-element:hover {
    transform: translateY(-2px); /* Smaller movement */
  }
}

/* No motion: Disable completely */
@media (prefers-reduced-motion: reduce) {
  .animated-element.critical-only {
    transition: none;
  }

  .animated-element.critical-only:hover {
    transform: none;
  }
}
```

### Automatic Detection Hook

```tsx
'use client'

import { useEffect, useState } from 'react'

export function useReducedMotionState() {
  const [prefersReducedMotion, setPrefersReducedMotion] = useState(false)

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-reduced-motion: reduce)')

    setPrefersReducedMotion(mediaQuery.matches)

    const handleChange = (event: MediaQueryListEvent) => {
      setPrefersReducedMotion(event.matches)
    }

    mediaQuery.addEventListener('change', handleChange)
    return () => mediaQuery.removeEventListener('change', handleChange)
  }, [])

  return prefersReducedMotion
}

// Usage in component
export function AdaptiveAnimation() {
  const reducedMotion = useReducedMotionState()

  return (
    <motion.div
      animate={{ x: reducedMotion ? 0 : 100 }}
      transition={{ duration: reducedMotion ? 0 : 0.5 }}
    >
      Adapts to user preference
    </motion.div>
  )
```

```typescript
// Performance measurement utilities
export class AnimationProfiler {
  private startTime: number = 0
  private frames: number[] = []
  private rafId: number | null = null

  start(label: string = 'Animation') {
    this.frames = []
    this.startTime = performance.now()

    console.log(`🎬 Starting profiling: ${label}`)

    performance.mark(`${label}-start`)

    // Track frames
    const measureFrame = () => {
      const currentTime = performance.now()
      const frameDuration = currentTime - this.startTime
      this.frames.push(frameDuration)
      this.startTime = currentTime

      this.rafId = requestAnimationFrame(measureFrame)
    }

    this.rafId = requestAnimationFrame(measureFrame)
  }

  stop(label: string = 'Animation'): AnimationMetrics {
    if (this.rafId) {
      cancelAnimationFrame(this.rafId)
    }

    performance.mark(`${label}-end`)
    performance.measure(label, `${label}-start`, `${label}-end`)

    const metrics = this.calculateMetrics()

    console.log(`📊 Profiling results for ${label}:`, {
      averageFPS: metrics.averageFPS.toFixed(2),
      minFPS: metrics.minFPS.toFixed(2),
      maxFPS: metrics.maxFPS.toFixed(2),
      frameCount: metrics.frameCount,
      droppedFrames: metrics.droppedFrames,
    })

    return metrics
  }

  private calculateMetrics(): AnimationMetrics {
    const frameTimes = this.frames
    const frameCount = frameTimes.length

    if (frameCount === 0) {
      return {
        averageFPS: 0,
        minFPS: 0,
        maxFPS: 0,
        frameCount: 0,
        droppedFrames: 0,
        percentile95: 0,
      }
    }

    const fps = frameTimes.map((time) => 1000 / time)
    const averageFPS = fps.reduce((a, b) => a + b, 0) / frameCount
    const minFPS = Math.min(...fps)
    const maxFPS = Math.max(...fps)

    // Count frames slower than 60fps (16.67ms)
    const droppedFrames = frameTimes.filter((time) => time > 16.67).length

    // 95th percentile frame time
    const sorted = [...frameTimes].sort((a, b) => a - b)
    const p95Index = Math.floor(frameCount * 0.95)
    const percentile95 = sorted[p95Index]

    return {
      averageFPS,
      minFPS,
      maxFPS,
      frameCount,
      droppedFrames,
      percentile95,
    }
  }
}

interface AnimationMetrics {
  averageFPS: number
  minFPS: number
  maxFPS: number
  frameCount: number
  droppedFrames: number
  percentile95: number
}

// React hook for profiling
export function useAnimationProfiler(label: string) {
  const profilerRef = useRef<AnimationProfiler | null>(null)

  const startProfiling = useCallback(() => {
    profilerRef.current = new AnimationProfiler()
    profilerRef.current.start(label)
  }, [label])

  const stopProfiling = useCallback(() => {
    if (profilerRef.current) {
      return profilerRef.current.stop(label)
    }
    return null
  }, [label])

  return { startProfiling, stopProfiling }
}
```

```tsx
'use client'

import { useEffect, useState, useRef } from 'react'

export function FPSMonitor() {
  const [fps, setFps] = useState(60)
  const [avgFps, setAvgFps] = useState(60)
  const frameTimesRef = useRef<number[]>([])
  const lastTimeRef = useRef(performance.now())

  useEffect(() => {
    let rafId: number

    const measureFPS = () => {
      const currentTime = performance.now()
      const delta = currentTime - lastTimeRef.current
      lastTimeRef.current = currentTime

      const currentFps = 1000 / delta
      frameTimesRef.current.push(currentFps)

      // Keep last 60 frames
      if (frameTimesRef.current.length > 60) {
        frameTimesRef.current.shift()
      }

      // Calculate average
      const sum = frameTimesRef.current.reduce((a, b) => a + b, 0)
      const avg = sum / frameTimesRef.current.length

      setFps(Math.round(currentFps))
      setAvgFps(Math.round(avg))

      rafId = requestAnimationFrame(measureFPS)
    }

    rafId = requestAnimationFrame(measureFPS)

    return () => cancelAnimationFrame(rafId)
  }, [])

  const getColor = (fps: number) => {
    if (fps >= 55) return 'text-green-500'
    if (fps >= 30) return 'text-yellow-500'
    return 'text-red-500'
  }

  return (
    <div className="fixed top-4 right-4 bg-black/80 text-white p-3 rounded-lg font-mono text-sm z-50">
      <div className={getColor(fps)}>
        <div className="font-bold">FPS: {fps}</div>
        <div className="text-xs">Avg: {avgFps}</div>
      </div>
    </div>
  )
}
```

## Best Practices Summary

### Do's

1. Use `transform` and `opacity` for GPU acceleration
2. Implement `will-change` strategically (add before, remove after)
3. Respect `prefers-reduced-motion` user preference
4. Profile animations with Chrome DevTools Performance tab
5. Use CSS for simple transitions, JS for complex coordination
6. Keep animations under 16.67ms per frame (60fps)
7. Use `transform: translate3d(0,0,0)` to force GPU layer
8. Batch DOM reads and writes to avoid layout thrashing

### Don'ts

1. Don't animate `width`, `height`, `top`, `left`, `margin`
2. Don't use `will-change` on too many elements
3. Don't forget to remove `will-change` after animations
4. Don't animate during critical user tasks (form submission)
5. Don't nest too many animated elements (causes layer explosion)
6. Don't animate `box-shadow` directly (use opacity on pseudo-element)
7. Don't ignore reduced motion preferences
8. Don't animate without testing on low-end devices

## Performance Checklist

Use this checklist to optimize your animations:

- [ ] All animations use `transform` or `opacity`
- [ ] `will-change` is added/removed dynamically
- [ ] Reduced motion preference is respected
- [ ] Animations maintain 60fps on mid-range devices
- [ ] No layout thrashing (batched reads/writes)
- [ ] CSS used for simple transitions
- [ ] JavaScript used only when necessary
- [ ] Performance profiled in Chrome DevTools
- [ ] Animations tested on mobile devices
- [ ] GPU layers monitored (< 10 active layers)
- [ ] Spring physics tuned appropriately
- [ ] Loading states use efficient spinners
- [ ] No animations during form submission
- [ ] Touch gestures feel responsive (< 100ms)
