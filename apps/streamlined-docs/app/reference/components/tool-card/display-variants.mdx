# ToolCard Display Variants

The ToolCard component offers flexible layout modes for displaying AI tool execution status across different contexts. From compact inline indicators to fully expanded detail views, ToolCard adapts to your UI needs while maintaining accessibility and performance.

## Overview

ToolCard supports multiple display variants optimized for different use cases:

- **Compact Mode**: Icon and name only for space-constrained layouts
- **Expanded Mode**: Full details including parameters, results, and errors
- **Grid Layout**: Multiple tools displayed in responsive grid
- **List Layout**: Vertical stacking with consistent spacing
- **Card Display**: Elevated cards with shadows and borders
- **Inline Display**: Embedded within message flows

All variants support responsive design, status indicators, and interactive elements.

```tsx
import { ToolCard } from '@clarity-chat/react'
import type { ToolCardStatus } from '@clarity-chat/react'

interface Tool {
  id: string
  name: string
  status: ToolCardStatus
  duration?: number
  args?: Record<string, unknown>
  result?: unknown
}

interface GridToolLayoutProps {
  tools: Tool[]
  columns?: {
    sm?: number
    md?: number
    lg?: number
    xl?: number
  }
  gap?: 'sm' | 'md' | 'lg'
  showDetails?: boolean
}

export function GridToolLayout({
  tools,
  columns = { sm: 2, md: 2, lg: 3, xl: 4 },
  gap = 'md',
  showDetails = false
}: GridToolLayoutProps) {
  const gapClasses = {
    sm: 'gap-2',
    md: 'gap-3',
    lg: 'gap-4'
  }

  const gridClasses = [
    'grid',
    'grid-cols-1',
    `sm:grid-cols-${columns.sm}`,
    `md:grid-cols-${columns.md}`,
    `lg:grid-cols-${columns.lg}`,
    `xl:grid-cols-${columns.xl}`,
    gapClasses[gap]
  ].join(' ')

  return (
    <div className={gridClasses}>
      {tools.map((tool) => (
        <ToolCard
          key={tool.id}
          name={tool.name}
          status={tool.status}
          duration={tool.duration}
          args={tool.args}
          result={tool.result}
          showArgs={showDetails}
          showResult={showDetails}
          size="md"
          className="w-full h-full"
        />
      ))}
    </div>
  )
}
```
  </TabsContent>
</Tabs>

**Responsive Grid Breakpoints**:
- **Mobile** (< 640px): 1 column
- **Tablet** (640px - 1024px): 2 columns
- **Laptop** (1024px - 1280px): 3 columns
- **Desktop** (1280px+): 4 columns

**Grid Spacing**:
```tsx

  sm: 'gap-2',      // 8px
  md: 'gap-3',      // 12px
  lg: 'gap-4'       // 16px
```

### 1. Expand/Collapse

Toggle between compact and expanded states:

```tsx

function ExpandableToolCard() {
```

- ARIA: `aria-expanded` attribute
- Screen reader: "Expanded" or "Collapsed" announced

### 2. Copy Button

Copy tool arguments or results to clipboard:

```tsx
import { ToolCard } from '@clarity-chat/react'
import { useState } from 'react'

function CopyableToolCard() {
  const [copied, setCopied] = useState(false)

  const handleCopy = () => {
    const content = JSON.stringify(args, null, 2)
    navigator.clipboard.writeText(content)
    setCopied(true)
    setTimeout(() => setCopied(false), 2000)
  }

  return (
    <div className="relative">
      <ToolCard
        name="api_call"
        status="success"
        args={args}
        showArgs
        expanded={true}
      />
      <button
        onClick={handleCopy}
        className="absolute top-2 right-2 px-2 py-1 text-xs rounded bg-primary text-primary-foreground"
      >
        {copied ? 'Copied!' : 'Copy'}
      </button>
    </div>
  )
}
```

## Responsive Design

### Mobile-First Approach

All ToolCard variants use mobile-first responsive design:

```tsx
// Base styles for mobile, enhanced for larger screens
<ToolCard
  size="sm"
  className="
    w-full
    px-2 py-1.5
    text-xs
    sm:px-3 sm:py-2 sm:text-sm
    md:px-4 md:py-2.5 md:text-base
  "
/>
```

### Breakpoint Strategy

| Breakpoint | Width | ToolCard Behavior |
|------------|-------|-------------------|
| Mobile | < 640px | Single column, compact size, truncated text |
| Tablet | 640px - 1024px | 2-column grid, standard size, full text |
| Laptop | 1024px - 1280px | 3-column grid, standard size |
| Desktop | 1280px+ | 4-column grid, large size option |

### Responsive Patterns

**Pattern 1: Adaptive sizing**
```tsx
<ToolCard
  size="sm" // Base size
  className="sm:px-3 sm:py-2 md:px-4 md:py-3" // Responsive padding
/>
```

**Pattern 2: Responsive grid**
```tsx
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-2 sm:gap-3 lg:gap-4">
  {tools.map(tool => (
    <ToolCard key={tool.id} {...tool} />
  ))}
</div>
```

**Pattern 3: Hide details on mobile**
```tsx
<ToolCard
  {...props}
  showArgs={false} // Hide on all screens
  className="sm:flex-row" // Row layout on tablet+
>
  <div className="hidden sm:block">
    {/* Additional details shown on tablet+ */}
  </div>
</ToolCard>
```

## Performance Considerations

### Virtual Scrolling

For large lists (100+ tools), use virtual scrolling:

```tsx
import { useVirtualizer } from '@tanstack/react-virtual'
import { ToolCard } from '@clarity-chat/react'
import { useRef } from 'react'

function VirtualizedToolList({ tools }) {
  const parentRef = useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: tools.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 50, // Estimated height per item
  })

  return (
    <div
      ref={parentRef}
      className="h-[600px] overflow-y-auto scrollbar-hide"
    >
      <div
        style={{
          height: `${virtualizer.getTotalSize()}px`,
          position: 'relative'
        }}
      >
        {virtualizer.getVirtualItems().map((virtualItem) => (
          <div
            key={virtualItem.key}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              height: `${virtualItem.size}px`,
              transform: `translateY(${virtualItem.start}px)`
            }}
          >
            <ToolCard {...tools[virtualItem.index]} />
          </div>
        ))}
      </div>
    </div>
  )
}
```

### Memoization

Prevent unnecessary re-renders:

```tsx
import { ToolCard } from '@clarity-chat/react'
import { memo } from 'react'

const MemoizedToolCard = memo(ToolCard, (prevProps, nextProps) => {
  return (
    prevProps.status === nextProps.status &&
    prevProps.name === nextProps.name &&
    prevProps.expanded === nextProps.expanded
  )
})

export function OptimizedToolList({ tools }) {
  return (
    <div>
      {tools.map(tool => (
        <MemoizedToolCard key={tool.id} {...tool} />
      ))}
    </div>
  )
}
```

### Lazy Expansion

Load expandable content on-demand:

```tsx
import { ToolCard } from '@clarity-chat/react'
import { useState, useEffect } from 'react'

function LazyExpandToolCard({ toolId }) {
  const [expanded, setExpanded] = useState(false)
  const [details, setDetails] = useState(null)

  useEffect(() => {
    if (expanded && !details) {
      fetchToolDetails(toolId).then(setDetails)
    }
  }, [expanded, toolId])

  return (
    <ToolCard
      name="api_call"
      status="success"
      args={details?.args}
      result={details?.result}
      showArgs={!!details}
      showResult={!!details}
      expanded={expanded}
      onToggleExpand={() => setExpanded(!expanded)}
    />
  )
}
```

### Throttling Updates

Limit re-renders during rapid status changes:

```tsx
import { ToolCard } from '@clarity-chat/react'
import { useThrottle } from '@/hooks/useThrottle'

function ThrottledToolCard({ status, ...props }) {
  const throttledStatus = useThrottle(status, 200) // Update max every 200ms

  return <ToolCard status={throttledStatus} {...props} />
}
```

## Best Practices

### 1. Choose the Right Size

Match size to context:

```tsx
// Compact inline mentions
<ToolCard size="sm" />

// Standard message lists
<ToolCard size="md" />

// Detailed inspection views
<ToolCard size="lg" />
```

### 2. Limit Expandable Content

Show details only when necessary:

```tsx
// ✅ Good: Expand only with meaningful content
<ToolCard
  showArgs={args && Object.keys(args).length > 0}
  showResult={result !== null}
/>

// ❌ Bad: Always expandable
<ToolCard showArgs showResult />
```

### 3. Use Consistent Status Mapping

Maintain consistent status representation:

```tsx
// Map API statuses to ToolCard statuses
const mapStatus = (apiStatus: string): ToolCardStatus => {
  switch (apiStatus) {
    case 'queued': return 'pending'
    case 'in_progress': return 'running'
    case 'completed': return 'success'
    case 'failed': return 'error'
    default: return 'pending'
  }
}
```

### 4. Handle Errors Gracefully

Provide actionable error messages:

```tsx
<ToolCard
  status="error"
  error="API timeout (30s). Check network connection and try again."
  // Include retry button if applicable
/>
```

### 5. Optimize for Scanning

Make status immediately visible:

```tsx
// ✅ Good: Status badge always visible
<ToolCard name="tool" status="success" size="md" />

// ❌ Bad: Status hidden in expandable section
<ToolCard name="tool" status="success" expanded={false} />
// Status indicator should always be visible
```

### 6. Respect User Preferences

Support reduced motion and dark mode:

```tsx
<ToolCard
  disableAnimations={prefersReducedMotion}
  className="dark:bg-gray-800 dark:text-gray-100"
/>
```

#### Agent Activity Dashboard

```tsx
import { ToolCardList } from '@clarity-chat/react'
import { useState, useEffect } from 'react'

function AgentDashboard({ agentId }) {
  const [tools, setTools] = useState([])

  useEffect(() => {
    const ws = new WebSocket(`/api/agents/${agentId}/tools`)
    ws.onmessage = (event) => {
      const update = JSON.parse(event.data)
      setTools(prev => [...prev, update])

    return () => ws.close()

  return (
    <div className="space-y-4">
      <h2 className="text-lg font-semibold">Agent Activity</h2>
      <div className="max-h-[600px] overflow-y-auto scrollbar-hide">
        <ToolCardList
          tools={tools}
          size="md"
          gap="sm"
          showResult
          className="divide-y divide-border"
        />
      </div>
    </div>
  )
}
```

```tsx
import { ToolCard } from '@clarity-chat/react'
```
