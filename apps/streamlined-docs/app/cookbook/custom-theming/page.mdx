# Custom Theming - Brand Your Chat Interface

> Complete guide to customizing colors, typography, spacing, and animations

## Problem

The default chat interface doesn't match your brand. You need to customize colors, fonts, spacing, borders, and animations to create a cohesive design that fits your application.

## Solution

Use Clarity Chat's theming system with CSS variables, Tailwind configuration, and component-level customization to create a fully branded chat experience.

## How It Works

### 1. Theme Object Created

```tsx
const theme = {
  colors: { primary: '#6366f1' },
  typography: { fontFamily: 'Inter' },
  // ...
}
```

### 2. Theme Passed to Component

```tsx
<ClarityChatApp theme={theme} />
```

### 3. CSS Variables Generated

```css
:root {
  --clarity-primary: 99 102 241;
}
```

### 4. Components Use Variables

```tsx
<div style={{ color: 'rgb(var(--clarity-primary))' }}>
  Message
</div>
```

### With Component-Level Customization

```tsx
import {
  useClarityChat,
  MessageList,
  ChatInput,
} from '@clarity-chat/react'

export default function CustomStyledChat() {
  const { messages, append } = useClarityChat({ api: '/api/chat' })

  return (
    <div className="flex h-screen flex-col bg-gradient-to-br from-indigo-50 to-purple-50">
      <MessageList
        messages={messages}
        className="flex-1"
        messageClassName={(message) =>
          message.role === 'user'
            ? 'bg-indigo-600 text-white rounded-2xl px-4 py-3 shadow-lg'
            : 'bg-white text-gray-900 rounded-2xl px-4 py-3 shadow-md border border-gray-200'
        }
      />

      <ChatInput
        onSubmit={(content) => append({ role: 'user', content })}
        className="border-t border-gray-200 bg-white p-4"
        inputClassName="rounded-full border-2 border-indigo-300 focus:border-indigo-600 px-6 py-3"
        sendButtonClassName="rounded-full bg-gradient-to-r from-indigo-600 to-purple-600 px-6 text-white shadow-lg hover:shadow-xl"
      />
    </div>
  )
}
```

### With Custom Message Bubbles

```tsx
import { MessageList } from '@clarity-chat/react'

const CustomMessageRenderer = ({ message }) => {
  const isUser = message.role === 'user'

  return (
    <div className={`flex ${isUser ? 'justify-end' : 'justify-start'} mb-4`}>
      <div
        className={`
          max-w-[70%] rounded-2xl px-4 py-3
          ${
            isUser
              ? 'bg-gradient-to-br from-indigo-600 to-purple-600 text-white shadow-lg'
              : 'bg-white text-gray-900 shadow-md border border-gray-200'
          }
        `}
      >
        {/* Avatar */}
        {!isUser && (
          <div className="mb-2 flex items-center gap-2">
            <div className="h-6 w-6 rounded-full bg-gradient-to-br from-pink-500 to-orange-500" />
            <span className="text-xs font-medium text-gray-500">AI Assistant</span>
          </div>
        )}

        {/* Content */}
        <div className="prose prose-sm">
          {message.content}
        </div>

        {/* Timestamp */}
        <div className={`mt-1 text-xs ${isUser ? 'text-indigo-100' : 'text-gray-400'}`}>
          {new Date(message.createdAt).toLocaleTimeString()}
        </div>
      </div>
    </div>
  )
}

export default function CustomMessagesChat() {
  const { messages, append } = useClarityChat({ api: '/api/chat' })

  return (
    <div className="flex h-screen flex-col">
      <MessageList
        messages={messages}
        renderMessage={CustomMessageRenderer}
      />
      <ChatInput onSubmit={(content) => append({ role: 'user', content })} />
    </div>
  )
}
```

## Common Pitfalls

### Pitfall 1: Inconsistent Color Format

**Problem:** Mixing RGB, hex, and HSL causes issues.

**Solution:** Use consistent RGB format for CSS variables.

```css
/* ✅ Good - RGB values */
:root {
  --clarity-primary: 99 102 241;
}

/* Usage */
.element {
  color: rgb(var(--clarity-primary));
  background: rgb(var(--clarity-primary) / 0.1);
}

/* ❌ Bad - Mixed formats */
:root {
  --clarity-primary: #6366f1;
  --clarity-secondary: rgb(99, 102, 241);
}
```

### Pitfall 2: Not Handling Dark Mode

**Problem:** Theme breaks in dark mode.

**Solution:** Define dark mode variants.

```css
:root {
  --clarity-bg: 255 255 255;
  --clarity-text: 17 24 39;
}

.dark {
  --clarity-bg: 17 24 39;
  --clarity-text: 243 244 246;
}
```

### Pitfall 3: Overriding Core Styles

**Problem:** Custom styles conflict with component internals.

**Solution:** Use className props for customization.

```tsx
// ✅ Good - Use provided props
<ChatInput
  className="custom-input"
  inputClassName="custom-input-field"
/>

// ❌ Bad - Global style overrides
<ChatInput />
/* In CSS: */
.chat-input { /* Conflicts with internal styles */ }
```

### Pitfall 4: Missing Accessibility Contrast

**Problem:** Custom colors don't meet WCAG AA standards.

**Solution:** Check contrast ratios.

```tsx
// Use a contrast checker
const backgroundColor = '#6366f1'
const textColor = '#ffffff'

const contrastRatio = checkContrast(backgroundColor, textColor)
// Must be >= 4.5:1 for normal text
// Must be >= 3:1 for large text
```

### Pitfall 5: Inconsistent Spacing

**Problem:** Different spacing values across components.

**Solution:** Use theme spacing tokens.

```tsx
// ✅ Good - Consistent spacing
<div className="space-y-[var(--clarity-spacing-md)]">

// ❌ Bad - Random values
<div className="space-y-3">
<div className="space-y-4">
<div className="space-y-5">
```

```tsx

})
```
