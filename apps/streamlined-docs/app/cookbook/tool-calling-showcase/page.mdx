# Tool Calling Showcase - AI Function Execution

> Build AI agents that can call functions, query APIs, and perform actions

## Problem

Your AI assistant needs to go beyond text responses to actually do things: fetch real-time data, perform calculations, update databases, or control external systems. You need structured tool calling with proper validation, error handling, and user confirmation.

## Solution

Use OpenAI's function calling or Anthropic's tool use with Clarity Chat's tool integration system for type-safe, validated, and user-confirmed tool execution.

### Backend with Tool Execution

```tsx
// app/api/chat/route.ts
import { OpenAI } from 'openai'
import { OpenAIStream, StreamingTextResponse } from 'ai'

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY! })

// Tool implementations
const tools = {
  get_weather: async ({ location, unit = 'fahrenheit' }) => {
    // Call weather API
    const response = await fetch(
      `https://api.weather.com/v1/current?location=${location}&unit=${unit}`,
      {
        headers: { Authorization: `Bearer ${process.env.WEATHER_API_KEY}` },
      }
    )
    const data = await response.json()
    return {
      temperature: data.temp,
      condition: data.conditions,
      humidity: data.humidity,
      unit,
    }
  },

  search_products: async ({ query, category, maxPrice }) => {
    // Query product database
    const products = await db.product.findMany({
      where: {
        AND: [
          { name: { contains: query, mode: 'insensitive' } },
          category ? { category } : {},
          maxPrice ? { price: { lte: maxPrice } } : {},
        ],
      },
      take: 10,
    })
    return products
  },
}

export async function POST(req: Request) {
  const { messages } = await req.json()

  const response = await openai.chat.completions.create({
    model: 'gpt-4-turbo-preview',
    stream: true,
    messages,
    tools: [
      {
        type: 'function',
        function: {
          name: 'get_weather',
          description: 'Get the current weather in a given location',
          parameters: {
            type: 'object',
            properties: {
              location: { type: 'string' },
              unit: { type: 'string', enum: ['celsius', 'fahrenheit'] },
            },
            required: ['location'],
          },
        },
      },
      {
        type: 'function',
        function: {
          name: 'search_products',
          description: 'Search for products',
          parameters: {
            type: 'object',
            properties: {
              query: { type: 'string' },
              category: {
                type: 'string',
                enum: ['electronics', 'clothing', 'home', 'sports'],
              },
              maxPrice: { type: 'number' },
            },
            required: ['query'],
          },
        },
      },
    ],
  })

  const stream = OpenAIStream(response, {
    async experimental_onToolCall(toolCall, appendToolCallMessage) {
      // Execute the tool
      const toolName = toolCall.function.name
      const toolArgs = JSON.parse(toolCall.function.arguments)

      console.log(`Executing tool: ${toolName}`, toolArgs)

      try {
        // Call the actual tool implementation
        const result = await tools[toolName](toolArgs)

        // Send result back to OpenAI
        return appendToolCallMessage({
          tool_call_id: toolCall.id,
          function_name: toolName,
          tool_call_result: result,
        })
      } catch (error) {
        console.error(`Tool execution error: ${toolName}`, error)
        return appendToolCallMessage({
          tool_call_id: toolCall.id,
          function_name: toolName,
          tool_call_result: { error: error.message },
        })
      }
    },
  })

  return new StreamingTextResponse(stream)
}
```

## How It Works

### 1. User Makes Request

```
User: "What's the weather in San Francisco?"
```

### 2. LLM Decides to Use Tool

```json
{
  "tool_calls": [
    {
      "id": "call_123",
      "type": "function",
      "function": {
        "name": "get_weather",
        "arguments": "{\"location\":\"San Francisco, CA\",\"unit\":\"fahrenheit\"}"
      }
    }
  ]
}
```

### 3. Backend Executes Tool

```tsx
const result = await tools.get_weather({
  location: 'San Francisco, CA',
  unit: 'fahrenheit',
})
// { temperature: 72, condition: 'sunny', humidity: 65 }
```

### 4. Result Sent Back to LLM

```json
{
  "role": "tool",
  "tool_call_id": "call_123",
  "content": "{\"temperature\":72,\"condition\":\"sunny\",\"humidity\":65}"
}
```

### 5. LLM Generates Natural Response

```
Assistant: "The weather in San Francisco is currently sunny with a temperature of 72°F and 65% humidity."
```

### With User Confirmation

```tsx
import { useClarityChat, ToolApprovalDialog } from '@clarity-chat/react'

export default function ChatWithToolApproval() {
  const [pendingTool, setPendingTool] = useState(null)

  const { messages, append } = useClarityChat({
    api: '/api/chat',
    tools,
    requireApproval: true,
    onToolCall: async (toolCall) => {
      // Show approval dialog
      return new Promise((resolve) => {
        setPendingTool({ toolCall, resolve })
      })
    },
  })

  return (
    <>
      <MessageList messages={messages} />
      <ChatInput onSubmit={(content) => append({ role: 'user', content })} />

      {pendingTool && (
        <ToolApprovalDialog
          toolName={pendingTool.toolCall.function.name}
          args={JSON.parse(pendingTool.toolCall.function.arguments)}
          onApprove={() => {
            pendingTool.resolve(true)
            setPendingTool(null)
          }}
          onReject={() => {
            pendingTool.resolve(false)
            setPendingTool(null)
          }}
        />
      )}
    </>
  )
}
```

### With Parallel Tool Execution

```tsx
export async function POST(req: Request) {
  const response = await openai.chat.completions.create({
    model: 'gpt-4-turbo-preview',
    stream: true,
    messages,
    tools,
    parallel_tool_calls: true, // Execute multiple tools simultaneously
  })

  const stream = OpenAIStream(response, {
    async experimental_onToolCall(toolCalls, appendToolCallMessages) {
      // Execute all tools in parallel
      const results = await Promise.all(
        toolCalls.map(async (toolCall) => {
          const result = await tools[toolCall.function.name](
            JSON.parse(toolCall.function.arguments)
          )
          return {
            tool_call_id: toolCall.id,
            function_name: toolCall.function.name,
            tool_call_result: result,
          }
        })
      )

      return appendToolCallMessages(results)
    },
  })

  return new StreamingTextResponse(stream)
}
```

### With Anthropic Tool Use

```tsx
import Anthropic from '@anthropic-ai/sdk'
import { AnthropicStream, StreamingTextResponse } from 'ai'

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY!,
})

export async function POST(req: Request) {
  const { messages } = await req.json()

  const response = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 4096,
    stream: true,
    messages,
    tools: [
      {
        name: 'get_weather',
        description: 'Get the current weather in a given location',
        input_schema: {
          type: 'object',
          properties: {
            location: {
              type: 'string',
              description: 'The city and state, e.g. San Francisco, CA',
            },
            unit: {
              type: 'string',
              enum: ['celsius', 'fahrenheit'],
            },
          },
          required: ['location'],
        },
      },
    ],
  })

  const stream = AnthropicStream(response, {
    async experimental_onToolCall(toolCall, appendToolCallMessage) {
      const result = await tools[toolCall.name](toolCall.input)

      return appendToolCallMessage({
        tool_use_id: toolCall.id,
        content: JSON.stringify(result),
      })
    },
  })

  return new StreamingTextResponse(stream)
}
```

## Common Pitfalls

### Pitfall 1: Not Validating Tool Arguments

**Problem:** Malformed arguments crash tool execution.

**Solution:** Validate with Zod before execution.

```tsx
import { z } from 'zod'

const weatherArgsSchema = z.object({
  location: z.string().min(1),
  unit: z.enum(['celsius', 'fahrenheit']),
})

async function get_weather(args: unknown) {
  try {
    const validated = weatherArgsSchema.parse(args)
    return await fetchWeather(validated)
  } catch (error) {
    if (error instanceof z.ZodError) {
      return { error: 'Invalid arguments', details: error.errors }
    }
    throw error
  }
}
```

### Pitfall 2: Exposing Sensitive Data

**Problem:** Tool returns internal IDs or sensitive info.

**Solution:** Sanitize tool results.

```tsx
function sanitizeProductResult(product) {
  return {
    name: product.name,
    price: product.price,
    // ❌ Don't expose:
    // internalId: product.internalId,
    // cost: product.cost,
    // supplierId: product.supplierId,
  }
}
```

### Pitfall 3: No Error Handling in Tools

**Problem:** Tool errors crash the entire stream.

**Solution:** Catch and return error objects.

```tsx
async function get_weather(args) {
  try {
    const result = await fetchWeather(args)
    return { success: true, data: result }
  } catch (error) {
    console.error('Weather API error:', error)
    return {
      success: false,
      error: 'Unable to fetch weather data',
      message: error.message,
    }
  }
}
```

### Pitfall 4: Not Logging Tool Usage

**Problem:** No visibility into which tools are used.

**Solution:** Log all tool invocations.

```tsx
const stream = OpenAIStream(response, {
  async experimental_onToolCall(toolCall, appendToolCallMessage) {
    // Log for analytics
    await logToolUsage({
      toolName: toolCall.function.name,
      args: toolCall.function.arguments,
      userId: currentUser.id,
      timestamp: Date.now(),
    })

    const result = await tools[toolCall.function.name](
      JSON.parse(toolCall.function.arguments)
    )

    return appendToolCallMessage({
      tool_call_id: toolCall.id,
      function_name: toolCall.function.name,
      tool_call_result: result,
    })
  },
})
```

### Pitfall 5: Unbounded Tool Execution

**Problem:** Malicious prompts cause infinite tool loops.

**Solution:** Limit tool calls per conversation.

```tsx
let toolCallCount = 0
const MAX_TOOL_CALLS = 10

const stream = OpenAIStream(response, {
  async experimental_onToolCall(toolCall, appendToolCallMessage) {
    toolCallCount++

    if (toolCallCount > MAX_TOOL_CALLS) {
      return appendToolCallMessage({
        tool_call_id: toolCall.id,
        function_name: toolCall.function.name,
        tool_call_result: { error: 'Maximum tool calls exceeded' },
      })
    }

    // Execute tool
    const result = await tools[toolCall.function.name](
      JSON.parse(toolCall.function.arguments)
    )

    return appendToolCallMessage({
      tool_call_id: toolCall.id,
      function_name: toolCall.function.name,
      tool_call_result: result,
    })
  },
})
```
