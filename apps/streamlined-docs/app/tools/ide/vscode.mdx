# VSCode Integration Guide

Complete VSCode configuration for optimal development experience with Clarity AI Chat Components. This guide includes TypeScript IntelliSense, code snippets, auto-imports, debugging, and workspace settings.

## Quick Setup

Install recommended extensions and apply workspace settings:

```bash
# 1. Open project in VSCode
code /path/to/Clarity-ai-chat-components

# 2. Install recommended extensions
# Press Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows/Linux)
# Type: "Extensions: Show Recommended Extensions"
# Click "Install All"

# 3. Reload window
# Press Cmd+Shift+P / Ctrl+Shift+P
# Type: "Developer: Reload Window"
```

  }

## Troubleshooting

### TypeScript IntelliSense Not Working

1. **Restart TS Server**:
   - Press `Cmd+Shift+P` / `Ctrl+Shift+P`
   - Type: "TypeScript: Restart TS Server"

2. **Check Workspace TypeScript Version**:
   - Click TypeScript version in status bar
   - Select "Use Workspace Version"

3. **Clear Cache**:
   ```bash
   rm -rf node_modules/.cache
   pnpm install
   ```

### Auto-Import Not Suggesting Packages

1. **Verify Path Mappings** in `tsconfig.json`
2. **Check** `typescript.suggest.autoImports` is `true`
3. **Restart VSCode** after package installation

### ESLint Not Running

1. **Check ESLint Output Panel**:
   - View → Output → ESLint

2. **Verify ESLint Config**:
   ```bash
   pnpm eslint --print-config src/index.ts
   ```

3. **Restart ESLint Server**:
   - Press `Cmd+Shift+P` / `Ctrl+Shift+P`
   - Type: "ESLint: Restart ESLint Server"
