# CLI Tools Reference

Complete command-line reference for development, testing, building, and deployment workflows.

## Quick Reference

```bash
# Setup & Installation
pnpm install                  # Install all dependencies
pnpm build                    # Build all packages
pnpm dev                      # Start development mode

# Code Generation
pnpm generate:component       # Generate new component
pnpm generate:hook           # Generate new hook
pnpm generate:example        # Generate example app

# Testing & Quality
pnpm test                    # Run all tests
pnpm typecheck               # Type checking
pnpm lint                    # Lint code
pnpm check                   # Quick pre-commit check

# Build & Bundle
pnpm build:packages          # Build packages only
pnpm bundle-analysis         # Analyze bundle size
pnpm size                    # Check size limits

# Migration & Codemods
npx @clarity-chat/codemods   # Run codemods
pnpm docs:sync               # Sync documentation
```

## Setup Scripts

### Project Initialization

#### `pnpm install`
Install all workspace dependencies with pnpm.

**Usage:**
```bash
pnpm install
```

**Features:**
- Enforces pnpm as package manager (via `preinstall` hook)
- Installs all workspace packages
- Links local dependencies
- Sets up Git hooks via Husky

**Requirements:**
- Node.js >= 20.0.0
- pnpm >= 10.0.0

**Troubleshooting:**
```bash
# Clear cache if installation fails
pnpm store prune
rm -rf node_modules
pnpm install
```

#### `pnpm build`
Build all packages in dependency order.

**Usage:**
```bash
# Standard build
pnpm build

# Sequential build (for CI or memory constraints)
pnpm build:sequential

# Build packages only (skip apps)
pnpm build:packages

# Optimized production build
pnpm build:optimized
```

**Options:**
- `NODE_OPTIONS='--max-old-space-size=2048'` - Increased memory limit
- `--concurrency=2` - Parallel build limit
- `--filter='./packages/*'` - Filter to specific packages

**Build Order:**
1. `@clarity-chat/primitives` - Base utilities
2. `@clarity-chat/types` - Type definitions
3. `@clarity-chat/utils` - Shared utilities
4. `@clarity-chat/memory` - Memory management
5. `@clarity-chat/react` - React components
6. Apps and documentation

**Output:**
- `packages/*/dist` - Package build output
- `apps/*/.next` - Next.js build output
- `apps/*/build` - Static build output

## Code Generators

### Component Generator

Generate new React components with tests and stories.

**Usage:**
```bash
# Interactive mode
pnpm generate:component

# With flags
pnpm generate
```

**Prompts:**
1. Component name (PascalCase)
2. Target package (default: `react`)
3. Component subdirectory
4. Include tests? (default: yes)
5. Include Storybook story? (default: yes)
6. Description

**Generated Files:**
```
packages/react/src/components/{category}/{ComponentName}/
├── ComponentName.tsx         # Main component
├── ComponentName.test.tsx    # Unit tests
├── ComponentName.stories.tsx # Storybook story
└── index.ts                  # Exports
```

**Example:**
```bash
$ pnpm generate:component
✔ Component name (PascalCase): MessageBubble
✔ Which package? react
✔ Component subdirectory: message
✔ Include test file? yes
✔ Include Storybook story? yes
✔ Description: A message bubble component for chat messages

✓ Created packages/react/src/components/message/MessageBubble/
```

**Template Features:**
- TypeScript with strict typing
- React.memo for performance
- Accessibility attributes
- Responsive design classes
- Test boilerplate with @testing-library/react
- Storybook story with controls

### Hook Generator

Generate custom React hooks with tests.

**Usage:**
```bash
pnpm generate:hook
```

**Prompts:**
1. Hook name (without `use` prefix, camelCase)
2. Target package (default: `react`)
3. Include tests? (default: yes)
4. Description

**Generated Files:**
```
packages/react/src/hooks/
├── use{HookName}.ts
└── __tests__/
    └── use{HookName}.test.ts
```

**Example:**
```bash
$ pnpm generate:hook
✔ Hook name (without "use" prefix): MessageScroll
✔ Which package? react
✔ Include test file? yes
✔ Description: Auto-scroll to latest message

✓ Created packages/react/src/hooks/useMessageScroll.ts
✓ Created packages/react/src/hooks/__tests__/useMessageScroll.test.ts
```

### Context Generator

Generate React context with provider and consumer hook.

**Usage:**
```bash
pnpm generate:context
```

**Generated Files:**
```
packages/react/src/contexts/
├── {Name}Context.tsx
└── __tests__/
    └── {Name}Context.test.tsx
```

**Template Includes:**

### Example App Generator

Generate new example applications from template.

**Usage:**
```bash
# Interactive mode
pnpm generate:example --interactive

# With flags
pnpm generate:example \
  --name "streaming-chat" \
  --title "Streaming Chat" \
  --description "Real-time streaming chat example"
```

**Flags:**
- `--name` - Example slug (kebab-case)
- `--title` - Display title
- `--description` - Short description
- `--subtitle` - Header subtitle (optional)
- `--icon` - Emoji icon (default: 💬)
- `--interactive` - Interactive prompts

**Generated Structure:**
```
apps/examples/{name}/
├── src/
│   └── app/
│       ├── page.tsx          # Main example page
│       └── layout.tsx        # Example layout
├── package.json              # Dependencies
├── tsconfig.json             # TypeScript config
├── tailwind.config.ts        # Tailwind config
└── README.md                 # Example documentation
```

**Placeholders Replaced:**
- `{{EXAMPLE_NAME}}` → slug name
- `{{EXAMPLE_TITLE}}` → display title
- `{{EXAMPLE_DESCRIPTION}}` → description
- `{{EXAMPLE_ICON}}` → emoji icon
- `{{EXAMPLE_COMPONENT_NAME}}` → PascalCase component name

**Next Steps After Generation:**
```bash
cd apps/examples/{name}
pnpm install  # (from monorepo root)
pnpm dev
```

## Validators

### TypeScript Validator

Check TypeScript types across all packages.

**Usage:**
```bash
# Check all packages
pnpm typecheck

# Check specific package
pnpm --filter @clarity-chat/react typecheck

# Extended diagnostics
pnpm analyze:ts-performance

# Trace for debugging
pnpm analyze:ts-trace
```

**Options:**
- `--noEmit` - Type check without emitting files
- `--extendedDiagnostics` - Show compilation performance
- `--generateTrace trace` - Generate trace for debugging

**Common Errors:**

```typescript
// ❌ Missing type annotation
export function processMessage(msg) { }

// ✅ Proper typing
export function processMessage(msg: Message): ProcessedMessage { }

// ❌ Implicit any
const items = messages.map(m => m.content)

// ✅ Explicit typing
const items: string[] = messages.map((m: Message) => m.content)
```

## Migration Tools

### Codemod Runner

Automated code transformations for API changes.

**Usage:**
```bash
# Interactive mode
npx @clarity-chat/codemods

# Specific codemod
npx @clarity-chat/codemods migrate-markdown-renderers

# Dry run (preview changes)
npx @clarity-chat/codemods migrate-toast --dry-run

# With path
npx @clarity-chat/codemods migrate-reduced-motion ./src
```

**Available Codemods:**

#### `migrate-markdown-renderers`
Migrate from legacy markdown renderers to new API.

**Before:**
```tsx
import { MarkdownRenderer } from '@clarity-chat/react'

<MarkdownRenderer content={text} />
```

**After:**
```tsx
import { EnhancedMarkdownRenderer } from '@clarity-chat/react/extended'

<EnhancedMarkdownRenderer content={text} />
```

#### `migrate-toast`
Update toast notifications to new Sonner API.

**Before:**
```tsx
import { toast } from '@clarity-chat/react'

toast.show({ message: 'Success' })
```

**After:**
```tsx
import { toast } from 'sonner'

toast.success('Success')
```

#### `migrate-reduced-motion`
Update motion preferences to new API.

**Before:**
```tsx
import { useReducedMotion } from '@clarity-chat/react'

const shouldAnimate = !useReducedMotion()
```

**After:**
```tsx
import { useReducedMotion } from '@clarity-chat/react/extended'

const prefersReducedMotion = useReducedMotion()
```

**Options:**
- `--dry-run` - Preview changes without writing
- `--print` - Print transformed source
- `--verbose` - Detailed logging
- `--parser` - Parser to use (default: tsx)

### Theme Migration

Migrate color system from v1 to v2 (OKLCH).

**Usage:**
```bash
npx @clarity-chat/cli migrate-theme
```

**Transformations:**
```css
/* Before (RGB/HSL) */
--color-primary: rgb(59, 130, 246);
--color-background: hsl(0, 0%, 100%);

/* After (OKLCH) */
--color-primary: oklch(0.66 0.17 264);
--color-background: oklch(1 0 0);
```

**Validates:**
- Color contrast ratios (WCAG AA)
- Theme consistency
- CSS variable usage
- Dark mode parity

## Git Hooks

### Pre-commit

Runs before every commit.

**Checks:**
1. Documentation artifacts
2. Workflow file validation (actionlint)
3. Lint-staged (format, lint)

**Configuration:**
```json
// .lintstagedrc
{
  "*.{ts,tsx}": [
    "eslint --fix",
    "prettier --write"
  ],
  "*.{json,md,mdx}": [
    "prettier --write"
  ]
}
```

**Skip Hook:**
```bash
# Emergency use only
git commit --no-verify -m "message"
```

### Pre-push

Runs before pushing to remote.

**Checks:**
1. Tests pass
2. Build succeeds
3. No TypeScript errors

## Troubleshooting

### Common Issues

**Build Failures:**
```bash
# Clear cache
pnpm clean
rm -rf .turbo
pnpm install
pnpm build
```

**Type Errors:**
```bash
# Rebuild type packages first
pnpm --filter @clarity-chat/types build
pnpm --filter @clarity-chat/primitives build
pnpm typecheck
```

**Test Failures:**
```bash
# Clear test cache
pnpm test -- --clearCache
pnpm test
```

**Dependency Issues:**
```bash
# Reset lockfile
rm pnpm-lock.yaml
pnpm install
```

### Debug Mode

Enable verbose logging:

```bash
# Debug builds
DEBUG=* pnpm build

# Debug tests
DEBUG=* pnpm test
```

## Performance Tips

### Faster Builds

```bash
# Use sequential build for memory constraints
pnpm build:sequential

# Filter to changed packages only
pnpm build --filter="[HEAD^1]"

# Skip cache for fresh build
pnpm build --force
```

### Faster Tests

```bash
# Run changed tests only
pnpm test -- --changed

# Run in band (sequential)
pnpm test -- --run --maxWorkers=1

# Skip slow tests in dev
pnpm test -- --testPathIgnorePatterns=e2e
```

### Faster Installs

```bash
# Use frozen lockfile
pnpm install --frozen-lockfile

# Offline mode (use cache)
pnpm install --offline

# Shamefully hoist (faster, less strict)
pnpm install --shamefully-hoist
```
