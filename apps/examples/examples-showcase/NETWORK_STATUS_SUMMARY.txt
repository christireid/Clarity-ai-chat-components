📊 STATUS INDICATORS
───────────────────────────────────────────────────────────────
Connection States:
  ✓ Online        - Connected, all systems operational
  ✕ Offline       - No connection, queue mode active
  ↻ Reconnecting  - Attempting to restore connection
  ⚠ Slow          - Poor connection quality warning

Sync States:
  ☁ Synced   - All changes saved to server
  ↻ Syncing  - Active synchronization in progress
  ⏸ Pending  - Offline changes queued (count shown)
  ✕ Failed   - Sync error, manual retry available
