# FollowUpSuggestions Interactive Demonstrations

Complete documentation and examples for context-aware follow-up suggestions with glassmorphism design.

## Quick Start

View the demos at:
- Main Demo: `/follow-up-suggestions` 
- Advanced Demo: Import `FollowUpSuggestionsAdvanced`

## Features

### Context-Aware Suggestions
- 5 conversation scenarios
- Dynamic suggestion generation
- Confidence scoring
- Category organization

### Glassmorphism Design
- Modern translucent styling
- Backdrop blur effects
- Layered shadows
- Gradient overlays

### Smooth Animations
- Spring physics
- Staggered entrance
- Hover effects
- Selection feedback

### Interactive Controls
- Scenario switcher
- Layout toggle
- Category filters
- Confidence slider
