# Clarity Chat Examples Gallery

An interactive gallery showcasing all Clarity Chat example applications.

## Features

- **Search**: Find examples by name, description, or features
- **Category Filtering**: Filter by Core, Analytics, AI/ML, Design, Enterprise, or Industry
- **Complexity Filtering**: Filter by beginner, intermediate, or advanced difficulty
- **Featured Examples**: Highlighted hero examples for enterprise showcases

## Quick Start

```bash
pnpm install
pnpm dev
```

## Categories

| Category                 | Description                                 |
| ------------------------ | ------------------------------------------- |
| Core Chat Features       | Basic chat, streaming, message operations   |
| Analytics & Optimization | Token tracking, cost analytics, performance |
| AI/ML Features           | RAG, model comparison, code assistant       |
| Design System            | Theme builder, component showcase           |
| Enterprise Features      | AI ops dashboard, research platform         |
| Industry Solutions       | E-commerce, customer support, analytics     |
