# Integration Examples

Complete integration examples demonstrating how to use Clarity Chat components in real-world applications.

## 📚 Examples Included

### 1. Basic Chat Integration
**File:** `basic-chat-integration.tsx`

Simple chat implementation with all core features:
- Message display
- Input handling
- Streaming responses
- Error handling

### 2. Advanced Chat with All Features
**File:** `advanced-chat-integration.tsx`

Full-featured chat with:
- Enhanced markdown rendering
- Prompt suggestions
- Advanced search
- Batch export
- Message metadata
- IndexedDB persistence

### 3. Configuration Builder Example
**File:** `config-builder-example.tsx`

Demonstrates the builder pattern for configuration:
- Streaming configuration
- Accessibility settings
- Persistence options
- Markdown features

### 4. Enterprise Chat Application
**File:** `enterprise-chat.tsx`

Enterprise-grade implementation with:
- Multi-tenancy
- RBAC
- Analytics
- Error tracking
- Performance monitoring

## 🚀 Quick Start

```bash
# Navigate to example
cd examples/integration-examples

# Install dependencies
npm install

# Run example
npm run dev
```

## 📖 Usage

Each example is self-contained and demonstrates best practices for integrating Clarity Chat components into your application.
