**High Contrast Mode Implementation:**
```typescript
// ThemeProvider.tsx
React.useEffect(() => {
  const highContrastQuery = window.matchMedia('(prefers-contrast: more)')

  const updateContrastMode = () => {
    if (highContrastQuery.matches) {
      document.documentElement.classList.add('high-contrast')
      document.documentElement.style.setProperty('--primary', '214 90% 35%')
      document.documentElement.style.setProperty('--border', '216 22% 50%')
    } else {
      document.documentElement.classList.remove('high-contrast')
      document.documentElement.style.removeProperty('--primary')
      document.documentElement.style.removeProperty('--border')
    }
  }

  updateContrastMode()
  highContrastQuery.addEventListener('change', updateContrastMode)
  return () => highContrastQuery.removeEventListener('change', updateContrastMode)
}, [])
```

## Design System Standards

### Shadow Scale

Use semantic shadow utilities instead of arbitrary values:

```tsx
// ❌ AVOID: Arbitrary shadows
className="shadow-[0_4px_6px_-1px_rgb(0_0_0_/_0.1)]"

// ✅ USE: Design token shadows
className="shadow-md"
```

**Available Tokens:**
- `shadow-xs` - Subtle depth (1px elevation)
- `shadow-sm` - Light depth (2px elevation)
- `shadow-md` - Medium depth (6px elevation)
- `shadow-lg` - Large depth (10px elevation)
- `shadow-xl` - Extra large depth (20px elevation)
- `shadow-2xl` - Maximum depth (25px elevation)

---

### Text Contrast

Always use sufficient opacity for WCAG compliance:

```tsx
// ❌ BAD: Fails WCAG AA (3.2:1 contrast)
className="text-muted-foreground/50"

// ✅ GOOD: Passes WCAG AA (4.5:1 contrast)
className="text-muted-foreground/70"

// ✅ BEST: Passes WCAG AAA (7:1 contrast)
className="text-muted-foreground"
```

**Opacity Guidelines:**
- `/100` - Main content, headings (7:1+)
- `/90` - Secondary content (6:1+)
- `/80` - Tertiary content (5:1+)
- `/70` - Minimum for text (4.5:1)
- `/50` and below - ❌ Never use for text

---

### Responsive Grids

Use mobile-first responsive breakpoints:

```tsx
// ❌ AVOID: Fixed columns
<div className="grid grid-cols-5 gap-4">

// ✅ USE: Responsive breakpoints
<div className="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 gap-4">
```

**Standard Pattern:**
- Mobile (< 640px): 1-2 columns
- Tablet (640-1024px): 2-3 columns
- Desktop (> 1024px): 3-5 columns

---

### Line Length

Constrain prose content to optimal reading width:

```tsx
// ❌ AVOID: Full width (100+ characters)
<div className="prose max-w-none">

// ✅ USE: Optimal reading width (65-75 characters)
<div className="prose max-w-3xl mx-auto">
```

**Width Guidelines:**
- `max-w-3xl` (48rem) - Long-form prose
- `max-w-2xl` (42rem) - Medium content
- `max-w-xl` (36rem) - Short content

## Best Practices

### For Developers

**1. Use Design Tokens**
```tsx
// ✅ Always use design tokens
<Card className="shadow-md border-border/50 bg-background">

// ❌ Avoid arbitrary values
<Card className="shadow-[0_4px_6px_rgba(0,0,0,0.1)]">
```

**2. Implement React.memo for Lists**
```tsx
// ✅ Memoize list components
export const ItemList = React.memo(function ItemList({ items }) {
  return items.map(item => <Item key={item.id} {...item} />)
})
```

**3. Use Progressive Images**
```tsx
// ✅ Use ProgressiveImage for better performance
<ProgressiveImage src={url} alt="Description" />

// ✅ Use CORS for external images (Sprint 5)
<ProgressiveImage
  src="https://cdn.example.com/image.jpg"
  crossOrigin="anonymous"
  alt="Description"
/>

// ❌ Avoid plain img tags
<img src={url} alt="Description" />
```

**4. Ensure Accessibility**
```tsx
// ✅ Semantic HTML with proper contrast
<h4 className="text-foreground">Title</h4>

// ❌ Avoid styled divs with poor contrast
<div className="font-bold text-foreground/50">Title</div>
```

---

### For Designers

**1. Image Specifications:**
- Provide multiple resolutions (1x, 2x, 3x)
- Include low-quality placeholders (< 5KB)
- Target file sizes: < 200KB per image
- Use WebP format where possible

**2. Typography Guidelines:**
- Mobile minimum: 14px (0.875rem)
- Desktop standard: 16px (1rem)
- Line height: 1.5-1.65 for body text
- Line length: 50-75 characters

**3. Color Contrast:**
- Text on background: ≥ 4.5:1 (WCAG AA)
- Large text: ≥ 3:1 (WCAG AA)
- Enhanced contrast: ≥ 7:1 (WCAG AAA)
- Test in high contrast mode

**4. Component Design:**
- Touch targets ≥ 44px on mobile
- Design for lazy loading states
- Plan for error states
- Test at 200% zoom
