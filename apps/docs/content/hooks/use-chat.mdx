# useChat

<Callout type="warning">
**Deprecated:** This hook is maintained for backwards compatibility only.
For new projects, use [`useClarityChat`](/reference/hooks/use-clarity-chat) instead,
which provides memory integration, token optimization, and enhanced features.
</Callout>

Legacy chat hook from Clarity Chat. This hook provides basic chat functionality
but lacks the advanced features available in `useClarityChat`.

## Migration to useClarityChat

```typescript
// Before (useChat)
const { messages, sendMessage, isLoading } = useChat({
  api: '/api/chat',
})

// After (useClarityChat) - Recommended
const { messages, append, isLoading } = useClarityChat({
  api: '/api/chat',
  memory: { enabled: true },
  tokenOptimization: { enabled: true },
})
```
