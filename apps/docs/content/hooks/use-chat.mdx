# useChat

:::warning Deprecated
**This hook is deprecated.** Use [`useClarityChat`](/docs/hooks/use-clarity-chat) instead.

This hook will be removed in v3.0.
:::

## Migration Guide

```tsx
// Old (deprecated)
import { useChat } from '@clarity-chat/react'
const { messages, sendMessage, isLoading } = useChat({
  onSendMessage: async (message) => {
    // handle message
  }
})

// New (recommended)
import { useClarityChat } from '@clarity-chat/react'
const { messages, append, isLoading } = useClarityChat({
  api: '/api/chat'
})
```

### Why migrate?

- `useClarityChat` provides better TypeScript support
- `useClarityChat` includes memory integration, error handling, and more features
- `useClarityChat` follows the new API shape conventions

## Import

```typescript
import { useChat } from '@clarity-chat/react'
```

## Signature

```typescript
function useChat(options?: UseChatOptions): UseChatReturn
```

## Parameters

### UseChatOptions

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `initialMessages` | `Message[]` | No | `[]` | Initial messages to populate the chat |
| `onSendMessage` | `(message: Message, options?: { signal?: AbortSignal }) => Promise<void>` | No | - | Callback to handle sending messages |
| `api` | `string` | No | - | API endpoint URL |
| `persistMessages` | `boolean` | No | `false` | Whether to persist messages |
| `memory` | `boolean \| object` | No | - | Memory configuration |
| `autoScroll` | `boolean` | No | `true` | Whether to auto-scroll on new messages |
| `storageKey` | `string` | No | - | Local storage key for persistence |

## Returns

### UseChatReturn

| Property | Type | Description |
| --- | --- | --- |
| `messages` | `Message[]` | Current messages |
| `isLoading` | `boolean` | Whether a request is in progress |
| `error` | `Error \| undefined` | Current error, if any |
| `sendMessage` | `(content: string, options?: { signal?: AbortSignal }) => Promise<void>` | Send a message |
| `retry` | `(messageId: string, options?: { signal?: AbortSignal }) => Promise<void>` | Retry a failed message |
| `clear` | `() => void` | Clear all messages |

## Example

```tsx
import { useChat } from '@clarity-chat/react'

function LegacyChat() {
  const { messages, sendMessage, isLoading, error, clear } = useChat({
    onSendMessage: async (message) => {
      const response = await fetch('/api/chat', {
        method: 'POST',
        body: JSON.stringify({ message: message.content }),
      })
      // Handle response
    },
  })

  return (
    <div>
      {messages.map((msg) => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isLoading && <div>Loading...</div>}
      {error && <div>Error: {error.message}</div>}
      <button onClick={clear}>Clear</button>
    </div>
  )
}
```
