# useClarityChat

The primary hook for building AI chat interfaces with Clarity Chat. This is the top-level hook that wraps the enhanced chat functionality with Clarity-specific features including memory integration, transport selection, and prompt optimization.

## Import

```typescript
import { useClarityChat } from '@clarity-chat/react'
```

## Quick Start

```tsx
import { useClarityChat, ClarityChat } from '@clarity-chat/react'

function MyChat() {
  const chat = useClarityChat({
    api: '/api/chat',
  })

  return (
    <ClarityChat
      messages={chat.messages}
      isLoading={chat.isLoading}
      onSendMessage={(content) => chat.append({ role: 'user', content })}
    />
  )
}
```

## Signature

```typescript
function useClarityChat(options?: UseClarityChatOptions): UseClarityChatReturn
```

## Parameters

### UseClarityChatOptions

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `api` | `string` | Yes | - | API endpoint URL for chat requests |
| `memory` | `ClarityMemoryOptions` | No | - | Memory integration configuration |
| `transport` | `'sse' \| 'websocket'` | No | `'sse'` | Transport protocol for streaming |
| `websocket` | `ClarityWebSocketOptions` | No | - | WebSocket-specific options |
| `promptOptimization` | `ClarityPromptOptimizationOptions` | No | - | Prompt optimization configuration |
| `initialMessages` | `CoreMessage[]` | No | `[]` | Initial messages to populate the chat |
| `onFinish` | `(message: CoreMessage) => void` | No | - | Callback when a message completes |
| `onError` | `(error: Error) => void` | No | - | Callback when an error occurs |
| `transform` | `(messages: CoreMessage[]) => CoreMessage[]` | No | - | Transform messages before sending |
| `headers` | `Record<string, string>` | No | - | Custom headers for API requests |
| `body` | `Record<string, unknown>` | No | - | Additional body data for API requests |

### ClarityMemoryOptions

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `enabled` | `boolean` | No | `false` | Enable memory integration |
| `strategy` | `'sliding-window' \| 'semantic-chunks' \| 'vector-store'` | No | - | Memory retrieval strategy |
| `maxTokens` | `number` | No | - | Maximum tokens for memory context |
| `retryOnError` | `boolean` | No | `true` | Retry failed memory operations |
| `maxRetryAttempts` | `number` | No | `2` | Maximum retry attempts |
| `onMemoryError` | `(error: Error, operation: 'query' \| 'store') => void` | No | - | Error callback |

### ClarityPromptOptimizationOptions

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `enabled` | `boolean` | No | `false` | Enable prompt optimization |
| `targetTokens` | `number` | No | - | Target token budget |
| `strategy` | `'sliding-window' \| 'summarize-old' \| 'drop-low-priority' \| 'hybrid'` | No | `'hybrid'` | Optimization strategy |
| `model` | `string` | No | `'gpt-4'` | Model identifier for token counting |
| `keepRecent` | `number` | No | `2` | Number of recent messages to always keep |

## Returns

### UseClarityChatReturn

| Property | Type | Description |
| --- | --- | --- |
| `messages` | `CoreMessage[]` | Array of chat messages |
| `append` | `(message: CoreMessage) => Promise<string \| null>` | Add a message and trigger AI response |
| `isLoading` | `boolean` | Whether a request is in progress |
| `error` | `Error \| undefined` | Last error that occurred |
| `stop` | `() => void` | Stop the current streaming response |
| `reload` | `() => Promise<string \| null>` | Regenerate the last AI response |
| `setMessages` | `(messages: CoreMessage[]) => void` | Replace all messages |
| `input` | `string` | Current input value (controlled) |
| `setInput` | `(value: string) => void` | Set the input value |
| `handleSubmit` | `(e: FormEvent) => void` | Form submit handler |
| `memoryInfo` | `ClarityChatMemoryInfo` | Memory statistics and status |
| `memoryErrorInfo` | `ClarityChatErrorInfo` | Memory operation error details |
| `tokenStats` | `ClarityChatTokenStats \| undefined` | Token statistics (when optimization enabled) |

### ClarityChatMemoryInfo

| Property | Type | Description |
| --- | --- | --- |
| `memoryCount` | `number` | Number of memories stored |
| `enabled` | `boolean` | Whether memory is enabled |
| `strategy` | `string \| undefined` | Current memory strategy |
| `lastContextSummary` | `string \| undefined` | Last context added to messages |

### ClarityChatTokenStats

| Property | Type | Description |
| --- | --- | --- |
| `inputTokens` | `number` | Current input token count |
| `remainingBudget` | `number` | Remaining token budget |
| `utilization` | `number` | Budget utilization (0-1) |
| `wasOptimized` | `boolean` | Whether optimization was applied |
| `lastOptimizationReason` | `string \| undefined` | Reason for last optimization |

## Examples

### Basic Usage

```tsx
import { useClarityChat, ChatWindow } from '@clarity-chat/react'

function SimpleChat() {
  const { messages, append, isLoading } = useClarityChat({
    api: '/api/chat',
  })

  const handleSend = async (content: string) => {
    await append({ role: 'user', content })
  }

  return (
    <ChatWindow
      messages={messages}
      isLoading={isLoading}
      onSendMessage={handleSend}
    />
  )
}
```

### With Memory Integration

```tsx
import { useClarityChat, MemoryProvider } from '@clarity-chat/react'

function ChatWithMemory() {
  const chat = useClarityChat({
    api: '/api/chat',
    memory: {
      enabled: true,
      strategy: 'vector-store',
      maxTokens: 2000,
      onMemoryError: (error, operation) => {
        console.error(`Memory ${operation} failed:`, error)
      },
    },
  })

  return (
    <div>
      <ChatWindow {...chat} />
      <div>
        Memory Status: {chat.memoryInfo.enabled ? 'Active' : 'Disabled'}
        ({chat.memoryInfo.memoryCount} memories)
      </div>
    </div>
  )
}

// Wrap with MemoryProvider at app level
function App() {
  return (
    <MemoryProvider>
      <ChatWithMemory />
    </MemoryProvider>
  )
}
```

### With Prompt Optimization

```tsx
function OptimizedChat() {
  const chat = useClarityChat({
    api: '/api/chat',
    promptOptimization: {
      enabled: true,
      targetTokens: 4000,
      strategy: 'hybrid',
      model: 'gpt-4o',
      keepRecent: 3,
    },
  })

  return (
    <div>
      <ChatWindow {...chat} />
      {chat.tokenStats && (
        <div>
          Tokens: {chat.tokenStats.inputTokens} / {chat.tokenStats.remainingBudget + chat.tokenStats.inputTokens}
          ({Math.round(chat.tokenStats.utilization * 100)}% utilized)
          {chat.tokenStats.wasOptimized && ' (optimized)'}
        </div>
      )}
    </div>
  )
}
```

### With WebSocket Transport

```tsx
function WebSocketChat() {
  const chat = useClarityChat({
    api: 'wss://api.example.com/chat',
    transport: 'websocket',
    websocket: {
      autoReconnect: true,
      maxReconnectAttempts: 5,
      enableHeartbeat: true,
    },
  })

  return <ChatWindow {...chat} />
}
```

### With Custom Headers and Body

```tsx
function AuthenticatedChat({ sessionToken }: { sessionToken: string }) {
  const chat = useClarityChat({
    api: '/api/chat',
    headers: {
      'Authorization': `Bearer ${sessionToken}`,
      'X-Custom-Header': 'value',
    },
    body: {
      model: 'gpt-4o',
      temperature: 0.7,
    },
  })

  return <ChatWindow {...chat} />
}
```

### With useChatHandlers

For easier integration with ChatWindow, use the companion `useChatHandlers` hook:

```tsx
import { useClarityChat, useChatHandlers, ChatWindow } from '@clarity-chat/react'

function ChatWithHandlers() {
  const chat = useClarityChat({ api: '/api/chat' })
  const handlers = useChatHandlers({ chat })

  return (
    <ChatWindow
      messages={chat.messages}
      isLoading={chat.isLoading}
      onSendMessage={handlers.onSendMessage}
      onMessageCopy={handlers.onMessageCopy}
      onMessageFeedback={handlers.onMessageFeedback}
      onMessageRetry={handlers.onMessageRetry}
    />
  )
}
```

## Error Handling

```tsx
function ChatWithErrorHandling() {
  const chat = useClarityChat({
    api: '/api/chat',
    onError: (error) => {
      console.error('Chat error:', error)
      // Show toast notification, etc.
    },
    memory: {
      enabled: true,
      onMemoryError: (error, operation) => {
        if (operation === 'query') {
          console.warn('Memory retrieval failed, continuing without context')
        } else {
          console.warn('Memory storage failed, message not persisted')
        }
      },
    },
  })

  return (
    <div>
      <ChatWindow {...chat} />
      {chat.error && (
        <div className="error-banner">
          Error: {chat.error.message}
          <button onClick={() => chat.reload()}>Retry</button>
        </div>
      )}
      {chat.memoryErrorInfo.memoryError && (
        <div className="warning-banner">
          Memory {chat.memoryErrorInfo.memoryErrorOperation} failed
        </div>
      )}
    </div>
  )
}
```

## Architecture

`useClarityChat` sits at the top of the hook hierarchy:

```
useClarityChat (Top-level: Drop-in ready)
    └── useChatEnhanced (Mid-level: Vercel AI SDK compatible)
        └── useChat (Low-level: Raw state management)
```

- **useClarityChat**: Best for most use cases. Includes memory, transport selection, and optimization.
- **useChatEnhanced**: Use when you need Vercel AI SDK compatibility without Clarity-specific features.
- **useChat**: Use when you need complete control over the chat state.
