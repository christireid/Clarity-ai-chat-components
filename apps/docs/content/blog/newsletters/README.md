# Newsletter Versions

Condensed versions of blog posts optimized for email delivery.

## Format

Each newsletter is ~500 words (2-3 minute read) and includes:
- Key insight hook
- One practical code example
- CTA to read full post
- Plain text friendly formatting

## Usage

These are designed for email platforms like:
- Mailchimp
- ConvertKit
- Buttondown
- Substack

Copy the content and adjust formatting for your platform.
