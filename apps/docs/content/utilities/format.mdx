# Format Utilities

> Essential utilities for consistent, human-readable formatting of data across your application.

Format utilities are the most frequently used utilities in Clarity Chat, appearing in nearly every UI component that displays data. These pure functions provide canonical implementations for common formatting needs.

## When to Use

- **Display file sizes and memory usage** - File uploads, downloads, storage metrics
- **Show response times and durations** - API latency, process times, chat response timing
- **Format numbers for readability** - Message counts, user statistics, token usage
- **Display percentages and progress** - Progress bars, completion rates, utilization metrics
- **Truncate long text** - Message previews, user names, file names in limited space

## Quick Start

```typescript
import {
  formatBytes,
  formatDuration,
  formatNumber,
  formatPercent,
  truncate,
} from '@clarity-chat/utils/format'

// Display file upload size
const size = formatBytes(1536000) // "1.5 MB"

// Show API response time
const time = formatDuration(1250) // "1.3s"

// Format message count
const count = formatNumber(1234567) // "1,234,567"

// Display progress
const progress = formatPercent(0.755, 1, true) // "75.5%"

// Truncate long message preview
const preview = truncate("This is a long message...", 20) // "This is a long me..."
```

## Core Functions

### formatBytes()

**Purpose:** Convert byte counts to human-readable file sizes with appropriate units (KB, MB, GB, etc.)

**Usage:**
```typescript
formatBytes(bytes: number, decimals?: number): string
```

**Parameters:**
- `bytes` - Number of bytes to format (must be non-negative)
- `decimals` - Number of decimal places to show (default: 2)

**Returns:** Human-readable string with appropriate unit (e.g., "1.5 MB")

**Throws:** `RangeError` if bytes is negative

**Common Patterns:**

```typescript
// File upload size display
const file = uploadedFiles[0]
const sizeDisplay = formatBytes(file.size) // "2.3 MB"

// Memory usage monitoring
const memUsage = formatBytes(process.memoryUsage().heapUsed) // "45.2 MB"

// Storage quota display
const used = formatBytes(userStorage.used) // "128.5 GB"
const total = formatBytes(userStorage.total) // "500 GB"
const message = `${used} of ${total} used`

// Zero and edge cases
formatBytes(0) // "0 B"
formatBytes(1024) // "1 KB"
formatBytes(1536, 1) // "1.5 KB" (one decimal)
formatBytes(1024 ** 6) // "1024 PB" (clamped to max unit)
```

**Best Practices:**
- Always use for displaying file sizes to ensure consistency
- Use 0-1 decimals for large files (GB, TB) to avoid clutter
- Use 2 decimals for precise measurements (bytes, KB, MB)
- Handle 0 bytes explicitly in UI messaging

**See Also:** [formatSize()](#formatsize) (alias), [formatDelta()](#formatdelta)

### formatDuration()

**Purpose:** Convert millisecond durations to readable time strings with appropriate granularity

**Usage:**
```typescript
formatDuration(ms: number): string
```

**Parameters:**
- `ms` - Duration in milliseconds (must be non-negative)

**Returns:** Human-readable duration (e.g., "1.5s", "2m 30s")

**Throws:** `RangeError` if ms is negative

**Common Patterns:**

```typescript
// API response time
const startTime = Date.now()
const response = await fetch('/api/chat')
const duration = formatDuration(Date.now() - startTime) // "850ms" or "1.2s"

// Chat message generation time
const generationTime = formatDuration(message.metadata.generationTimeMs) // "3.5s"

// Timeout display
const timeoutDisplay = `Request timeout: ${formatDuration(30000)}` // "30s"

// Process duration for analytics
const processTime = formatDuration(endTime - startTime)
console.log(`Processing completed in ${processTime}`) // "2m 15s"

// Granularity examples
formatDuration(250) // "250ms" (< 1 second)
formatDuration(1500) // "1.5s" (< 1 minute)
formatDuration(90000) // "1m 30s" (>= 1 minute with seconds)
formatDuration(120000) // "2m" (even minutes, no seconds)
```

**Best Practices:**
- Use for all time measurements visible to users
- Display milliseconds for fast operations (< 1s)
- Show seconds with decimals for medium operations (1-60s)
- Use minutes and seconds for longer operations
- Consider using formatRelativeTime() for timestamps vs formatDuration() for elapsed time

**See Also:** [formatRelativeTime()](#formatrelativetime), [sleep()](/utilities/async#sleep)

### formatNumber()

**Purpose:** Format numbers with locale-aware thousand separators for improved readability

**Usage:**
```typescript
formatNumber(num: number, options?: Intl.NumberFormatOptions): string
```

**Parameters:**
- `num` - Number to format
- `options` - Optional Intl.NumberFormat options for advanced formatting

**Returns:** Formatted number string with locale-appropriate separators

**Common Patterns:**

```typescript
// Display message count
const messageCount = formatNumber(1234567) // "1,234,567" (US locale)

// Token usage display
const tokensUsed = formatNumber(15234) // "15,234"
const tokensRemaining = formatNumber(84766) // "84,766"

// User statistics
const totalUsers = formatNumber(50000) // "50,000"
const activeUsers = formatNumber(12500) // "12,500"

// Advanced formatting with options
const price = formatNumber(99.99, {
  style: 'currency',
  currency: 'USD',
}) // "$99.99"

const percentage = formatNumber(0.755, {
  style: 'percent',
  minimumFractionDigits: 1,
}) // "75.5%"

const compact = formatNumber(1234567, {
  notation: 'compact',
}) // "1.2M"

// Decimal precision
const precise = formatNumber(1234.5678, {
  maximumFractionDigits: 2,
}) // "1,234.57"
```

**Best Practices:**
- Always use for counts and metrics over 1,000
- Use options parameter for currencies, percentages, and compact notation
- Consider formatPercent() for simple percentage display
- Respect user's locale settings (function uses browser/system locale)
- For very large numbers (millions+), consider compact notation

**See Also:** [formatPercent()](#formatpercent), [formatDelta()](#formatdelta)

### formatPercent()

**Purpose:** Display percentage values with consistent formatting and optional decimal precision

**Usage:**
```typescript
formatPercent(value: number, decimals?: number, isDecimal?: boolean): string
```

**Parameters:**
- `value` - Numeric value to format (0-100 or 0-1 depending on isDecimal)
- `decimals` - Number of decimal places (default: 1)
- `isDecimal` - If true, treats value as 0-1 range; if false, 0-100 range (default: false)

**Returns:** Formatted percentage string with % symbol

**Common Patterns:**

```typescript
// Progress indicator
const uploadProgress = formatPercent(75.5) // "75.5%"
const completionRate = formatPercent(0.755, 1, true) // "75.5%" (from decimal)

// Token budget utilization
const budgetUsed = (tokensUsed / tokenBudget) * 100
const utilizationDisplay = formatPercent(budgetUsed, 0) // "82%" (no decimals)

// Success rate metrics
const successRate = successfulRequests / totalRequests
const display = formatPercent(successRate, 2, true) // "94.73%" (2 decimals)

// Cache hit rate
const hitRate = cacheHits / totalRequests
const cacheDisplay = formatPercent(hitRate, 1, true) // "87.3%"

// Different decimal precision
formatPercent(75, 0) // "75%"
formatPercent(75.5, 1) // "75.5%"
formatPercent(75.556, 2) // "75.56%"

// Decimal vs percentage input
formatPercent(75.5) // "75.5%" (value is already percentage)
formatPercent(0.755, 1, true) // "75.5%" (value is decimal, converted)
```

**Best Practices:**
- Use `isDecimal: true` when working with ratios (0-1 range)
- Use 0 decimals for approximate progress (loading bars)
- Use 1-2 decimals for precise metrics and analytics
- Consider color coding (green > 80%, yellow 60-80%, red < 60%)
- Always include % symbol for clarity

**See Also:** [formatNumber()](#formatnumber)

### truncate()

**Purpose:** Shorten long strings to fit in limited UI space while indicating truncation with ellipsis

**Usage:**
```typescript
truncate(str: string, maxLength: number, ellipsis?: string): string
```

**Parameters:**
- `str` - String to truncate
- `maxLength` - Maximum length including ellipsis (must be >= 1)
- `ellipsis` - Ellipsis string to append (default: "...")

**Returns:** Truncated string with ellipsis, or original string if within maxLength

**Throws:** `RangeError` if maxLength < 1

**Common Patterns:**

```typescript
// Message preview in list view
const messagePreview = truncate(message.content, 50)
// "This is a long message that will be truncated..."

// User display name in header
const displayName = truncate(user.fullName, 20)
// "Christopher Smith..."

// File name in upload list
const fileName = truncate(file.name, 30)
// "very-long-document-name-20..."

// Custom ellipsis
const preview = truncate(text, 25, "…") // Single char ellipsis
const custom = truncate(text, 30, " [more]") // Custom indicator

// Edge cases
truncate("Short", 10) // "Short" (no truncation needed)
truncate("Hello World", 8) // "Hello..." (exactly fits)
truncate("Hello", 2, "...") // ".." (handles maxLength < ellipsis.length)
truncate("Test", 1) // "." (minimum length)

// Responsive truncation
const isMobile = window.innerWidth < 768
const maxLen = isMobile ? 20 : 50
const title = truncate(article.title, maxLen)

// Multi-line text preview
const linePreview = text.split('\n')[0] // First line
const preview = truncate(linePreview, 100) // Then truncate
```

**Best Practices:**
- Always show full text on hover/tooltip when truncated
- Use ellipsis consistently across your app (default "..." is recommended)
- Consider responsive maxLength based on viewport size
- For multi-line truncation, use CSS `-webkit-line-clamp` instead
- Truncate before displaying, not in render loop (memoize if needed)
- Account for ellipsis length in your maxLength calculation
- Test with long words and unicode characters

**See Also:** [formatRelativeTime()](#formatrelativetime) for date truncation

## Best Practices

### Consistency
- Use these utilities everywhere you display data - avoid inline formatting
- Establish project-wide conventions (e.g., always 1 decimal for percentages)
- Create wrapper components that use these utilities internally

### Performance
- Format utilities are pure functions - safe to call frequently
- For high-frequency renders (e.g., animations), memoize formatted values:
  ```typescript
  const formattedSize = useMemo(() => formatBytes(size), [size])
  ```
- Avoid formatting in tight loops - format once, reuse the result

### Error Handling
- Always validate input before formatting to avoid RangeError:
  ```typescript
  const size = Math.max(0, bytesValue) // Ensure non-negative
  const display = formatBytes(size)
  ```
- Provide fallback for invalid data:
  ```typescript
  const display = typeof bytes === 'number'
    ? formatBytes(bytes)
    : 'Unknown size'
  ```

### Accessibility
- Provide full values in ARIA labels or tooltips:
  ```typescript
  <span title={`${bytes} bytes`}>
    {formatBytes(bytes)}
  </span>
  ```
- Use semantic HTML for numbers:
  ```typescript
  <data value={1234567}>{formatNumber(1234567)}</data>
  ```

### Internationalization
- formatNumber() respects browser locale automatically
- For explicit locale control:
  ```typescript
  const localized = num.toLocaleString('fr-FR') // French formatting
  ```
- Be mindful that formatBytes/formatDuration use English units (KB, MB, s, m)

## Real-World Examples

### Chat Message Display

```typescript
import { formatDuration, truncate } from '@clarity-chat/utils/format'

function MessageListItem({ message }) {
  const preview = truncate(message.content, 100)
  const timestamp = formatRelativeTime(new Date(message.timestamp))
  const generationTime = message.metadata?.generationTimeMs
    ? formatDuration(message.metadata.generationTimeMs)
    : null

  return (
    <div className="message-item">
      <p className="preview">{preview}</p>
      <div className="metadata">
        <span>{timestamp}</span>
        {generationTime && <span>{generationTime} to generate</span>}
      </div>
    </div>
  )
}
```

### File Upload UI

```typescript
import { formatBytes, formatPercent } from '@clarity-chat/utils/format'

function FileUploadStatus({ file, progress, bytesUploaded }) {
  const sizeDisplay = formatBytes(file.size)
  const uploadedDisplay = formatBytes(bytesUploaded)
  const progressDisplay = formatPercent(progress, 0)
  const truncatedName = truncate(file.name, 40)

  return (
    <div className="upload-status">
      <div className="file-name" title={file.name}>
        {truncatedName}
      </div>
      <div className="progress">
        <div className="progress-bar" style={{ width: `${progress}%` }} />
        <span>{progressDisplay}</span>
      </div>
      <div className="size">
        {uploadedDisplay} / {sizeDisplay}
      </div>
    </div>
  )
}
```

### Analytics Dashboard

```typescript
import { formatNumber, formatPercent, formatDuration } from '@clarity-chat/utils/format'

function AnalyticsDashboard({ metrics }) {
  return (
```
