# Cache Utilities

> High-performance in-memory caching with LRU eviction, automatic expiration, and function memoization for optimizing expensive operations.

Cache utilities provide production-ready caching implementations to reduce redundant computations, minimize API calls, and improve application performance. They offer flexible eviction strategies, automatic expiration, and seamless memoization of synchronous and async functions.

## When to Use

- **Cache expensive computations** - Complex calculations, data transformations
- **Reduce API calls** - Cache API responses to minimize network requests
- **Memoize functions** - Automatically cache function results based on arguments
- **Session management** - Store temporary data with automatic expiration
- **Rate limit protection** - Cache to avoid hitting API rate limits
- **Performance optimization** - Speed up frequently accessed data

## Quick Start

```typescript
import {
  LRUCache,
  TTLCache,
  memoize,
  memoizeAsync,
  getContentHash,
} from '@clarity-chat/utils/cache'

// LRU Cache (evicts least recently used)
const userCache = new LRUCache<string, User>(100) // Max 100 users
userCache.set('user-123', user)
const user = userCache.get('user-123')

// TTL Cache (expires after time)
const sessionCache = new TTLCache<string, Session>(60000) // 1 minute TTL
sessionCache.set('session-abc', session)

// Memoize expensive function
const cachedCompute = memoize(expensiveComputation, { maxSize: 50 })
const result = cachedCompute(input) // Cached on subsequent calls

// Memoize async function
const cachedFetch = memoizeAsync(fetchUserData, { ttlMs: 60000 })
const userData = await cachedFetch(userId)

// Generate cache keys
const hash = getContentHash('unique-content')
```

## Cache Classes

### LRUCache

**Purpose:** Least Recently Used (LRU) cache that evicts oldest accessed items when full

**Usage:**
```typescript
new LRUCache<K, V>(maxSize: number)
```

**Parameters:**
- `maxSize` - Maximum number of entries before eviction starts

**Methods:**
- `get(key)` - Get value and mark as recently used
- `set(key, value)` - Set value and evict oldest if at capacity
- `has(key)` - Check if key exists
- `delete(key)` - Remove key
- `clear()` - Remove all entries
- `size` - Current number of entries

**Common Patterns:**

```typescript
// Basic usage
const userCache = new LRUCache<string, User>(100)

userCache.set('user-123', { id: '123', name: 'Alice' })
userCache.set('user-456', { id: '456', name: 'Bob' })

const user = userCache.get('user-123')
// Returns user and moves it to end (most recently used)

if (userCache.has('user-456')) {
  console.log('User cached')
}

// API response caching
const apiCache = new LRUCache<string, APIResponse>(50)

async function fetchWithCache(endpoint: string): Promise<APIResponse> {
  if (apiCache.has(endpoint)) {
    return apiCache.get(endpoint)!
  }

  const response = await fetch(endpoint).then(r => r.json())
  apiCache.set(endpoint, response)
  return response
}

// Image cache
const imageCache = new LRUCache<string, ImageBitmap>(20)

async function loadImage(url: string): Promise<ImageBitmap> {
  const cached = imageCache.get(url)
  if (cached) return cached

  const response = await fetch(url)
  const blob = await response.blob()
  const bitmap = await createImageBitmap(blob)

  imageCache.set(url, bitmap)
  return bitmap
}

// Search results cache
const searchCache = new LRUCache<string, SearchResults>(30)

function search(query: string): SearchResults {
  const cached = searchCache.get(query)
  if (cached) return cached

  const results = performSearch(query)
  searchCache.set(query, results)
  return results
}

// Eviction behavior
const cache = new LRUCache<number, string>(3)

cache.set(1, 'one')
cache.set(2, 'two')
cache.set(3, 'three')

cache.get(1) // Marks 1 as most recently used

cache.set(4, 'four')
// Evicts 2 (least recently used), keeps 1, 3, 4

console.log(cache.has(2)) // false (evicted)
console.log(cache.has(1)) // true (recently accessed)

// Iteration
for (const [key, value] of cache.entries()) {
  console.log(key, value)
}

// Clear all
cache.clear()
console.log(cache.size) // 0
```

**Best Practices:**
- Use for caches with predictable maximum size
- Set maxSize based on memory constraints
- Accessing (get) updates recency - use has() to check without updating
- Choose LRU when frequency of access matters more than age
- Good for: API responses, search results, computed data

**See Also:** [TTLCache](#ttlcache)

### TTLCache

**Purpose:** Time-to-Live cache that automatically expires entries after specified duration

**Usage:**
```typescript
new TTLCache<K, V>(
  defaultTTLMs: number,
  options?: { autoPrune?: number | false }
)
```

**Parameters:**
- `defaultTTLMs` - Default time-to-live in milliseconds
- `options.autoPrune` - Auto-prune interval in milliseconds (optional)

**Methods:**
- `get(key)` - Get value if not expired
- `set(key, value, ttlMs?)` - Set value with optional custom TTL
- `has(key)` - Check if key exists and not expired (no side effects)
- `delete(key)` - Remove key
- `clear()` - Remove all entries
- `prune()` - Manually remove expired entries
- `getTTL(key)` - Get remaining TTL in milliseconds
- `dispose()` - Stop auto-prune and clear cache

**Common Patterns:**

```typescript
// Basic usage
const sessionCache = new TTLCache<string, Session>(60000) // 1 minute default

sessionCache.set('session-abc', session)
const session = sessionCache.get('session-abc')
// Returns undefined after 60 seconds

// Custom TTL per item
sessionCache.set('admin-session', adminSession, 3600000) // 1 hour
sessionCache.set('guest-session', guestSession, 30000) // 30 seconds

// Auto-pruning (cleans up every 30 seconds)
const cache = new TTLCache<string, Data>(
  60000,
  { autoPrune: 30000 }
)

// Always dispose when done to prevent memory leaks!
cache.dispose()

// Authentication tokens
const tokenCache = new TTLCache<string, Token>(300000) // 5 minutes

function storeToken(userId: string, token: Token) {
  tokenCache.set(userId, token)
}

function getToken(userId: string): Token | undefined {
  return tokenCache.get(userId) // Auto-expires after 5 minutes
}

// API rate limiting cache
const rateLimitCache = new TTLCache<string, number>(60000) // 1 minute window

function checkRateLimit(userId: string, maxRequests: number): boolean {
  const current = rateLimitCache.get(userId) || 0

  if (current >= maxRequests) {
    return false // Rate limited
  }

  rateLimitCache.set(userId, current + 1)
  return true
}

// Check remaining TTL
const remaining = cache.getTTL('session-abc')
if (remaining < 10000) {
  console.warn('Session expires in less than 10 seconds')
}

// Manual pruning
const removed = cache.prune()
console.log(`Removed ${removed} expired entries`)

// One-time codes (OTP)
const otpCache = new TTLCache<string, string>(300000) // 5 minutes

function generateOTP(email: string): string {
  const code = Math.random().toString(36).substring(7)
  otpCache.set(email, code)
  return code
}

function verifyOTP(email: string, code: string): boolean {
  const stored = otpCache.get(email)
  if (!stored) return false // Expired or not found

  if (stored === code) {
    otpCache.delete(email) // One-time use
    return true
  }
  return false
}

// Feature flags cache (refresh every 5 minutes)
const featureCache = new TTLCache<string, boolean>(300000)

async function isFeatureEnabled(featureName: string): Promise<boolean> {
  const cached = featureCache.get(featureName)
  if (cached !== undefined) return cached

  const enabled = await fetchFeatureFlag(featureName)
  featureCache.set(featureName, enabled)
  return enabled
}

// React example with cleanup
function useSessionCache() {
  const cacheRef = useRef<TTLCache<string, Session>>()

  if (!cacheRef.current) {
    cacheRef.current = new TTLCache(60000)
  }

  useEffect(() => {
    return () => {
      cacheRef.current?.dispose() // Cleanup on unmount
    }
  }, [])

  return cacheRef.current
}
```

**Best Practices:**
- Use when entries should expire after a time period
- Call `dispose()` when done to prevent memory leaks (especially with autoPrune)
- Set appropriate TTL based on data freshness requirements
- Use autoPrune for long-running applications (but remember to dispose)
- Use `getTTL()` to check if refresh is needed soon
- Good for: sessions, tokens, temporary data, rate limiting

**See Also:** [LRUCache](#lrucache), [memoizeAsync()](#memoizeasync)

## Memoization Functions

### memoize()

**Purpose:** Cache synchronous function results based on arguments

**Usage:**
```typescript
memoize<Args, Result>(
  fn: (...args: Args) => Result,
  options?: {
    maxSize?: number           // Default: 100 (LRU)
    ttlMs?: number             // If set, uses TTL instead of LRU
    keyFn?: (...args) => string // Custom key generation
  }
): (...args: Args) => Result
```

**Parameters:**
- `fn` - Function to memoize
- `options` - Memoization configuration

**Returns:** Memoized version of function

**Common Patterns:**

```typescript
// Basic memoization
const fibonacci = memoize((n: number): number => {
  if (n <= 1) return n
  return fibonacci(n - 1) + fibonacci(n - 2)
})

fibonacci(40) // Fast due to memoization

// Expensive computation
const expensiveCalc = memoize(
  (data: number[]) => {
    return data.reduce((sum, n) => sum + Math.sqrt(n), 0)
  },
  { maxSize: 50 }
)

// With TTL expiration
const cachedTransform = memoize(
  (input: string) => transform(input),
  { ttlMs: 60000 } // Cache for 1 minute
)

// Custom key function (important for object arguments!)
interface User {
  id: string
  name: string
  age: number
}

const computeScore = memoize(
  (user: User) => {
    return complexScoreCalculation(user)
  },
  { keyFn: (user) => user.id } // Use only ID for cache key
)

// Multiple arguments
const cachedCompute = memoize(
  (a: number, b: number, c: number) => a * b + c,
  { maxSize: 100 }
)

cachedCompute(2, 3, 4) // Computes: 10
cachedCompute(2, 3, 4) // Returns cached: 10

// Data transformations
const transformData = memoize((data: RawData) => {
  return {
    ...data,
    processed: processExpensiveOperation(data),
    score: calculateScore(data),
  }
})

// Parsing
const parseMarkdown = memoize(
  (markdown: string) => parseToHTML(markdown),
  { maxSize: 50 }
)

// React component memoization
function ExpensiveComponent({ data }: { data: ComplexData }) {
  const processedData = useMemo(
    () => memoize((d: ComplexData) => expensiveTransform(d))(data),
    [data]
  )

  return <div>{processedData.display}</div>
}

// Circular reference handling
const problematicFn = memoize((obj: any) => {
  return obj.value * 2
}, {
  // Circular objects will skip caching gracefully
  keyFn: (obj) => obj.id // Provide custom key to avoid JSON.stringify issues
})

// Cache object with circular reference fails JSON.stringify
const circular: any = { value: 10 }
circular.self = circular

problematicFn(circular) // Works with custom keyFn
```

**Limitations:**

```typescript
// ⚠️ Default key generation uses JSON.stringify
// These cases need custom keyFn:

// 1. Circular references
const obj: any = {}
obj.circular = obj
// memoize(fn) will skip caching for this argument

// 2. Functions (not serializable)
const fn = memoize((callback: () => void) => callback())
// Different functions will produce same key!

// 3. Complex objects (provide keyFn)
const compute = memoize(
  (config: Config) => doWork(config),
  { keyFn: (config) => `${config.id}:${config.version}` }
)
```

**Best Practices:**
- Use for pure functions (same input → same output)
- Provide `keyFn` for object arguments to avoid JSON.stringify issues
- Use `ttlMs` for data that becomes stale (e.g., API data)
- Use `maxSize` for data that doesn't expire (computation results)
- Don't memoize functions with side effects
- Monitor memory usage for large caches

**See Also:** [memoizeAsync()](#memoizeasync)

### memoizeAsync()

**Purpose:** Cache async function results and share in-flight requests

**Usage:**
```typescript
memoizeAsync<Args, Result>(
  fn: (...args: Args) => Promise<Result>,
  options?: {
    maxSize?: number           // Default: 100 (LRU)
    ttlMs?: number             // If set, uses TTL instead of LRU
    keyFn?: (...args) => string // Custom key generation
  }
): (...args: Args) => Promise<Result>
```

**Parameters:**
- `fn` - Async function to memoize
- `options` - Memoization configuration

**Returns:** Memoized async function

**Features:**
- Concurrent requests share the same Promise (request deduplication)
- Failed promises are removed from cache (won't cache errors)
- Supports both LRU and TTL eviction

**Common Patterns:**

```typescript
// Basic async memoization
const fetchUser = memoizeAsync(
  async (userId: string) => {
    const response = await fetch(`/api/users/${userId}`)
    return response.json()
  },
  { ttlMs: 60000 } // Cache for 1 minute
)

// Request deduplication - both calls share same Promise
const [user1, user2] = await Promise.all([
  fetchUser('123'),
  fetchUser('123'), // Doesn't make second request!
])

// API calls with custom key
const fetchWithAuth = memoizeAsync(
  async (endpoint: string, token: string) => {
    const response = await fetch(endpoint, {
      headers: { Authorization: `Bearer ${token}` },
    })
    return response.json()
  },
  { keyFn: (endpoint, token) => `${endpoint}:${token}` }
)

// Database queries
const getUserById = memoizeAsync(
  async (id: string) => {
    return await db.users.findById(id)
  },
  { ttlMs: 30000 } // Cache for 30 seconds
)

// Failed requests not cached
const cachedFetch = memoizeAsync(async (url: string) => {
  const response = await fetch(url)
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`)
  }
  return response.json()
})

try {
  await cachedFetch('/api/not-found') // Throws error
} catch (error) {
  // Error is not cached - next call will retry
  await cachedFetch('/api/not-found') // Makes new request
}

// GraphQL queries
const executeQuery = memoizeAsync(
  async (query: string, variables: Record<string, any>) => {
    return await graphqlClient.query({ query, variables })
  },
  {
    ttlMs: 60000,
    keyFn: (query, vars) => `${query}:${JSON.stringify(vars)}`,
  }
)

// React hook integration
function useUser(userId: string) {
  const [user, setUser] = useState<User | null>(null)
  const [loading, setLoading] = useState(true)

  useEffect(() => {
    const cachedFetchUser = memoizeAsync(
      (id: string) => fetch(`/api/users/${id}`).then(r => r.json()),
      { ttlMs: 60000 }
    )

    cachedFetchUser(userId)
      .then(setUser)
      .finally(() => setLoading(false))
  }, [userId])

  return { user, loading }
}

// Parallel requests with shared cache
const cachedFetch = memoizeAsync(
  (url: string) => fetch(url).then(r => r.json()),
  { ttlMs: 30000 }
)

// All 3 requests to same URL share one Promise
const results = await Promise.all([
  cachedFetch('/api/data'),
  cachedFetch('/api/data'),
  cachedFetch('/api/data'),
]) // Only 1 network request made!

// Image loading
const loadImage = memoizeAsync(
  async (url: string): Promise<ImageBitmap> => {
    const response = await fetch(url)
    const blob = await response.blob()
    return await createImageBitmap(blob)
  },
  { maxSize: 20 }
)

// Preload images
await Promise.all(imageUrls.map(url => loadImage(url)))

// Computation with external API
const computeWithAPI = memoizeAsync(
  async (input: string) => {
    const apiResult = await fetch(`/api/process?input=${input}`)
      .then(r => r.json())
    return expensiveLocalComputation(apiResult)
  },
  { ttlMs: 300000 } // Cache for 5 minutes
)
```

**Best Practices:**
- Use `ttlMs` for API responses that become stale
- Use `maxSize` for data that doesn't expire
- Provide `keyFn` for complex arguments
- Failed promises are automatically removed (won't cache errors)
- Concurrent calls automatically deduplicated
- Great for: API calls, database queries, async computations

**See Also:** [memoize()](#memoize), [TTLCache](#ttlcache)

## Helper Functions

### getContentHash()

**Purpose:** Generate fast, non-cryptographic hash for cache keys

**Usage:**
```typescript
getContentHash(content: string): string
```

**Parameters:**
- `content` - String to hash

**Returns:** 8-character hexadecimal hash

**Algorithm:** FNV-1a (fast, good distribution, browser-compatible)

**Common Patterns:**

```typescript
// Basic hashing
const hash = getContentHash('hello world')
// "b94d27b9" (consistent)

// Cache key generation
const cacheKey = getContentHash(JSON.stringify(userData))
cache.set(cacheKey, processedData)

// Content-addressable storage
const fileHash = getContentHash(fileContent)
storage.set(fileHash, fileContent)

// Unique IDs
const requestId = `req-${getContentHash(JSON.stringify(request))}`

// Fingerprinting
const fingerprint = getContentHash(
  `${userAgent}:${screenResolution}:${timezone}`
)
```

**Best Practices:**
- Use for cache keys, not security (not cryptographically secure)
- Fast and browser-compatible (no Node.js dependencies)
- Good distribution for cache keys
- Consistent output for same input

**See Also:** [createCacheKey()](#createcachekey)

## Best Practices

### Choosing Cache Strategy

**Use LRUCache When:**
- Fixed memory budget
- Access frequency matters (popular items stay cached)
- No natural expiration time
- Examples: Search results, computed data, UI state

**Use TTLCache When:**
- Data becomes stale over time
- Time-based expiration needed
- Examples: API responses, sessions, tokens, rate limits

**Use memoize When:**
- Pure functions (no side effects)
- Expensive computations
- Same inputs always produce same outputs
- Examples: Data transformations, calculations, parsing

**Use memoizeAsync When:**
- Async operations (API calls, database queries)
- Need request deduplication
- Examples: Fetch calls, GraphQL queries, image loading

### Memory Management

```typescript
// Set appropriate sizes
const smallCache = new LRUCache<string, Data>(50)    // UI components
const mediumCache = new LRUCache<string, Data>(200)  // API responses
const largeCache = new LRUCache<string, Data>(1000)  // Static assets

// Monitor size
console.log(`Cache usage: ${cache.size}/${maxSize}`)

// Clear when needed
window.addEventListener('memorywarning', () => {
  cache.clear()
})

// Dispose TTL caches
const cache = new TTLCache(60000, { autoPrune: 30000 })
// ... use cache ...
cache.dispose() // Always dispose!
```

### Error Handling

```typescript
// memoizeAsync removes failed promises
const cachedFetch = memoizeAsync(async (url: string) => {
  const response = await fetch(url)
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`)
  }
  return response.json()
})

// Errors not cached - will retry
try {
  await cachedFetch('/api/data')
} catch (error) {
  // Next call will try again (not cached)
}
```

### Custom Key Functions

```typescript
// ✅ Good: Custom key for objects
const cached = memoize(
  (user: User) => computeScore(user),
  { keyFn: (user) => user.id }
)

// ❌ Bad: Default JSON.stringify for objects
const cached = memoize((user: User) => computeScore(user))
// Inefficient and fails on circular references

// ✅ Good: Composite keys
const cached = memoizeAsync(
  (endpoint: string, params: Params) => fetchData(endpoint, params),
  { keyFn: (endpoint, params) => `${endpoint}:${params.id}` }
)
```

## Real-World Examples

### API Client with Caching

```typescript
import { memoizeAsync, TTLCache } from '@clarity-chat/utils/cache'

class APICacheClient {
  private cache = new TTLCache<string, any>(60000) // 1 minute default

  async get<T>(endpoint: string, ttlMs?: number): Promise<T> {
    const cached = this.cache.get(endpoint)
    if (cached) return cached

    const response = await fetch(endpoint)
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`)
    }

    const data = await response.json()
    this.cache.set(endpoint, data, ttlMs)
    return data
  }

  clearCache() {
    this.cache.clear()
  }

  dispose() {
    this.cache.dispose()
  }
}

// Usage
const api = new APIClient()
const users = await api.get('/api/users', 30000) // Cache for 30s
```

### React Component with Memoization

```typescript
import { memoize } from '@clarity-chat/utils/cache'
import { useMemo } from 'react'

interface Props {
  data: ComplexData[]
  filters: Filters
}

function DataTable({ data, filters }: Props) {
  // Memoize expensive filtering
  const filterData = useMemo(
    () => memoize(
      (items: ComplexData[], f: Filters) => {
        return items.filter(item =>
          Object.entries(f).every(([key, value]) =>
            item[key] === value
          )
        )
      },
      { maxSize: 10 }
    ),
    []
  )

  const filtered = filterData(data, filters)

  return (
    <table>
      {filtered.map(item => (
        <tr key={item.id}>
          <td>{item.name}</td>
        </tr>
      ))}
    </table>
  )
}
```

### Rate Limiting with TTL Cache

```typescript
import { TTLCache } from '@clarity-chat/utils/cache'

class RateLimiter {
  private cache: TTLCache<string, number>
  private maxRequests: number

  constructor(maxRequests: number, windowMs: number) {
    this.maxRequests = maxRequests
    this.cache = new TTLCache(windowMs)
  }

  checkLimit(userId: string): boolean {
    const current = this.cache.get(userId) || 0

    if (current >= this.maxRequests) {
      return false // Rate limited
    }

    this.cache.set(userId, current + 1)
    return true
  }

  getRemainingRequests(userId: string): number {
    const current = this.cache.get(userId) || 0
    return Math.max(0, this.maxRequests - current)
  }

  dispose() {
    this.cache.dispose()
  }
}

// Usage: 100 requests per minute
const limiter = new RateLimiter(100, 60000)

if (limiter.checkLimit(userId)) {
  await processRequest()
} else {
  throw new Error('Rate limit exceeded')
}
```
