# Config Management

> Type-safe configuration validation with comprehensive schema definition, automatic defaults, and detailed error reporting.

Config management utilities provide a robust system for validating application configuration with type safety, automatic defaults, range checking, pattern matching, and custom validation rules. Perfect for validating environment variables, user settings, and API configurations.

## When to Use

- **Validate environment variables** - Type-safe .env file validation
- **User settings/preferences** - Validate and merge user configuration
- **API configuration** - Validate API keys, timeouts, retry settings
- **Feature flags** - Validate boolean feature toggles
- **Plugin configuration** - Validate third-party plugin settings
- **Application initialization** - Ensure all required config before startup

## Quick Start

```typescript
import { createConfigManager } from '@clarity-chat/utils/config-manager'

// Define configuration schema
const schema = {
  apiKey: { type: 'string', required: true },
  timeout: { type: 'number', default: 5000, min: 1000, max: 60000 },
  retries: { type: 'number', default: 3, min: 0, max: 10 },
  debug: { type: 'boolean', default: false },
}

// Create manager
const configManager = createConfigManager(schema)

// Validate configuration
const result = configManager.validate(userConfig)

if (!result.success) {
  console.error('Invalid configuration:', result.errors)
  process.exit(1)
}

const config = result.data
// config is now fully typed and validated!
```

## Core Functions

### createConfigManager()

**Purpose:** Create a type-safe configuration manager with validation, defaults, and schema introspection

**Usage:**
```typescript
createConfigManager<T extends Record<string, unknown>>(
  schema: ConfigSchema<T>
): ConfigManager<T>
```

**Parameters:**
- `schema` - Configuration schema defining all fields

**Returns:** ConfigManager instance with methods:
- `validate(config)` - Validate configuration against schema
- `getDefaults()` - Get all default values from schema
- `merge(partial)` - Merge partial config with defaults and validate
- `getSchema()` - Get the schema definition

**Schema Options:**

```typescript
interface ConfigFieldSchema<T> {
  type: 'string' | 'number' | 'boolean' | 'object' | 'array'
  required?: boolean              // Field is mandatory
  default?: T                     // Default value if not provided
  min?: number                    // Minimum value (numbers only)
  max?: number                    // Maximum value (numbers only)
  pattern?: RegExp                // Regex pattern (strings only)
  enum?: T[]                      // Allowed values (any type)
  validate?: (value: unknown) => boolean  // Custom validation
  transform?: (value: unknown) => T       // Transform before validation
}
```

**Common Patterns:**

```typescript
// Basic configuration
const configManager = createConfigManager({
  port: { type: 'number', default: 3000, min: 1024, max: 65535 },
  host: { type: 'string', default: 'localhost' },
})

const result = configManager.validate({ port: 8080 })
// result.data = { port: 8080, host: 'localhost' }

// Required fields
const apiConfig = createConfigManager({
  apiKey: { type: 'string', required: true },
  baseUrl: { type: 'string', required: true },
  timeout: { type: 'number', default: 5000 },
})

const result = apiConfig.validate({})
// result.success = false
// result.errors = ["Field 'apiKey' is required", "Field 'baseUrl' is required"]

// Environment variable validation
const envSchema = createConfigManager({
  NODE_ENV: {
    type: 'string',
    default: 'development',
    enum: ['development', 'production', 'test'],
  },
  API_KEY: {
    type: 'string',
    required: true,
    pattern: /^[a-zA-Z0-9_-]{32,}$/,
  },
  PORT: {
    type: 'number',
    default: 3000,
    transform: (value) => parseInt(String(value), 10),
  },
})

const config = envSchema.validate(process.env)

// Pattern matching
const emailConfig = createConfigManager({
  email: {
    type: 'string',
    required: true,
    pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
  },
  name: {
    type: 'string',
    pattern: /^[a-zA-Z\s]{2,50}$/,
  },
})

// Custom validation
const advancedConfig = createConfigManager({
  password: {
    type: 'string',
    required: true,
    validate: (value) => {
      const pwd = String(value)
      return pwd.length >= 8 &&
             /[A-Z]/.test(pwd) &&
             /[a-z]/.test(pwd) &&
             /[0-9]/.test(pwd)
    },
  },
  age: {
    type: 'number',
    validate: (value) => Number(value) >= 18 && Number(value) <= 120,
  },
})

// Transform before validation
const transformConfig = createConfigManager({
  enabled: {
    type: 'boolean',
    transform: (value) => {
      if (value === 'true') return true
      if (value === 'false') return false
      return Boolean(value)
    },
  },
  tags: {
    type: 'array',
    transform: (value) => {
      if (typeof value === 'string') {
        return value.split(',').map(s => s.trim())
      }
      return value
    },
  },
})

// Get defaults
const defaults = configManager.getDefaults()
// { port: 3000, host: 'localhost', timeout: 5000 }

// Merge with defaults
const merged = configManager.merge({ port: 8080 })
// Validates and returns: { port: 8080, host: 'localhost', timeout: 5000 }

// Unknown field detection
const result = configManager.validate({
  port: 3000,
  unknownField: 'value',
})
// result.success = false
// result.errors = ["Unknown field 'unknownField'"]

// Get schema for introspection
const schema = configManager.getSchema()
console.log(schema.port.default) // 3000
```

**Best Practices:**
- Define schema at module level for reuse
- Use `required: true` for mandatory fields
- Provide sensible defaults for optional fields
- Use `min`/`max` for numeric bounds
- Use `pattern` for string format validation
- Use `enum` for limited set of values
- Use `validate` for complex business logic
- Use `transform` for type coercion (e.g., string → number)

### validateConfig()

**Purpose:** One-shot configuration validation without creating manager instance

**Usage:**
```typescript
validateConfig<T>(
  config: unknown,
  schema: ConfigSchema<T>
): StrictValidation<T>
```

**Parameters:**
- `config` - Configuration object to validate
- `schema` - Configuration schema

**Returns:** Validation result with `{ success, data?, errors? }`

**Common Patterns:**

```typescript
// Quick validation
const result = validateConfig(userConfig, {
  username: { type: 'string', required: true },
  age: { type: 'number', min: 0, max: 120 },
})

if (!result.success) {
  throw new Error(`Invalid config: ${result.errors.join(', ')}`)
}

const { username, age } = result.data

// API request validation
app.post('/api/config', (req, res) => {
  const result = validateConfig(req.body, {
    theme: { type: 'string', enum: ['light', 'dark'] },
    fontSize: { type: 'number', min: 12, max: 24 },
    notifications: { type: 'boolean', default: true },
  })

  if (!result.success) {
    return res.status(400).json({ errors: result.errors })
  }

  saveUserPreferences(result.data)
  res.json({ success: true })
})

// File configuration
import fs from 'fs'

const configFile = JSON.parse(fs.readFileSync('config.json', 'utf-8'))

const result = validateConfig(configFile, {
  database: {
    type: 'object',
    required: true,
  },
  redis: {
    type: 'object',
    default: { host: 'localhost', port: 6379 },
  },
})
```

**Purpose:** Extract default values from schema

**Usage:**
```typescript

```

**Common Patterns:**

```typescript
// Get defaults
const defaults = getConfigDefaults({
  port: { type: 'number', default: 3000 },
  host: { type: 'string', default: 'localhost' },
  timeout: { type: 'number', default: 5000 },
  apiKey: { type: 'string', required: true }, // No default
})

// defaults = { port: 3000, host: 'localhost', timeout: 5000 }

// Documentation generation
const schema = {
  maxRetries: { type: 'number', default: 3 },
  backoffMs: { type: 'number', default: 1000 },
}

const defaults = getConfigDefaults(schema)

console.log('Default Configuration:')
for (const [key, value] of Object.entries(defaults)) {
  console.log(`  ${key}: ${value}`)
}
```

### mergeConfig()

**Purpose:** Merge partial configuration with defaults and validate

**Usage:**
```typescript
mergeConfig<T>(
  partial: Partial<T>,
  schema: ConfigSchema<T>
): T
```

**Parameters:**
- `partial` - Partial configuration object
- `schema` - Configuration schema

**Returns:** Merged and validated configuration

**Throws:** Error if validation fails

**Common Patterns:**

```typescript
// Merge user config with defaults
const schema = {
  theme: { type: 'string', default: 'light' },
  fontSize: { type: 'number', default: 14 },
  notifications: { type: 'boolean', default: true },
}

const userPrefs = mergeConfig({ theme: 'dark' }, schema)
// { theme: 'dark', fontSize: 14, notifications: true }

// Override environment defaults
const envDefaults = {
  LOG_LEVEL: { type: 'string', default: 'info' },
  PORT: { type: 'number', default: 3000 },
}

const config = mergeConfig(process.env, envDefaults)

// Throws on invalid merge
try {
  const config = mergeConfig({ port: 'invalid' }, {
    port: { type: 'number', default: 3000 },
  })
} catch (error) {
  console.error(error.message)
  // "Invalid configuration: Field 'port' must be a number"
}
```

## Best Practices

### Schema Design

```typescript
// ✅ Good: Clear, specific schemas
const schema = {
  apiKey: {
    type: 'string',
    required: true,
    pattern: /^sk-[a-zA-Z0-9]{32}$/,
  },
  timeout: {
    type: 'number',
    default: 5000,
    min: 1000,
    max: 60000,
  },
  environment: {
    type: 'string',
    default: 'development',
    enum: ['development', 'staging', 'production'],
  },
}

// ❌ Bad: No validation constraints
const schema = {
  apiKey: { type: 'string' },
  timeout: { type: 'number' },
  environment: { type: 'string' },
}
```

### Environment Variables

```typescript
// ✅ Good: Transform and validate env vars
const envSchema = createConfigManager({
  PORT: {
    type: 'number',
    default: 3000,
    transform: (value) => parseInt(String(value), 10),
  },
  REDIS_URL: {
    type: 'string',
    required: true,
    pattern: /^redis:\/\/.+/,
  },
  DEBUG: {
    type: 'boolean',
    default: false,
    transform: (value) => value === 'true' || value === true,
  },
})

const config = envSchema.validate(process.env)

// ❌ Bad: Direct env var usage without validation
const port = parseInt(process.env.PORT || '3000')
const debug = process.env.DEBUG === 'true'
```

### Error Handling

```typescript
// ✅ Good: Check validation result
const result = configManager.validate(userConfig)

if (!result.success) {
  logger.error('Configuration validation failed', {
    errors: result.errors,
  })
  throw new Error(`Invalid configuration: ${result.errors.join(', ')}`)
}

const config = result.data

// ❌ Bad: Assume validation succeeds
const config = configManager.validate(userConfig).data // Might be undefined!
```

### Defaults Strategy

```typescript
// ✅ Good: Sensible defaults for optional fields
const schema = {
  timeout: { type: 'number', default: 5000 },
  retries: { type: 'number', default: 3 },
  debug: { type: 'boolean', default: false },
  apiKey: { type: 'string', required: true }, // No default for secrets
}

// ❌ Bad: Required fields with defaults
const schema = {
  apiKey: { type: 'string', default: 'REPLACE_ME' }, // Security risk!
}
```

## Real-World Examples

### Application Configuration

```typescript
import { createConfigManager } from '@clarity-chat/utils/config-manager'

interface AppConfig {
  server: {
    port: number
    host: string
  }
  database: {
    url: string
    maxConnections: number
  }
  redis: {
    url: string
    ttl: number
  }
  api: {
    key: string
    timeout: number
    retries: number
  }
  features: {
    caching: boolean
    logging: boolean
  }
}

const configSchema = {
  server: {
    type: 'object' as const,
    default: { port: 3000, host: 'localhost' },
  },
  database: {
    type: 'object' as const,
    required: true,
  },
  redis: {
    type: 'object' as const,
    default: { url: 'redis://localhost:6379', ttl: 3600 },
  },
  api: {
    type: 'object' as const,
    required: true,
  },
  features: {
    type: 'object' as const,
    default: { caching: true, logging: true },
  },
}

const configManager = createConfigManager(configSchema)

function loadConfig(): AppConfig {
  const configFile = JSON.parse(
    fs.readFileSync('config.json', 'utf-8')
  )

  const result = configManager.validate(configFile)

  if (!result.success) {
    console.error('Configuration errors:')
    result.errors.forEach(err => console.error(`  - ${err}`))
    process.exit(1)
  }

  return result.data as AppConfig
}

const config = loadConfig()
```

### Environment Variable Validation

```typescript
import { createConfigManager } from '@clarity-chat/utils/config-manager'

const envSchema = createConfigManager({
  NODE_ENV: {
    type: 'string',
    default: 'development',
    enum: ['development', 'staging', 'production'],
  },
  PORT: {
    type: 'number',
    default: 3000,
    transform: (value) => {
      const port = parseInt(String(value), 10)
      if (isNaN(port)) return 3000
      return port
    },
    min: 1024,
    max: 65535,
  },
  DATABASE_URL: {
    type: 'string',
    required: true,
    pattern: /^postgres:\/\/.+/,
  },
  REDIS_URL: {
    type: 'string',
    default: 'redis://localhost:6379',
    pattern: /^redis:\/\/.+/,
  },
  API_KEY: {
    type: 'string',
    required: true,
    pattern: /^[a-zA-Z0-9_-]{32,}$/,
  },
  LOG_LEVEL: {
    type: 'string',
    default: 'info',
    enum: ['debug', 'info', 'warn', 'error'],
  },
  MAX_CONNECTIONS: {
    type: 'number',
    default: 100,
    transform: (value) => parseInt(String(value), 10),
    min: 1,
    max: 1000,
  },
  ENABLE_CACHE: {
    type: 'boolean',
    default: true,
    transform: (value) =>
      value === 'true' || value === true || value === '1',
  },
})

// Validate at startup
const result = envSchema.validate(process.env)

if (!result.success) {
  console.error('❌ Environment validation failed:')
  result.errors.forEach(error => {
    console.error(`   ${error}`)
  })
  process.exit(1)
}

export const env = result.data
console.log('✓ Environment validated successfully')
```
