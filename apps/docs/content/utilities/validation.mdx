# Validation & Type Guards

> Type-safe runtime validation with comprehensive type guards, detailed error reporting, and TypeScript type narrowing.

Validation utilities provide the foundation for type-safe runtime checks throughout Clarity Chat. They combine TypeScript's compile-time type system with runtime validation, offering type guards for narrowing, assertions for guarantees, and validators for detailed error reporting.

## When to Use

- **Validate user input** - Forms, API payloads, configuration files
- **Runtime type checking** - Ensure data matches expected types at boundaries
- **Type narrowing** - Use type guards to narrow `unknown` to specific types
- **Defensive programming** - Assert preconditions and invariants
- **API validation** - Validate external data before processing
- **Format validation** - Check emails, URLs, UUIDs, JSON

## Quick Start

```typescript
import {
  isString,
  isDefined,
  validateString,
  assertDefined,
  isValidEmail,
} from '@clarity-chat/utils/validation'

// Type guard - narrows type
function processValue(value: unknown) {
  if (isString(value)) {
    // value is now string
    console.log(value.toUpperCase())
  }
}

// Validation - detailed errors
const result = validateString(userInput, {
  minLength: 3,
  maxLength: 50,
  pattern: /^[a-zA-Z0-9]+$/,
})

if (!result.success) {
  console.error(result.errors) // ["String must be at least 3 characters long"]
}

// Assertion - throws if invalid
assertDefined(user, 'User is required')
// user is now guaranteed non-null

// Format validation
if (isValidEmail(input)) {
  sendEmail(input) // input is validated email string
}
```

## Type Guards

Type guards return boolean and narrow TypeScript types.

### Basic Type Guards

#### isString()

**Purpose:** Check if value is a string and narrow type

**Usage:**
```typescript
isString(value: unknown): value is string
```

**Example:**
```typescript
function greet(name: unknown) {
  if (isString(name)) {
    // name is now string
    console.log(`Hello, ${name.toUpperCase()}!`)
  } else {
    console.log('Invalid name')
  }
}

// Array filtering
const mixed = [1, 'hello', null, 'world', undefined]
const strings = mixed.filter(isString) // string[]
```

#### isNumber()

**Purpose:** Check if value is a number (excludes NaN)

**Usage:**
```typescript
isNumber(value: unknown): value is number
```

**Example:**
```typescript
function calculate(value: unknown) {
  if (isNumber(value)) {
    // value is number
    return value * 2
  }
  return 0
}

// isNumber(42) → true
// isNumber(NaN) → false (excluded!)
// isNumber('42') → false
```

#### isBoolean()

**Purpose:** Check if value is boolean

**Usage:**
```typescript
isBoolean(value: unknown): value is boolean
```

**Example:**
```typescript
if (isBoolean(config.enabled)) {
  if (config.enabled) {
    startService()
  }
}
```

### Object & Array Type Guards

#### isObject()

**Purpose:** Check if value is a plain object (not null, not array)

**Usage:**
```typescript
isObject(value: unknown): value is Record<string, unknown>
```

**Example:**
```typescript
function processConfig(data: unknown) {
  if (isObject(data)) {
    // data is Record<string, unknown>
    const name = data.name
    const version = data.version
  }
}

// isObject({}) → true
// isObject(null) → false
// isObject([]) → false (use isArray)
```

#### isArray()

**Purpose:** Check if value is an array

**Usage:**
```typescript
isArray(value: unknown): value is unknown[]
```

**Example:**
```typescript
if (isArray(response.data)) {
  response.data.forEach(item => process(item))
}
```

#### isArrayOf()

**Purpose:** Check if value is an array of specific type

**Usage:**
```typescript
isArrayOf<T>(
  value: unknown,
  guard: (item: unknown) => item is T
): value is T[]
```

**Example:**
```typescript
// Validate array of strings
if (isArrayOf(tags, isString)) {
  // tags is now string[]
  tags.forEach(tag => console.log(tag.toUpperCase()))
}

// Validate array of numbers
if (isArrayOf(scores, isNumber)) {
  const average = scores.reduce((a, b) => a + b, 0) / scores.length
}

// Custom type guard
interface User {
  id: string
  name: string
}

const isUser = (value: unknown): value is User =>
  isObject(value) && isString(value.id) && isString(value.name)

if (isArrayOf(data, isUser)) {
  // data is now User[]
  data.forEach(user => console.log(user.name))
}
```

#### isNonEmptyArray()

**Purpose:** Check if value is an array with at least one element

**Usage:**
```typescript
isNonEmptyArray<T>(value: unknown): value is T[]
```

**Example:**
```typescript
if (isNonEmptyArray(items)) {
  // items has at least one element
  const firstItem = items[0] // Safe to access
}
```

## Validation Functions

Validation functions return `{ success: boolean, data?: T, errors?: string[] }` for detailed error reporting.

### validateString()

**Purpose:** Validate string with length and pattern constraints

**Usage:**
```typescript
validateString(
  value: unknown,
  options?: {
    minLength?: number
    maxLength?: number
    pattern?: RegExp
    required?: boolean
    allowEmpty?: boolean
  }
): StrictValidation<string>
```

**Example:**
```typescript
// Username validation
const result = validateString(username, {
  minLength: 3,
  maxLength: 20,
  pattern: /^[a-zA-Z0-9_]+$/,
})

if (!result.success) {
  console.error(result.errors)
  // ["String must be at least 3 characters long"]
  // ["String does not match required pattern"]
} else {
  saveUsername(result.data)
}

// Optional field
const descResult = validateString(description, {
  maxLength: 500,
  required: false,
  allowEmpty: true,
})

// Email pattern validation
const emailResult = validateString(email, {
  pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
})
```

## Best Practices

### Type Guard Selection
- Use **type guards** (`isString`) for conditional logic and filtering
- Use **assertions** (`assertString`) when failure is exceptional
- Use **validators** (`validateString`) for user input with error messages

### Type Narrowing
```typescript
// ✅ Good: Type narrowing
function process(value: unknown) {
  if (isString(value)) {
    return value.toUpperCase() // value is string
  }
}

// ❌ Bad: Type assertion
function process(value: unknown) {
  return (value as string).toUpperCase() // Unsafe!
}
```

### Assertion Patterns
```typescript
// ✅ Good: Informative error messages
assertDefined(user, `User with ID ${userId} not found`)

// ❌ Bad: Generic messages
assertDefined(user) // Less helpful debugging
```

### Validation with Recovery
```typescript
// ✅ Good: Validate with fallback
const result = validateNumber(input, { min: 0, max: 100 })
const value = result.success ? result.data : 0

// ❌ Bad: Assertion without recovery
assertNumber(input) // Throws, no recovery
```

### Composition
```typescript
// Compose type guards for complex validation
const isValidUser = (value: unknown): value is User =>
  isObject(value) &&
  isString(value.id) &&
  isString(value.name) &&
  isValidEmail(value.email)

if (isValidUser(data)) {
  // data is fully validated User
}
```

## Real-World Examples

### Form Validation

```typescript
import { validateString, validateNumber, isValidEmail } from '@clarity-chat/utils/validation'

interface UserForm {
  name: string
  age: number
  email: string
}

function validateUserForm(data: unknown): { success: boolean; errors: string[]; data?: UserForm } {
  const errors: string[] = []

  const nameResult = validateString(data?.name, {
    minLength: 2,
    maxLength: 50,
  })
  if (!nameResult.success) errors.push(...nameResult.errors)

  const ageResult = validateNumber(data?.age, {
    min: 18,
    max: 120,
    integer: true,
  })
  if (!ageResult.success) errors.push(...ageResult.errors)

  const emailResult = validateString(data?.email)
  if (!emailResult.success) {
    errors.push(...emailResult.errors)
  } else if (!isValidEmail(emailResult.data)) {
    errors.push('Invalid email format')
  }

  if (errors.length > 0) {
    return { success: false, errors }
  }

  return {
    success: true,
    errors: [],
    data: {
      name: nameResult.data!,
      age: ageResult.data!,
      email: emailResult.data!,
    },
  }
}
```

### API Response Validation

```typescript
import { isObject, isString, isArray, assertDefined } from '@clarity-chat/utils/validation'

interface ApiUser {
  id: string
  name: string
  roles: string[]
}

const isApiUser = (value: unknown): value is ApiUser =>
  isObject(value) &&
  isString(value.id) &&
  isString(value.name) &&
  isArrayOf(value.roles, isString)

async function fetchUser(userId: string): Promise<ApiUser> {
  const response = await fetch(`/api/users/${userId}`)
  const data = await response.json()

  assertDefined(data, 'API returned empty response')

  if (!isApiUser(data)) {
    throw new TypeError('Invalid user data from API')
  }

  return data
}
```

### Configuration Validation

```typescript
import { validateString, validateNumber, parseJson } from '@clarity-chat/utils/validation'

interface AppConfig {
  apiKey: string
  timeout: number
  retries: number
}

function loadConfig(jsonString: string): AppConfig {
  const parseResult = parseJson(jsonString)

  if (!parseResult.success) {
    throw new Error(`Invalid config JSON: ${parseResult.errors.join(', ')}`)
  }

  const data = parseResult.data

  const apiKeyResult = validateString(data.apiKey, {
    minLength: 32,
    pattern: /^[a-zA-Z0-9_-]+$/,
  })

  const timeoutResult = validateNumber(data.timeout, {
    min: 1000,
    max: 60000,
  })

  const retriesResult = validateNumber(data.retries, {
    min: 0,
    max: 5,
    integer: true,
  })

  const errors: string[] = []
  if (!apiKeyResult.success) errors.push(...apiKeyResult.errors)
  if (!timeoutResult.success) errors.push(...timeoutResult.errors)
  if (!retriesResult.success) errors.push(...retriesResult.errors)

  if (errors.length > 0) {
    throw new Error(`Config validation failed: ${errors.join(', ')}`)
  }

  return {
    apiKey: apiKeyResult.data,
    timeout: timeoutResult.data,
    retries: retriesResult.data,
  }
}
```
