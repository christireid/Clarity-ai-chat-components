# UseCompletionReturn

Return type for useCompletion hook (mid-level API)

Follows the standard hook return pattern:
- Data: `completion` (current completion text)
- State: `isLoading`, `error`, `progress`
- Actions: `complete`, `stop`, `abort`, `clearCache`
