## 📏 Spacing Scale

Our spacing scale is based on an 8px grid system:

| Token | Value | Use Case |
|-------|-------|----------|
| `0.5` | 2px | Tight spacing, borders |
| `1` | 4px | Compact elements |
| `2` | 8px | Default gap |
| `3` | 12px | Small padding |
| `4` | 16px | Standard padding |
| `6` | 24px | Section spacing |
| `8` | 32px | Large padding |
| `12` | 48px | Page sections |
| `16` | 64px | Major sections |

---

## 🔘 Border Radius

| Token | Value | Use Case |
|-------|-------|----------|
| `sm` | 4px | Small elements (badges, tags) |
| `md` | 6px | Buttons, inputs |
| `lg` | 8px | Cards, dialogs |
| `xl` | 12px | Large cards |
| `2xl` | 16px | Hero sections |
| `full` | 9999px | Pills, avatars |

---

## 🎭 Shadows

### Elevation System

| Level | Use Case | Shadow |
|-------|----------|--------|
| `sm` | Subtle lift | `0 1px 2px 0 rgb(0 0 0 / 0.05)` |
| `md` | Cards, dropdowns | `0 4px 6px -1px rgb(0 0 0 / 0.1)` |
| `lg` | Modals, popovers | `0 10px 15px -3px rgb(0 0 0 / 0.1)` |
| `xl` | Floating elements | `0 20px 25px -5px rgb(0 0 0 / 0.1)` |

## ⚡ Transitions

### Duration

- **Fast** - 150ms (micro-interactions)
- **Base** - 200ms (standard transitions)
- **Slow** - 300ms (complex animations)

### Easing

- **Linear** - `linear`
- **Ease** - `cubic-bezier(0.4, 0, 0.2, 1)`
- **Ease In** - `cubic-bezier(0.4, 0, 1, 1)`
- **Ease Out** - `cubic-bezier(0, 0, 0.2, 1)`
- **Bounce** - `cubic-bezier(0.68, -0.55, 0.265, 1.55)`

## ♿ Accessibility

### Color Contrast

All color combinations meet **WCAG AA+** standards (7:1 contrast ratio).

### Focus States

- **Focus Ring** - 2px solid primary color with 2px offset
- **Keyboard Navigation** - Clear visual indicators for all interactive elements

### Screen Reader Support

- Proper ARIA labels on all components
- Semantic HTML structure
- Live regions for dynamic content

---

## 🎯 Component Patterns

### Button Hierarchy

1. **Primary** - Main call-to-action (one per screen)
2. **Secondary** - Supporting actions
3. **Outline** - Tertiary actions
4. **Ghost** - Subtle actions
5. **Link** - Text-based actions

### Message States

- **User Message** - Right-aligned, primary color background
- **Assistant Message** - Left-aligned, neutral background
- **System Message** - Centered, muted text
- **Error Message** - Red accent, error icon

### Loading States

- **Typing Indicator** - Animated dots
- **Skeleton** - Pulsing placeholder
- **Spinner** - Rotating loader
- **Progress Bar** - Linear progress

## 🌙 Dark Mode

Dark mode uses inverted luminance with the same color hue:

### Light Mode

- Background: White (#ffffff)
- Surface: Gray 50 (#f9fafb)
- Text: Gray 900 (#111827)

### Dark Mode

- Background: Gray 900 (#111827)
- Surface: Gray 800 (#1f2937)
- Text: Gray 50 (#f9fafb)

### Automatic Switching

```tsx
import { ThemeProvider } from '@clarity-chat/react'

function App() {
  return (
    <ThemeProvider defaultTheme={{ mode: 'system' }}>
      <YourApp />
    </ThemeProvider>
  )
}
```

---

## 🎨 Theme Customization

Create your own theme:

```tsx
import { ThemeProvider } from '@clarity-chat/react'

const customTheme = {
  mode: 'light',
  // Note: For custom themes, omit preset and define all colors
  colors: {
    primary: '#3b82f6',
    background: '#ffffff',
    foreground: '#111827',
    // ... more colors
  },
  radius: 'md',
  font: 'inter',
}

function App() {
  return (
    <ThemeProvider defaultTheme={customTheme}>
      <YourApp />
    </ThemeProvider>
  )
}
```

## 🚀 Using the Design System

### In Components

```tsx
import { Button } from '@clarity-chat/react'

// Uses design system automatically
<Button variant="primary" size="md">
  Click me
</Button>
```

### Custom Styling

```tsx
import { cn } from '@clarity-chat/react'

<div className={cn(
  'rounded-lg',        // Uses design system radius
  'p-4',              // Uses spacing scale
  'bg-primary',       // Uses color palette
  'text-white',       // Semantic color
  'shadow-md'         // Elevation system
)}>
  Custom styled component
</div>
```
