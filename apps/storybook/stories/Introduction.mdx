# Welcome to Clarity Chat

Clarity Chat is a React component system for building production-grade AI conversations. This Storybook showcases every component, hook, and pattern available in the library.

## Highlights

- **69+ components** covering full chat windows, streaming messages, tool invocation, and operational dashboards.
- **Model-agnostic adapters** for OpenAI, Anthropic, Google AI, or your own providers.
- **Accessibility-first design** with WCAG-compliant colors, keyboard support, and screen reader semantics.
- **TypeScript ready** with rich IntelliSense and strict typings.

## Exploring the Stories

1. Start with the `ChatWindow` stories to see an end-to-end conversation surface.
2. Visit the `Streaming` section to review token-by-token rendering and thinking indicators.
3. Open the `Operational` stories for dashboards, safety cards, and evaluation widgets.
4. Use the toolbar controls to toggle light/dark themes, responsive viewports, and addon panels.

## Example Usage

```tsx
import { ChatWindow, ModelSelector } from '@clarity-chat/react'
import { useChat } from '@clarity-chat/react'

export function Demo() {
  const { messages, sendMessage, activeModel, setActiveModel } = useChat({
    chatId: 'storybook-demo',
  })

  return (
    <>
      <ModelSelector value={activeModel} onChange={setActiveModel} />
      <ChatWindow messages={messages} onSendMessage={content => sendMessage({ role: 'user', content })} />
    </>
  )
}
```
