    ## 📦 Component Categories

    ### Primitives
    Low-level UI building blocks like buttons, inputs, and dialogs. These are the foundation of all other components.

    **Examples:** Button, Input, Dialog, Drawer, Card, Badge, Avatar

    ### Core Components
    Chat-specific components for building conversational interfaces.

    **Examples:** ChatWindow, Message, ChatInput, StreamingMessage, MessageList

    ### Advanced Components
    Feature-rich components for enhanced UX and functionality.

    **Examples:** CommandPalette, VoiceInput, FileUpload, CodeEditor, ContextManager

    ### Templates
    Pre-built, production-ready chat implementations for common use cases.

    **Examples:** Support Bot, Code Assistant, Documentation Bot, Sales Assistant

    ### Enterprise Components
    Advanced features for enterprise deployments.

    **Examples:** Multi-tenant Dashboard, SSO Config, API Token Manager, Audit Logs

    ### AI Ops Components
    Tools for monitoring, testing, and improving AI performance.

    **Examples:** Evaluation Dashboard, Safety Console, Prompt Test Harness

    ## 🚀 Quick Start

    ```bash
    # Install the package
    npm install @clarity-chat/react

    # Import components
    import { ChatWindow, Message } from '@clarity-chat/react'
    ```

    ```jsx
    // Basic usage
    function App() {
      const [messages, setMessages] = useState([])
      
      return (
        <ChatWindow
          messages={messages}
          onSendMessage={(content) => {
            // Handle message
          }}
        />
      )
    }
    ```

    ## 🎨 Design Principles

    ### 1. **Delightful by Default**
    Every interaction should feel smooth and responsive. We use microanimations and tactile feedback to create engaging experiences.

    ### 2. **Accessible Always**
    Accessibility isn't optional. All components are keyboard navigable, screen-reader friendly, and WCAG 2.1 AA compliant.

    ### 3. **Performance First**
    Built with performance in mind using virtualization, code splitting, and React 18 concurrent features.

    ### 4. **Flexible & Composable**
    Components are designed to work together seamlessly while remaining flexible enough for custom use cases.

    ### 5. **Type-Safe**
    Full TypeScript support with comprehensive type definitions for better DX and fewer bugs.
