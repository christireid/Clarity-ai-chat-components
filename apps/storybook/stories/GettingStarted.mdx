# Getting Started with Clarity Chat

Kick off your integration in three short steps: install the package, configure a chat hook, and render the `ChatWindow` component.

## 1. Install

```bash
npm install @clarity-chat/react
# or
yarn add @clarity-chat/react
# or
pnpm add @clarity-chat/react
```

## 2. Provide Messages

```tsx
import { ChatWindow } from '@clarity-chat/react'
import { useState } from 'react'

const initialMessages = [
  {
    id: '1',
    chatId: 'demo',
    role: 'assistant',
    content: 'Hey there! Ready to build an AI assistant?',
    createdAt: new Date(),
    status: 'sent',
  },
]

export function QuickStartChat() {
  const [messages, setMessages] = useState(initialMessages)

  async function handleSendMessage(content) {
    const nextMessage = {
      id: crypto.randomUUID(),
      chatId: 'demo',
      role: 'user',
      content,
      createdAt: new Date(),
      status: 'sent',
    }

    setMessages(prev => [...prev, nextMessage])
    // TODO: call your model adapter here
  }

  return (
    <ChatWindow
      messages={messages}
      onSendMessage={handleSendMessage}
    />
  )
}
```
