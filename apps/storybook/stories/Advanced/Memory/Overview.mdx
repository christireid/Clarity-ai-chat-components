# Memory & Context Components

Memory components manage conversation context, knowledge bases, and document integration. They enable AI systems to maintain context and retrieve relevant information.

- [DocumentViewer](?path=/docs/advanced-memory-documentviewer--docs) - View and annotate documents

## Component Categories

### Context Management
- **MemoryInspector** - Debug and inspect conversation memory
- **ContextManager** - Add, remove, and manage context
- **ContextVisualizer** - Visualize token usage and context window

### Knowledge Integration
- **KnowledgeBaseViewer** - Browse and search knowledge bases
- **DocumentViewer** - View source documents and citations

## Best Practices

- ✅ Monitor token usage to avoid context limit
- ✅ Prioritize recent and relevant context
- ✅ Use semantic chunking for documents
- ✅ Provide citations for grounded responses
- ✅ Allow users to manage context manually
- ✅ Implement sliding window for long conversations

## When to Use

**MemoryInspector**: For debugging context issues
**ContextManager**: When users need control over context
**ContextVisualizer**: To show token usage transparency
**KnowledgeBaseViewer**: For RAG applications
**DocumentViewer**: When working with source documents
