## Common Patterns

### Agent with Tools

```tsx
import { AgentRunFeed, ToolInvocationCard } from '@clarity-chat/react'

function AgentInterface({ runs }) {
  return (
    <div>
      <AgentRunFeed runs={runs} showTools />
      {runs.map((run) =>
        run.tools.map((tool) => (
          <ToolInvocationCard
            key={tool.id}
            tool={tool}
            showResult
          />
        ))
      )}
    </div>
  )
}
```

### RAG with Memory

```tsx
import { MemoryInspector, KnowledgeBaseViewer } from '@clarity-chat/react'

function RAGChat({ memory, knowledgeBase }) {
  return (
    <div className="grid grid-cols-2 gap-4">
      <div>
        {/* Chat interface */}
      </div>
      <div>
        <MemoryInspector memory={memory} />
        <KnowledgeBaseViewer kb={knowledgeBase} />
      </div>
    </div>
  )
}
```

### Streaming with Analytics

```tsx
import { StreamBlock, TokenOptimizationDashboard } from '@clarity-chat/react'

function MonitoredChat({ content, isStreaming, tokens }) {
  return (
    <>
      <TokenOptimizationDashboard tokens={tokens} />
      <StreamBlock
        content={content}
        isStreaming={isStreaming}
        onComplete={() => console.log('Stream complete')}
      />
    </>
  )
}
```

## Best Practices

### Security
- Always validate user permissions
- Use API tokens securely
- Enable audit logging
- Review AI safety guidelines

### Performance
- Monitor token usage
- Optimize context windows
- Use streaming for long responses
- Cache frequently accessed data

### Scalability
- Design for multi-tenancy
- Plan for data growth
- Monitor performance metrics
- Implement rate limiting

### Compliance
- Enable audit logs
- Review data retention policies
- Implement access controls
- Follow security best practices
