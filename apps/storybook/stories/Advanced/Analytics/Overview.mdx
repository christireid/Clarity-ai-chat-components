- **PerformanceDashboard** - Response times, throughput, errors

- **UsageDashboard** - User activity, API calls, costs
- **TokenOptimizationDashboard** - Token usage optimization

## Best Practices

- ✅ Monitor token usage to control costs
- ✅ Track response times and errors
- ✅ Set up alerts for anomalies
- ✅ Use token optimization (caching, prompts)
- ✅ Analyze usage patterns regularly
- ✅ Export data for long-term analysis

## Token Optimization Strategies

### Prompt Caching
Cache frequently used system prompts to reduce costs by up to 90%.

### Context Pruning
Automatically remove irrelevant context to stay within limits.

### Smart Summarization
Summarize older messages to preserve important context.

## When to Use

**PerformanceDashboard**: To monitor system health
**UsageDashboard**: To track costs and usage
**TokenOptimizationDashboard**: To reduce token costs
