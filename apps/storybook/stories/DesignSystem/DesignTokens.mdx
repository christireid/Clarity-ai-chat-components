# Design Tokens

Clarity Chat uses a consistent set of design tokens for colors, typography, spacing, and more.
These tokens are implemented using Tailwind CSS and CSS custom properties.

|-------|-------|-------|

## CSS Custom Properties

Clarity Chat exposes CSS custom properties for runtime theming:

```css
:root {
  /* Colors */
  --clarity-primary: #6366F1;
  --clarity-primary-foreground: #FFFFFF;
  --clarity-background: #FFFFFF;
  --clarity-foreground: #1E293B;
  --clarity-muted: #F1F5F9;
  --clarity-muted-foreground: #64748B;
  --clarity-border: #E2E8F0;
  --clarity-ring: #6366F1;

  /* Spacing */
  --clarity-radius: 0.5rem;

  /* Typography */
  --clarity-font-sans: 'Inter', system-ui, sans-serif;
  --clarity-font-mono: 'JetBrains Mono', monospace;
}

.dark {
  --clarity-primary: #818CF8;
  --clarity-primary-foreground: #0F172A;
  --clarity-background: #0F172A;
  --clarity-foreground: #F1F5F9;
  --clarity-muted: #1E293B;
  --clarity-muted-foreground: #94A3B8;
  --clarity-border: #334155;
  --clarity-ring: #818CF8;
}
```

## Using Design Tokens

### With Tailwind CSS

```tsx
<div className="bg-primary text-primary-foreground rounded-lg p-4 shadow-md">
  Content styled with Tailwind utilities
</div>
```

### With CSS Custom Properties

```tsx
<div style={{
  backgroundColor: 'var(--clarity-primary)',
  color: 'var(--clarity-primary-foreground)',
  borderRadius: 'var(--clarity-radius)',
  padding: '1rem'
}}>
  Content styled with CSS variables
</div>
```

### With the Theme Hook

```tsx
import { useTheme } from '@clarity-chat/react'

function ThemedComponent() {
  const { theme, setTheme } = useTheme()

  return (
    <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>
      Toggle Theme
    </button>
  )
}
```
