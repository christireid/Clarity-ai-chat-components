# UI Primitives

The `@clarity-chat/primitives` package provides foundational UI components built on
[shadcn/ui](https://ui.shadcn.com/) and [Radix UI](https://www.radix-ui.com/).
All components are accessible (WCAG 2.1 AA compliant) and fully customizable.

---

## Installation

```bash
npm install @clarity-chat/primitives
```

## Quick Start

```tsx
import { Button, Card, Input, Dialog } from '@clarity-chat/primitives'

function MyComponent() {
  return (
    <Card>
      <Input placeholder="Enter text..." />
      <Button variant="default">Submit</Button>
    </Card>
  )
}
```

## Design Principles

### Accessibility First

All primitives are built with accessibility as a core requirement:

- Full keyboard navigation
- Screen reader announcements
- Focus management
- ARIA attributes
- Color contrast compliance

### Composable Architecture

Primitives follow a composable pattern allowing flexible customization:

```tsx
// Composable usage
<Dialog>
  <DialogTrigger>
    <Button>Open</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Title</DialogTitle>
      <DialogDescription>Description</DialogDescription>
    </DialogHeader>
    <DialogBody>Content here</DialogBody>
    <DialogFooter>
      <Button>Close</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

### Styling with Tailwind

All components use Tailwind CSS with the `cn()` utility for class merging:

```tsx
import { Button, cn } from '@clarity-chat/primitives'

// Custom styles merge with defaults
<Button className={cn('my-4', isLarge && 'text-lg')}>
  Click me
</Button>
```

### Variants with CVA

Components use [class-variance-authority](https://cva.style/) for type-safe variants:

```tsx
// Button variants
<Button variant="default">Default</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="destructive">Destructive</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="link">Link</Button>

// Sizes
<Button size="sm">Small</Button>
<Button size="default">Default</Button>
<Button size="lg">Large</Button>
<Button size="icon">Icon</Button>
```

## Enhanced Components

Some primitives have enhanced versions with additional features:

### Button (Enhanced)

The default Button export includes loading state support:

```tsx
import { Button, type ButtonState } from '@clarity-chat/primitives'

function SubmitButton() {
  const [state, setState] = useState<ButtonState>('idle')

  const handleClick = async () => {
    setState('loading')
    try {
      await submitForm()
      setState('success')
    } catch {
      setState('error')
    }
  }

  return (
    <Button state={state} onClick={handleClick}>
      {state === 'loading' ? 'Submitting...' : 'Submit'}
    </Button>
  )
}
```

### Tooltip (Simplified)

A simplified Tooltip with content prop:

```tsx
import { Tooltip } from '@clarity-chat/primitives'

// Simple usage
<Tooltip content="Helpful information">
  <span>Hover me</span>
</Tooltip>

// Full control (using TooltipRoot)
<TooltipProvider>
  <TooltipRoot>
    <TooltipTrigger>Hover</TooltipTrigger>
    <TooltipContent>Content</TooltipContent>
  </TooltipRoot>
</TooltipProvider>
```

## Utility Exports

### cn() - Class Merging

Merge Tailwind classes with conflict resolution:

```tsx
import { cn } from '@clarity-chat/primitives'

const className = cn(
  'px-4 py-2 rounded',        // Base classes
  isActive && 'bg-primary',   // Conditional
  'text-sm',                  // Override-friendly
  customClassName             // User classes
)
```

### generateId() - Unique IDs

Generate unique identifiers for accessibility:

```tsx
import { generateId } from '@clarity-chat/primitives'

const id = generateId() // "cid-abc123xyz"
```

## Hooks

### useRippleEffect

Material-style ripple effect for buttons:

```tsx
import { useRippleEffect } from '@clarity-chat/primitives'

function RippleButton() {
  const { handleClick, rippleStyle } = useRippleEffect()

  return (
    <button onClick={handleClick} style={rippleStyle}>
      Click me
    </button>
  )
}
```

### useBodyScrollLock

Lock body scroll when modals are open:

```tsx
import { useBodyScrollLock } from '@clarity-chat/primitives'

function Modal({ isOpen }) {
  useBodyScrollLock(isOpen)

  return isOpen ? <div>Modal content</div> : null
}
```

## Migration from Custom Components

If migrating from earlier versions, note that default exports now point to
shadcn/ui components. For backward compatibility, components are also
exported with a `Shadcn` prefix:

```tsx
// These are equivalent
import { Button } from '@clarity-chat/primitives'
import { ShadcnButton } from '@clarity-chat/primitives'
```
