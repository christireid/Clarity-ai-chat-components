# Navigation Components

Navigation components help users move through your application and access contextual actions. They provide intuitive ways to discover and execute commands.

## Quick Links

- [CommandPalette](?path=/docs/components-navigation-commandpalette--docs) ⭐ - Command search interface
- [ContextMenu](?path=/docs/components-navigation-contextmenu--docs) ⭐ - Right-click context menu
- [DropdownMenu](?path=/docs/components-navigation-dropdownmenu--docs) - Dropdown menu component
- [Popover](?path=/docs/components-navigation-popover--docs) - Floating popover element
- [Draggable](?path=/docs/components-navigation-draggable--docs) - Drag-and-drop functionality

## Component Categories

### Command & Search
- **CommandPalette** - Fuzzy search command interface (⌘K)

### Contextual Actions
- **ContextMenu** - Right-click menus
- **DropdownMenu** - Dropdown action menus
- **Popover** - Floating content panels

### Interactions
- **Draggable** - Drag-and-drop support

## Best Practices

- ✅ Support keyboard navigation (arrow keys, Tab, Enter)
- ✅ Provide keyboard shortcuts (⌘K for command palette)
- ✅ Use clear, action-oriented labels
- ✅ Group related actions together
- ✅ Show keyboard hints in menus
- ✅ Ensure touch-friendly hit targets (44x44px)

## Keyboard Shortcuts

- **Command Palette**: `⌘K` / `Ctrl+K`
- **Context Menu**: Right-click or `Menu` key
- **Navigation**: Arrow keys, `Tab`, `Enter`, `Escape`

## When to Use

**CommandPalette**: For power users and quick access to commands
**ContextMenu**: For contextual actions on items
**DropdownMenu**: For grouped actions in a button
**Popover**: For supplementary information or actions
**Draggable**: For reordering or organizing content
