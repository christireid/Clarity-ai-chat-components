# Components Overview

Clarity Chat provides 70+ production-ready components for building AI chat interfaces. This guide helps you understand how components are organized and how to use them effectively.

## Component Categories

### 📨 Messaging Components

Components for displaying and managing chat messages:

- **Message** - Individual message display with animations and interactions
- **MessageList** - Virtualized list of messages
- **StreamingMessage** - Real-time streaming message display
- **ChatWindow** - Complete chat interface container

**When to use:**
- Building chat interfaces
- Displaying conversation history
- Showing real-time updates

**See:** [Messaging Components](./MessageEssentials)

---

### ⌨️ Input & Interaction

Components for user input and interaction:

- **ChatInput** - Text input with auto-resize and file upload
- **VoiceInput** - Voice-to-text input with waveform
- **CommandPalette** - Command palette with fuzzy search
- **ContextMenu** - Right-click context menus

**When to use:**
- Collecting user input
- Voice interactions
- Power-user features
- Contextual actions

**See:** [Input Components](./ChatInputEssentials)

## Best Practices

### Component Selection

1. **Start Simple** - Use basic components first
2. **Progressive Enhancement** - Add features as needed
3. **Check Examples** - Look at real-world examples
4. **Read Docs** - Understand props and behavior

### Performance

1. **Use Virtualization** - For long lists (MessageList)
2. **Memoize Props** - Prevent unnecessary re-renders
3. **Lazy Load** - Load components on demand
4. **Optimize Imports** - Import only what you need

### Accessibility

1. **Use Semantic HTML** - Components handle this automatically
2. **Keyboard Navigation** - All components support keyboard
3. **Screen Readers** - ARIA labels included
4. **Focus Management** - Proper focus handling

## Component Patterns

### Basic Pattern

```tsx
import { ComponentName } from '@clarity-chat/react'

function App() {
  return <ComponentName prop1="value" />
}
```

### With State

```tsx
import { ComponentName } from '@clarity-chat/react'
import { useState } from 'react'

function App() {
  const [value, setValue] = useState('')
  
  return (
    <ComponentName
      value={value}
      onChange={setValue}
    />
  )
}
```

### With Hooks

```tsx
import { ComponentName } from '@clarity-chat/react'
import { useClarityChat } from '@clarity-chat/react'

function App() {
  const { messages } = useClarityChat({ api: '/api/chat' })
  
  return <ComponentName messages={messages} />
}
```
