Components for displaying messages, data, and content in chat interfaces. Optimized for performance with large datasets.

## Performance Tips

- ✅ Use MessageList for 50+ messages (virtualization)
- ✅ Memoize message components
- ✅ Lazy load message history
- ✅ Enable markdown rendering selectively
- ✅ Optimize images and media
