# Layout Components

Layout components provide structure and organization for your chat interface. They handle responsive design, sidebars, modals, and overall page structure.

## Quick Links

- [ChatWindow](?path=/docs/components-layout-chatwindow--docs) ⭐ - Complete chat interface container
- [Dialog](?path=/docs/components-layout-dialog--docs) ⭐ - Modal dialog component
- [Drawer](?path=/docs/components-layout-drawer--docs) - Slide-out drawer panel
- [ConversationList](?path=/docs/components-layout-conversationlist--docs) - List of conversations
- [ProjectSidebar](?path=/docs/components-layout-projectsidebar--docs) - Project navigation sidebar
- [SettingsPanel](?path=/docs/components-layout-settingspanel--docs) - Settings configuration panel

## Component Categories

### Main Layouts
- **ChatWindow** - Primary chat interface container
- **ConversationList** - Conversation history sidebar

### Overlays
- **Dialog** - Modal dialogs for important actions
- **Drawer** - Slide-out panels for additional content

### Navigation
- **ProjectSidebar** - Project and file navigation
- **SettingsPanel** - Configuration and preferences

## Best Practices

- ✅ Use responsive breakpoints (mobile, tablet, desktop)
- ✅ Ensure keyboard navigation works
- ✅ Handle focus trapping in modals
- ✅ Support scroll restoration
- ✅ Optimize for mobile touch targets
- ✅ Use semantic HTML landmarks

## When to Use

**ChatWindow**: As the main chat interface container
**Dialog**: For confirmations, forms, or important messages
**Drawer**: For supplementary content or navigation
**ConversationList**: To show conversation history
**ProjectSidebar**: For multi-project applications
**SettingsPanel**: For user preferences and configuration
