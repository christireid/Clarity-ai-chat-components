# Input Components

Input components allow users to enter data and interact with your chat interface. Built for accessibility, performance, and delightful UX.

## Best Practices

- ✅ Auto-focus input on mount
- ✅ Support keyboard shortcuts (Enter to send)
- ✅ Show loading states
- ✅ Add character/token counters
- ✅ Validate input before sending
- ✅ Ensure keyboard accessibility
