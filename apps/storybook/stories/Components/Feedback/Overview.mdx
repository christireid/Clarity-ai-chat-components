# Feedback Components

Feedback components communicate system status, user actions, and application state. They provide essential visual and interactive feedback to keep users informed.

## Component Categories

### Loading & Progress
- **ThinkingIndicator** - Shows AI is processing
- **FeedbackAnimation** - Animated feedback states

### Notifications
- **Toast** - Temporary notification messages
- **NetworkStatus** - Connection and sync status

### Status & Quality
- **ResponseQualityMeter** - Measures response quality
- **SafetyStatusCard** - Monitors AI safety
- **SessionSummaryCard** - Summarizes conversation

### Error Handling
- **ErrorBoundary** - Catches and displays errors
- **EmptyState** - Friendly empty states

## Best Practices

- ✅ Show loading states for operations > 500ms
- ✅ Keep toast messages brief (3-5 seconds)
- ✅ Provide clear error messages with actions
- ✅ Use appropriate status indicators
- ✅ Ensure animations are accessible
- ✅ Support prefers-reduced-motion

## When to Use

**ThinkingIndicator**: When AI is generating a response
**Toast**: For temporary success/error messages
**ErrorBoundary**: To gracefully handle component errors
**NetworkStatus**: For real-time connection monitoring
**EmptyState**: When lists or content areas are empty
