# State Management Hooks

State management hooks help manage component state, local storage, and message operations. They provide utilities for common state patterns in chat interfaces.

## Quick Links

- [useLocalStorage](?path=/docs/hooks-state-uselocalstorage--docs) ⭐ - Persistent local storage
- [usePrevious](?path=/docs/hooks-state-useprevious--docs) - Track previous values
- [useClarityObject](?path=/docs/hooks-state-useclarityobject--docs) - Clarity object state
- [useMessageOperations](?path=/docs/hooks-state-usemessageoperations--docs) - Message CRUD operations

## Hook Categories

### Persistence
- **useLocalStorage** - Sync state with localStorage

### State Utilities
- **usePrevious** - Access previous render values
- **useClarityObject** - Manage Clarity-specific state

### Message Management
- **useMessageOperations** - Edit, delete, branch messages

## Best Practices

- ✅ Use `useLocalStorage` for user preferences
- ✅ Implement proper serialization for complex objects
- ✅ Handle storage quota errors
- ✅ Use `usePrevious` for animations and transitions
- ✅ Batch message operations for performance
- ✅ Provide undo/redo for destructive operations

## Basic Usage

### useLocalStorage

```tsx
import { useLocalStorage } from '@clarity-chat/react'

function Settings() {
  const [theme, setTheme] = useLocalStorage('theme', 'light')

  return (
    <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
      Toggle Theme ({theme})
    </button>
  )
}
```

### usePrevious

```tsx
import { usePrevious } from '@clarity-chat/react'

function Counter() {
  const [count, setCount] = useState(0)
  const prevCount = usePrevious(count)

  return (
    <div>
      Current: {count}, Previous: {prevCount}
      <button onClick={() => setCount(c => c + 1)}>Increment</button>
    </div>
  )
}
```

## When to Use

**useLocalStorage**: For persisting user preferences
**usePrevious**: For animations or comparing values
**useClarityObject**: For Clarity-specific state management
**useMessageOperations**: For message editing features
