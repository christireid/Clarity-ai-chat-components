# Hooks Overview

Clarity Chat provides powerful React hooks for building AI chat interfaces.
These hooks handle complex state management, streaming, memory, and more.

---

## Core Hooks

### useClarityChat

**The flagship hook** for building chat interfaces. This is the recommended starting point.

- Message management with automatic state
- API integration with streaming
- Memory support (sliding-window, semantic-chunks)
- Transport selection (SSE/WebSocket)
- Error handling and recovery

**See:** [useClarityChat Stories](?path=/docs/hooks-primary-useclaritychat--docs)

---

### useStreaming

Low-level streaming primitive for handling ReadableStream data.

- Automatic text decoding from Uint8Array
- Chunk-by-chunk processing with callbacks
- AbortController support for cancellation
- Complete content accumulation

**See:** [useStreaming Stories](?path=/docs/hooks-streaming-usestreaming--docs)

---

### useCompletion

Mid-level hook for text completion with streaming support.

- Single-turn completions
- Request caching and deduplication
- Progress tracking
- Error handling

**See:** [useCompletion Stories](?path=/docs/hooks-chat-usecompletion--docs)

---

### useAssistant

Hook for AI assistant interactions with tool calling support.

- Tool invocation handling
- Multi-step workflows
- Status tracking (idle, loading, streaming, processing_tools)
- Thread/run management

**See:** [useAssistant Stories](?path=/docs/hooks-chat-useassistant--docs)

---

### useAutoScroll

Smart auto-scrolling for chat interfaces.

- User scroll detection
- Configurable threshold
- Smooth animation
- Manual control

**See:** [useAutoScroll Stories](?path=/docs/hooks-performance-useautoscroll--docs)

## Quick Start

### Basic Chat

```tsx
import { useClarityChat } from '@clarity-chat/react'

function App() {
  const { messages, append, isLoading } = useClarityChat({
    api: '/api/chat',
  })

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      <button onClick={() => append({ role: 'user', content: 'Hello' })}>
        Send
      </button>
    </div>
  )
}
```

## Hook Patterns

### Pattern 1: Basic Chat

```tsx
const { messages, append, isLoading } = useClarityChat({
  api: '/api/chat',
})
```

### Pattern 2: With Memory

```tsx
const { messages, append } = useClarityChat({
  api: '/api/chat',
  memory: {
    enabled: true,
    strategy: 'sliding-window',
    maxTokens: 4000,
  },
})
```

### Pattern 3: With Streaming

```tsx
const { messages, append, isStreaming } = useClarityChat({
  api: '/api/chat',
  stream: true,
})
```

## Best Practices

### ✅ Do

- Use `useClarityChat` for most cases (it's the flagship hook)
- Enable memory for multi-turn conversations
- Handle errors with `onError` callback and `error` state
- Use TypeScript for full type safety
- Prefer `append()` over manual message manipulation

### ❌ Don't

- Don't duplicate hook state in component state
- Don't ignore error states in your UI
- Don't skip memory for context-heavy chats
- Don't forget to handle loading states
- Don't use deprecated `useChat` - migrate to `useClarityChat`
