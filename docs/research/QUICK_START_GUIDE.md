## 🎨 Design System Decisions

### Colors: OKLCH from shadcn/ui AI

```css
--background: oklch(1 0 0);
--foreground: oklch(0.145 0 0);
--primary: oklch(0.6 0.2 240);
```

### Typography: Geist from shadcn/ui AI

```css
font-family: 'Geist', system-ui, sans-serif;
```

### Spacing: 4px grid from Ant Design X

```css
/* Base: 4px, Scale: 1, 2, 3, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 64 */
```

### Components: Sub-component composition from Ant Design X

```tsx
<Sender header={<Header />} prefix={<Icon />} suffix={<Button />} onSubmit={handleSubmit} />
```
