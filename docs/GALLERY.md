# The Full Gallery

Every screen below is a real capture of the Clarity Chat component showcase running locally — 103
component views and 26 clips across 18 categories.

Run it yourself:

```bash
pnpm install && pnpm build:packages
pnpm --filter @clarity-chat/component-showcase dev   # http://localhost:3100
```
