## 🎓 Guiding Principles

### Non-Negotiables
- ✅ Library-first thinking (not app-first)
- ✅ Research-driven decisions
- ✅ Incremental, phased work
- ✅ Reuse over reinvention
- ✅ AI-specific patterns baked in
- ✅ Accessibility as core feature

### Review Loops
After each phase:
1. **Staff Engineering Review** - API, maintainability
2. **AI Product Review** - Developer experience
3. **Reuse Audit** - Simplification opportunities
4. **QA & Security Review** - Safety and quality
5. **Research Spot-Check** - Alignment with best practices
