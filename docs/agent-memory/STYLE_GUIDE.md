# Style Guide

## Typography
- Font: Inter (via Geist)
- Headings: Tracking-tight, heavy weight
- Body: Relaxed line-height

## Colors
- Primary: Blue-600 (Light), Blue-500 (Dark)
- Surface: White / Slate-950
- Glass: `backdrop-blur-md bg-white/50`

## Components
- **Cards**: Thin border, subtle shadow, hover lift.
- **Buttons**: Medium radius, strong focus ring.
