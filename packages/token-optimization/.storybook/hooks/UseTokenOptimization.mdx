# useTokenOptimization

The unified hook for complete token optimization. Combines compression, caching, and routing with provider-native caching for up to 90% cost savings.

## Overview

`useTokenOptimization` is the **recommended starting point** for token optimization. It provides an all-in-one interface that combines:

- **Token counting** - Accurate counts across GPT-4, Claude, and Gemini
- **Compression** - TOON-inspired markdown compression (20-40% savings)
- **Caching** - 3-tier cache with exact, smart, and semantic matching
- **Model routing** - Cost-optimized selection based on complexity
- **Provider-native caching** - 90% cost savings on cached tokens (Anthropic, OpenAI, Google)

**When to use:**
- Building chat applications with LLM APIs
- Need automatic cost optimization
- Want caching with semantic matching
- Require intelligent model routing
- Looking for the simplest complete solution

**When not to use:**
- Only need token counting → use `useTokenCount`
- Only need budget tracking → use `useTokenBudgetMonitor`
- Need fine-grained control over each feature → use individual hooks

## Basic Usage

```tsx
import { useTokenOptimization } from '@clarity-chat/token-optimization/react'

function ChatComponent() {
  const [prompt, setPrompt] = useState('')
  const { optimize, getStats } = useTokenOptimization({
    preset: 'production',
    model: 'gpt-4o',
  })

  const handleSend = async () => {
    const {
      cachedResponse,
      compressedPrompt,
      recommendedModel,
      tokensSaved,
      estimatedCostSaved,
    } = await optimize(prompt)

    if (cachedResponse) {
      // Use cached response - saved 100% of tokens!
      displayResponse(cachedResponse)
      return
    }

    // Send compressedPrompt to recommendedModel
    const response = await sendToLLM(compressedPrompt, recommendedModel)
    console.log(`Saved ${tokensSaved} tokens ($${estimatedCostSaved.toFixed(4)})`)
  }

  return (
    <div>
      <textarea
        value={prompt}
        onChange={(e) => setPrompt(e.target.value)}
        placeholder="Type your prompt..."
      />
      <button onClick={handleSend}>Send</button>
    </div>
  )
}
```

## API Reference

### Hook Signature

```tsx
useTokenOptimization(
  config?: UseTokenOptimizationConfig
): UseTokenOptimizationReturn
```

### Configuration Options

#### `config: UseTokenOptimizationConfig` (optional)

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `preset` | `'minimal' \| 'standard' \| 'production' \| 'enterprise'` | `'standard'` | Use preset configuration (recommended) |
| `model` | `string` | `'gpt-4o'` | Model for token counting |
| `availableModels` | `string[]` | `['gpt-4o-mini', 'gpt-4o', 'gpt-4-turbo']` | Models available for routing |
| `enableCache` | `boolean` | `true` | Enable 3-tier caching |
| `enableCompression` | `boolean` | `true` | Enable markdown compression |
| `enableRouting` | `boolean` | `true` | Enable model routing |
| `cacheConfig` | `Partial<TieredCacheConfig>` | - | Override cache settings |
| `routerConfig` | `Partial<ModelRouterConfig>` | - | Override router settings |

### Preset Configurations

Each preset optimizes for different use cases:

#### `minimal` - Development/Testing
- **Cache**: 100 exact, 50 smart entries (5 min TTL)
- **Compression**: Light (preserves readability)
- **Routing**: Cost-optimized
- **Best for**: Local development, testing

#### `standard` - Small Apps (Default)
- **Cache**: 500 exact, 200 smart entries (30 min TTL)
- **Compression**: Moderate (balanced savings)
- **Routing**: Balanced
- **Best for**: Small to medium applications

#### `production` - Production Apps
- **Cache**: 1000 exact, 500 smart entries (1 hour TTL)
- **Compression**: Moderate (balanced savings)
- **Routing**: Balanced
- **Best for**: Production deployments

#### `enterprise` - High-Volume Apps
- **Cache**: 5000 exact, 2000 smart entries (2 hour TTL)
- **Compression**: Aggressive (maximum savings)
- **Routing**: Quality-first
- **Best for**: Enterprise applications, high traffic

#### Core Functions

**`countTokens(text: string): number`**

Count tokens in text using accurate tokenizer.

```tsx
const tokens = countTokens('Hello, world!')
// => 4
```

**`getFromCache(prompt: string): Promise<string | undefined>`**

Retrieve cached response. Checks exact → smart → semantic tiers.

```tsx
const cached = await getFromCache('What is 2+2?')
if (cached) {
  console.log('Cache hit!', cached)
}
```

**`setInCache(prompt: string, response: string): Promise<void>`**

Store response in cache for future use.

```tsx
await setInCache('What is 2+2?', 'The answer is 4')
```

**`compress(text: string): CompressionResult`**

Compress markdown text to reduce tokens.

```tsx
const result = compress('# Heading\n\n- Item 1\n- Item 2')
console.log(`Saved ${result.savingsPercent}%`)
```

Returns:
```tsx
{
  compressed: string           // Compressed text
  originalSize: number         // Original character count
  compressedSize: number       // Compressed character count
  savingsPercent: number       // Percentage saved (0-100)
  estimatedTokensSaved: number // Approximate tokens saved
  toonApplied: boolean         // Whether TOON format was used
}
```

**`route(prompt: string): RoutingResult`**

Select optimal model based on complexity analysis.

```tsx
const routing = route('Write a detailed essay about...')
console.log(`Use ${routing.selectedModel?.id}`)
```

Returns:
```tsx
{
  selectedModel: ModelConfig | undefined
  strategy: RoutingStrategy
  complexity?: ComplexityResult
  estimatedCost?: number
  confidence: number  // 0-1
}
```

**`optimize(prompt: string): Promise<OptimizeResult>`**

**The main function** - applies all optimizations in optimal order:

1. Check cache for existing response
2. If not cached, compress the prompt
3. Route to optimal model
4. Return all optimization details

```tsx
const result = await optimize(prompt)
if (result.cachedResponse) {
  // Use cached response
} else {
  // Send result.compressedPrompt to result.recommendedModel
}
```

Returns:
```tsx
{
  cachedResponse?: string      // Cached response if found
  compressedPrompt: string     // Compressed prompt
  recommendedModel: string     // Model to use
  tokensSaved: number          // Tokens saved
  estimatedCostSaved: number   // USD saved
}
```

#### Statistics Functions

**`getStats(): StatsResult`**

Get comprehensive statistics across all features.

```tsx
const stats = getStats()
console.log(`Hit rate: ${stats.cache?.hitRate * 100}%`)
console.log(`Total saved: ${stats.tokensSaved} tokens`)
```

Returns:
```tsx
{
  cache: CacheStats | null
  router: RouterStats
  tokensProcessed: number
  tokensSaved: number
}
```

**`resetStats(): void`**

Reset all statistics counters to zero.

**`clearCache(): void`**

Clear all cached responses from all cache tiers.

#### React 19 Features

**`isPending: boolean`**

Whether a transition is pending (non-blocking state updates).

**`optimisticCache: OptimisticCacheState`**

Optimistic cache state for instant UI feedback.

```tsx
{

  lastOperation: 'idle' | 'pending' | 'success' | 'error'
}
```

**`optimisticSetInCache(prompt: string, response: string): void`**

Optimistically update cache with instant UI feedback (React 19).

## Examples

### 1. Complete Chat Application

```tsx
import { useTokenOptimization } from '@clarity-chat/token-optimization/react'
import { useState } from 'react'

function ChatApp() {
  const [messages, setMessages] = useState<Array<{ role: string; content: string }>>([])
  const [input, setInput] = useState('')
  const [loading, setLoading] = useState(false)

  const { optimize, setInCache, getStats } = useTokenOptimization({
    preset: 'production',
    model: 'gpt-4o',
  })

  const handleSend = async () => {
    if (!input.trim()) return

    setLoading(true)
    const userMessage = { role: 'user', content: input }
    setMessages((prev) => [...prev, userMessage])

    try {
      const {
        cachedResponse,
        compressedPrompt,
        recommendedModel,
        tokensSaved,
        estimatedCostSaved,
      } = await optimize(input)

      let response: string

      if (cachedResponse) {
        // Use cached response - instant and free!
        response = cachedResponse
      } else {
        // Send to LLM with optimized prompt
        response = await callLLM(compressedPrompt, recommendedModel)

        // Cache the response for future use
        await setInCache(input, response)
      }

      setMessages((prev) => [
        ...prev,
        { role: 'assistant', content: response },
      ])

      // Log savings
      const stats = getStats()
      console.log(`Saved ${tokensSaved} tokens ($${estimatedCostSaved.toFixed(4)})`)
      console.log(`Cache hit rate: ${(stats.cache?.hitRate ?? 0) * 100}%`)
    } finally {
      setLoading(false)
      setInput('')
    }
  }

  return (
    <div>
      <div className="messages">
        {messages.map((msg, i) => (
          <div key={i} className={`message ${msg.role}`}>
            {msg.content}
          </div>
        ))}
      </div>
      <div className="input">
        <textarea
          value={input}
          onChange={(e) => setInput(e.target.value)}
          disabled={loading}
        />
        <button onClick={handleSend} disabled={loading}>
          {loading ? 'Sending...' : 'Send'}
        </button>
      </div>
    </div>
  )
}

async function callLLM(prompt: string, model: string): Promise<string> {
  // Your LLM API call here
  const response = await fetch('/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt, model }),
  })
  const data = await response.json()
  return data.response
}
```

```tsx
import { useTokenOptimization } from '@clarity-chat/token-optimization/react'

function OptimisticChat() {
  const {
    optimize,
    optimisticSetInCache,
    optimisticCache,

          key={i}

        </div>
      ))}

      {optimisticCache.lastOperation === 'pending' && (
        <div>Caching in progress...</div>
      )}
    </div>
  )
}

  // Simple prediction for common patterns
  if (prompt.toLowerCase().includes('hello')) return 'Hi there!'
  return 'Let me think about that...'
}
```

```tsx
function SafeOptimization() {
  const { optimize } = useTokenOptimization({
    preset: 'production',
  })

  const handleSend = async (prompt: string) => {
    try {

        result.compressedPrompt,

  }
```

## Performance Considerations

### Initialization

The hook initializes all components on first render:

- **Token counter**: ~5ms (one-time)
- **Cache**: ~1ms (in-memory)
- **Router**: ~1ms (configuration)
- **Compressor**: <1ms (stateless)

Total initialization: **~10ms**

### Runtime Performance

#### Token Counting
- **Speed**: ~0.1ms per 1000 characters
- **Caching**: Results cached for identical input
- **Thread**: Synchronous, non-blocking

#### Compression
- **Speed**: ~1-5ms per 1000 characters
- **Savings**: 20-40% typical (up to 60% for verbose content)
- **Thread**: Synchronous

#### Caching
- **Lookup**: O(1) for exact matches (~0.1ms)
- **Smart matching**: O(n) patterns (~1ms for 500 entries)
- **Semantic matching**: O(n) embeddings (~10-50ms for 200 entries)
- **Storage**: All in-memory, no disk I/O

#### Routing
- **Analysis**: ~1-2ms per prompt
- **Decision**: <1ms
- **Caching**: Complexity results cached

#### Combined (optimize)
- **Without cache hit**: ~5-10ms total
- **With cache hit**: ~0.1-1ms (99% faster)
- **Async operations**: Cache lookups only

### Memory Usage

Per hook instance:

- **Token counter**: ~100KB (shared encoder)
- **Cache**: ~1-5MB (depends on preset)
  - Minimal: ~500KB
  - Standard: ~2MB
  - Production: ~3MB
  - Enterprise: ~5MB
- **Router**: ~10KB
- **Compressor**: <1KB

**Total**: 1-5MB depending on preset and cache size

### Optimization Tips

1. **Use appropriate preset**
   ```tsx
   // Development
   useTokenOptimization({ preset: 'minimal' })

   // Production
   useTokenOptimization({ preset: 'production' })
   ```

2. **Adjust cache size for your use case**
   ```tsx
   useTokenOptimization({
     cacheConfig: {
       exact: { maxSize: 100 },  // Fewer unique queries
       semantic: { maxSize: 50 }, // Reduce memory
     },
   })
   ```

3. **Disable unused features**
   ```tsx
   useTokenOptimization({
     enableCompression: false, // If content is already optimized
   })
   ```

4. **Clear cache periodically**
   ```tsx
   useEffect(() => {
     const interval = setInterval(() => {
       clearCache()
     }, 3600000) // Clear every hour
     return () => clearInterval(interval)
   }, [clearCache])
   ```

```tsx
// Apply caching to your messages before sending

  // ...
```

**Savings**: 90% on cached tokens after first use

### Batch Processing

```tsx
function BatchProcessor() {
  const { optimize } = useTokenOptimization({
    preset: 'production',
  })

  const processBatch = async (prompts: string[]) => {
    const results = await Promise.all(
      prompts.map(async (prompt) => {
        const result = await optimize(prompt)

        if (result.cachedResponse) {
          return { prompt, response: result.cachedResponse, cached: true }
        }

        const response = await callLLM(
          result.compressedPrompt,
          result.recommendedModel
        )
        return { prompt, response, cached: false }
      })
    )

    const cacheHits = results.filter((r) => r.cached).length
    console.log(`Cache hit rate: ${(cacheHits / results.length) * 100}%`)

    return results
  }

  return <div>Batch processor</div>
}
```

## Troubleshooting

### Cache not hitting

**Problem**: Cache always returns `undefined`

**Solutions**:
1. Verify caching is enabled:
   ```tsx
   useTokenOptimization({ enableCache: true })
   ```

2. Check if prompts are identical:
   ```tsx
   // These are different (whitespace matters)
   await setInCache('hello', 'hi')
   await getFromCache('hello ') // undefined
   ```

3. Verify TTL hasn't expired:
   ```tsx
   useTokenOptimization({
     cacheConfig: {
       exact: { ttl: 1800000 }, // 30 minutes
     },
   })
   ```

4. Use semantic cache for similar prompts:
   ```tsx
   useTokenOptimization({
     cacheConfig: {
       semantic: {
         similarityThreshold: 0.85, // Lower = more lenient
       },
     },
   })
   ```

### Routing always selects same model

**Problem**: Router picks the same model regardless of complexity

**Solutions**:
1. Verify multiple models are configured:
   ```tsx
   useTokenOptimization({
     availableModels: ['gpt-4o-mini', 'gpt-4o', 'gpt-4-turbo'],
   })
   ```

2. Check routing strategy:
   ```tsx
   useTokenOptimization({
     routerConfig: {
       defaultStrategy: RoutingStrategy.Balanced, // Not always cost-optimized
     },
   })
   ```

3. Verify model configs have different tiers:
   ```tsx
   const models = [
     { id: 'gpt-4o-mini', tier: 'small', ... },
     { id: 'gpt-4o', tier: 'medium', ... },
     { id: 'gpt-4-turbo', tier: 'large', ... },
   ]
   ```

### High memory usage

**Problem**: Hook consuming too much memory

**Solutions**:
1. Use smaller preset:
   ```tsx
   useTokenOptimization({ preset: 'minimal' }) // vs 'enterprise'
   ```

2. Reduce cache size:
   ```tsx
   useTokenOptimization({
     cacheConfig: {
       exact: { maxSize: 100 },
       smart: { maxSize: 50 },
       semantic: { maxSize: 25 },
     },
   })
   ```

3. Clear cache periodically:
   ```tsx
   useEffect(() => {
     const interval = setInterval(clearCache, 3600000)
     return () => clearInterval(interval)
   }, [clearCache])
   ```

### Compression not saving tokens

**Problem**: `compress()` returns 0% savings

**Solutions**:
1. Verify compression is enabled:
   ```tsx
   useTokenOptimization({ enableCompression: true })
   ```

2. Use content with compressible formatting:
   ```tsx
   // Compressible (markdown)
   compress('# Heading\n\n- Item 1\n- Item 2')

   // Not compressible (plain text)
   compress('Plain text without formatting')
   ```

3. Use higher compression level:
   ```tsx
   useTokenOptimization({ preset: 'enterprise' }) // Uses aggressive compression
   ```

### TypeError: Cannot read property 'count'

**Problem**: `countTokens()` throws error

**Solutions**:
1. Wait for hook initialization:
   ```tsx
   const { countTokens } = useTokenOptimization()

   useEffect(() => {
     // Safe after mount
     const count = countTokens(text)
   }, [text, countTokens])
   ```

2. Pass valid string:
   ```tsx
   // ❌ Wrong
   countTokens(undefined)

   // ✅ Correct
   countTokens(text || '')
   ```

### React 19 features not working

**Problem**: `isPending` or `optimisticCache` not functioning

**Solutions**:
1. Verify React version:
   ```bash
   npm ls react
   # Should be 19.x
   ```

2. Enable concurrent features:
   ```tsx
   // In your root component
   import { createRoot } from 'react-dom/client'

   const root = createRoot(document.getElementById('root'))
   root.render(<App />)
   ```

3. Use in component, not effects:
   ```tsx
   // ❌ Wrong
   useEffect(() => {
     optimisticSetInCache(prompt, response)
   }, [])

   // ✅ Correct (in event handler)
   const handleClick = () => {
     optimisticSetInCache(prompt, response)
   }
   ```
