# Dev Tools Examples

Examples demonstrating the React 19 enhanced developer tools.

## React 19 Demo

Comprehensive example showing all React 19 features:

```tsx
import { React19DevToolsDemo } from '@clarity-chat/dev-tools/examples/react-19-demo'

function App() {
  return <React19DevToolsDemo />
}
```

## Features Demonstrated

1. **useOptimistic** - Optimistic UI updates in API inspector and profiler
2. **Client-Side Form State** - Form state management in validation forms
3. **Real-time Updates** - Components automatically update as data changes
4. **State Management** - Time-travel debugging with state snapshots

## Running Examples

```bash
# Install dependencies
npm install

# Run example (requires React 19)
npm run example
```
