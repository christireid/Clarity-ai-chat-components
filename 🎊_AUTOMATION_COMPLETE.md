## 🛠️ How to Use

### For Contributors

**Enhance an Example:**
```bash
# 1. Check current state
./scripts/enhance-example.sh example-name

# 2. Fix identified issues
# - Remove @ts-nocheck
# - Fix type errors
# - Add missing features

# 3. Update/generate README
./scripts/generate-readme.sh example-name

# 4. Verify
cd examples/example-name
npx tsc --noEmit  # Should be 0 errors
npm run dev       # Should work

# 5. Commit
git add examples/example-name
git commit -m "feat: Enhance example-name"
```

**Follow the Guide:**
```bash
# Read comprehensive guide
cat CONTRIBUTING_EXAMPLES.md

# Check status
./scripts/check-all-examples.sh

# View detailed report
```

**Review Progress:**
```bash
./scripts/check-all-examples.sh
```
