## 🎨 Design Patterns Reference

### The 6 Core Patterns

All documentation references these patterns:

1. **Ring-Based Borders** - `ring-1 ring-border/50`
2. **Refined Shadows** - `shadow-xs`, `shadow-sm`
3. **Consistent Radius** - `rounded-md`, `rounded-lg`
4. **Enhanced Focus** - `ring-[3px] ring-ring/50`
5. **Precise Hover** - `-translate-y-[2px]`
6. **Consistent Opacity** - `/10`, `/30`, `/50`

See [DESIGN_SYSTEM_GUIDE_V2.md](./DESIGN_SYSTEM_GUIDE_V2.md) for complete details.
